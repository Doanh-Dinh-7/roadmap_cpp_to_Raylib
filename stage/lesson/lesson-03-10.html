Các Hàm Xử Lý Chuỗi Thường Gặp

Mục tiêu đầu ra: Dùng thành thạo substr, find (và npos), ghép chuỗi bằng +/append, insert, erase, toupper/tolower trong <cctype> để cắt, ghép, kiểm tra và chuẩn hóa chuỗi — áp dụng chuẩn hóa họ tên và kiểm tra chuỗi đối xứng (palindrome).

1. Lý thuyết cốt lõi (30 Phút)

Ở Buổi 31, bạn đã biết khai báo std::string, nhập bằng std::getline và duyệt từng ký tự. Nhưng game thật cần nhiều hơn thế: tách tên clan khỏi tên nhân vật, lọc từ cấm trong khung chat, đọc lệnh /heal 30, chuẩn hóa tên người chơi... std::string có sẵn một bộ hàm thành viên (gọi bằng dấu chấm: s.ten_ham(...)) giúp làm các việc này chỉ trong một dòng.

1.1 Bảng tóm tắt các hàm xử lý chuỗi

Giả sử std::string s = "Hello World"; (chỉ số bắt đầu từ 0):

Hàm Ý nghĩa Ví dụ Kết quả
s.substr(pos, len)Cắt chuỗi con dài len bắt đầu tại poss.substr(0, 5)"Hello"
s.substr(pos)Cắt từ pos đến hết chuỗis.substr(6)"World"
s.find(x)Vị trí xuất hiện đầu tiên của x; không thấy → std::string::nposs.find("o")4
s.find(x, start)Tìm x bắt đầu từ vị trí starts.find("o", 5)7
s.rfind(x)Vị trí xuất hiện cuối cùng của xs.rfind("o")7
s + t, s += tGhép chuỗi (tạo mới / nối vào cuối)s + "!""Hello World!"
s.append(t)Nối t vào cuối s (giống +=)s.append("!!")"Hello World!!"
s.insert(pos, t)Chèn t vào trước vị trí poss.insert(5, ",")"Hello, World"
s.erase(pos, len)Xóa len ký tự bắt đầu tại poss.erase(0, 6)"World"
std::toupper(c) / std::tolower(c)Đổi một ký tự sang chữ hoa / thường (thư viện <cctype>)std::toupper('a')'A'
std::isalpha, isdigit, isalnum, isupper, islowerKiểm tra loại ký tự: chữ cái, chữ số, chữ hoặc số, hoa, thường (<cctype>)std::isdigit('7')khác 0 (đúng)

Lưu ý: insert, erase, append sửa trực tiếp chuỗi s; còn substr, find chỉ đọc và trả về kết quả mới, s giữ nguyên.

1.2 Cắt, ghép, chèn, xóa — Tạo danh hiệu nhân vật

Ví dụ dưới đây tách tên clan VN khỏi tag "[VN]DragonSlayer", rồi tạo một danh hiệu mới:

string_basics.cpp 
#include <iostream>
#include <string>

int main() {
    std::string tag = "[VN]DragonSlayer";

    // substr(vi_tri, so_ky_tu): cat lay chuoi con
    std::string clan = tag.substr(1, 2);        // "VN"
    std::string name = tag.substr(4);           // "DragonSlayer" (lay den het chuoi)

    // find: tim vi tri xuat hien dau tien
    std::size_t pos = name.find("Slayer");      // 6
    if (pos != std::string::npos) {
        std::cout << "Tim thay 'Slayer' tai vi tri " << pos << "\n";
    }

    // Ghep chuoi bang + va append
    std::string title = name + " Lv.";
    title.append("99");                         // "DragonSlayer Lv.99"

    // insert(vi_tri, chuoi): chen vao giua
    title.insert(0, "Sir ");                    // "Sir DragonSlayer Lv.99"

    // erase(vi_tri, so_ky_tu): xoa bot mot doan
    title.erase(4, 6);                          // "Sir Slayer Lv.99"

    std::cout << "Clan: " << clan << "\n";
    std::cout << "Ten: " << name << "\n";
    std::cout << "Danh hieu: " << title << "\n";
    return 0;
}

1.3 find và giá trị đặc biệt npos

Khi không tìm thấy, find trả về hằng số std::string::npos (một số nguyên không âm rất lớn). Vì vậy luôn so sánh với npos trước khi dùng vị trí tìm được. Kiểu dữ liệu chuẩn để lưu vị trí là std::size_t (số nguyên không âm). Muốn đếm số lần xuất hiện, ta gọi find lặp lại, mỗi lần bắt đầu tìm từ sau vị trí vừa thấy:

chat_counter.cpp 
#include <iostream>
#include <string>

int main() {
    std::string chat = "gg ez, gg wp, gg";
    std::string word = "gg";

    int count = 0;
    std::size_t pos = chat.find(word);                // Tim lan dau tien
    while (pos != std::string::npos) {
        count++;
        pos = chat.find(word, pos + word.length());   // Tim tiep tu sau lan truoc
    }
    std::cout << "'" << word << "' xuat hien " << count << " lan\n";   // 3 lan

    if (chat.find("noob") == std::string::npos) {
        std::cout << "Tin nhan sach, khong co tu cam.\n";
    }
    return 0;
}

1.4 erase trong vòng lặp — Cắt khoảng trắng thừa

Người chơi hay gõ thừa dấu cách khi đặt tên. Hàm trim xóa dần ký tự trống ở hai đầu cho đến khi gặp ký tự thật:

trim.cpp 
#include <iostream>
#include <string>

// Xoa khoang trang thua o dau va cuoi chuoi
std::string trim(std::string s) {
    while (s.length() > 0 && s[0] == ' ') {
        s.erase(0, 1);                       // Xoa ky tu dau tien
    }
    while (s.length() > 0 && s[s.length() - 1] == ' ') {
        s.erase(s.length() - 1, 1);          // Xoa ky tu cuoi cung
    }
    return s;
}

int main() {
    std::string input = "    Shadow Knight   ";
    std::cout << "[" << trim(input) << "]\n";    // [Shadow Knight]
    std::cout << "[" << input << "]\n";          // Chuoi goc van con khoang trang
    return 0;
}

Chú ý: chuỗi std::string truyền vào hàm theo kiểu tham trị (Buổi 24) nên hàm làm việc trên bản sao — chuỗi input ở main không bị thay đổi. Đây là điểm khác với mảng: mảng truyền vào hàm sẽ bị sửa trực tiếp (cơ chế này sẽ được giải thích ở Giai đoạn 04).

1.5 Đổi hoa/thường với <cctype>

std::toupper và std::tolower chỉ xử lý một ký tự. Muốn đổi cả chuỗi, ta duyệt từng ký tự bằng vòng for:

case_convert.cpp 
#include <iostream>
#include <string>
#include <cctype>

std::string toUpperStr(std::string s) {
    for (int i = 0; i < s.length(); i++) {
        s[i] = std::toupper(s[i]);           // Doi tung ky tu sang chu hoa
    }
    return s;                                // s la ban sao -> chuoi goc khong doi
}

int main() {
    std::string boss = "Dark Lord";
    std::cout << toUpperStr(boss) << "\n";   // DARK LORD
    std::cout << boss << "\n";               // Dark Lord (khong bi sua)

    char key = 'w';
    if (std::islower(key)) {
        key = std::toupper(key);
    }
    std::cout << "Phim: " << key << "\n";    // Phim: W
    return 0;
}
🎮 Mẹo tư duy Game: Xử lý chuỗi có mặt khắp nơi trong game: chat filter dùng find để phát hiện từ cấm; console lệnh (/give sword 3) dùng find(' ') + substr để tách lệnh và tham số; so sánh không phân biệt hoa thường (người chơi gõ YES, yes hay Yes) bằng cách tolower toàn bộ trước khi so sánh. Trong Raylib, bạn sẽ ghép chuỗi kiểu "Player: " + name để vẽ chữ lên màn hình.
⚠️ Lỗi thường gặp:
  • Quên kiểm tra npos: dùng thẳng s.substr(s.find(' ')) khi chuỗi không có dấu cách → substr nhận vị trí khổng lồ và chương trình dừng đột ngột (lỗi out_of_range).
  • substr(pos) với pos > s.length() cũng gây lỗi tương tự. Riêng len quá dài thì an toàn — substr chỉ lấy đến hết chuỗi.
  • Lưu vị trí vào int rồi so sánh với npos có thể cho kết quả sai — hãy dùng std::size_t.
  • erase trong vòng for tăng i: sau khi xóa, các ký tự phía sau dồn lên một ô, nếu vẫn i++ sẽ bỏ sót ký tự. Hoặc dùng while như hàm trim, hoặc xây chuỗi kết quả mới (cách ở bài tập trên lớp).
  • Tiếng Việt có dấu ("Nguyễn") dùng nhiều byte cho một chữ, nên toupper, isalpha, length() không hoạt động như mong đợi. Trong khóa học, dữ liệu chuỗi viết không dấu.

2. Bài tập trên lớp (60 Phút)

Bài 1: Chuẩn hóa họ tên người chơi

Trên lớp

Đề bài: Viết hàm std::string normalizeName(std::string s) chuẩn hóa họ tên: bỏ khoảng trắng ở đầu/cuối, giữa hai từ chỉ còn đúng một dấu cách, chữ cái đầu mỗi từ viết hoa, các chữ còn lại viết thường.
Ví dụ: " nGUyen vAN aN " → "Nguyen Van An".

Ý tưởng: Thay vì erase nhiều lần trên chuỗi gốc (dễ bỏ sót ký tự), ta xây chuỗi kết quả mới: duyệt từng ký tự, gặp dấu cách thì đánh dấu "sắp sang từ mới" (newWord = true); gặp chữ cái thì nếu là đầu từ → thêm 1 dấu cách (trừ từ đầu tiên) và viết hoa, ngược lại viết thường.
normalize_name.cpp 
#include <iostream>
#include <string>
#include <cctype>

// Chuan hoa ho ten: bo khoang trang thua, viet hoa chu cai dau moi tu
std::string normalizeName(std::string s) {
    std::string result = "";
    bool newWord = true;                     // Ky tu tiep theo la dau mot tu?

    for (int i = 0; i < s.length(); i++) {
        char c = s[i];
        if (c == ' ') {
            newWord = true;                  // Gap khoang trang -> sap sang tu moi
            continue;
        }
        if (newWord) {
            if (result.length() > 0) {
                result += ' ';               // Chi them 1 khoang trang giua 2 tu
            }
            char up = std::toupper(c);
            result += up;
            newWord = false;
        } else {
            char low = std::tolower(c);
            result += low;
        }
    }
    return result;
}

int main() {
    std::string fullName;
    std::cout << "Nhap ho ten: ";
    std::getline(std::cin, fullName);

    std::cout << "Truoc: [" << fullName << "]\n";
    std::cout << "Sau:   [" << normalizeName(fullName) << "]\n";
    return 0;
}

Bài 2: Kiểm tra chuỗi đối xứng (Palindrome)

Trên lớp

Đề bài: Viết hàm bool isPalindrome(std::string s) kiểm tra một câu có đọc xuôi và ngược giống nhau không, bỏ qua dấu cách, dấu câu và hoa/thường.
Test: "level" → đúng; "Race car" → đúng; "Was it a car or a cat I saw?" → đúng; "hello" → sai.

palindrome.cpp 
#include <iostream>
#include <string>
#include <cctype>

bool isPalindrome(std::string s) {
    // Buoc 1: Lam sach - chi giu chu cai/chu so, doi het ve chu thuong
    std::string clean = "";
    for (int i = 0; i < s.length(); i++) {
        if (std::isalnum(s[i])) {
            char low = std::tolower(s[i]);
            clean += low;
        }
    }

    // Buoc 2: Hai chi so chay tu hai dau vao giua
    int n = clean.length();
    int left = 0;
    int right = n - 1;
    while (left < right) {
        if (clean[left] != clean[right]) {
            return false;                    // Lech 1 cap la khong doi xung
        }
        left++;
        right--;
    }
    return true;
}

int main() {
    std::string line;
    std::cout << "Nhap mot cau: ";
    std::getline(std::cin, line);

    if (isPalindrome(line)) {
        std::cout << "-> La chuoi doi xung (palindrome)!\n";
    } else {
        std::cout << "-> Khong phai chuoi doi xung.\n";
    }
    return 0;
}
🎯 Kỹ thuật hai con trỏ chỉ số: left chạy từ đầu, right chạy từ cuối, gặp nhau ở giữa → chỉ cần n/2 lần so sánh, tức độ phức tạp O(n) (Buổi 30). Kỹ thuật này còn dùng để đảo ngược mảng hoặc chuỗi tại chỗ.

3. Bài tập về nhà (Tự luyện tập)

Bài 1 [Easy]: Tạo tag hiển thị cho nhân vật

Easy (40%)

Nhập tên nhân vật (có thể có dấu cách). In ra: tên viết HOA toàn bộ, tên viết thường toàn bộ, và dòng hiển thị dạng [TAG] Ten, trong đó TAG là 3 ký tự đầu của tên viết hoa. Ví dụ: "Shadow" → [SHA] Shadow. Viết các hàm toUpperStr, toLowerStr, makeTag.

Gợi ý: substr(0, 3) vẫn an toàn khi tên chỉ có 1–2 ký tự — nó lấy đến hết chuỗi.

player_tag.cpp 
#include <iostream>
#include <string>
#include <cctype>

std::string toUpperStr(std::string s) {
    for (int i = 0; i < s.length(); i++) {
        s[i] = std::toupper(s[i]);
    }
    return s;
}

std::string toLowerStr(std::string s) {
    for (int i = 0; i < s.length(); i++) {
        s[i] = std::tolower(s[i]);
    }
    return s;
}

// Tag = 3 ky tu dau cua ten, viet hoa, dat trong ngoac vuong
std::string makeTag(std::string name) {
    std::string head = name.substr(0, 3);    // Ten ngan hon 3 ky tu -> substr tu lay het
    return "[" + toUpperStr(head) + "]";
}

int main() {
    std::string name;
    std::cout << "Nhap ten nhan vat: ";
    std::getline(std::cin, name);

    std::cout << "Chu hoa:    " << toUpperStr(name) << "\n";
    std::cout << "Chu thuong: " << toLowerStr(name) << "\n";
    std::cout << "Hien thi:   " << makeTag(name) << " " << name << "\n";
    return 0;
}

Bài 2 [Medium]: Tách họ, tên đệm, tên và tạo username

Medium (40%)

Nhập họ tên bất kỳ, chuẩn hóa bằng normalizeName (bài trên lớp), sau đó tách ra Họ (từ đầu), Tên (từ cuối) và Tên đệm (phần giữa, có thể rỗng hoặc nhiều từ). Cuối cùng tạo username = tên viết thường + chữ cái đầu của họ và của từng từ tên đệm.
Ví dụ: " nguyen van AN" → Họ: Nguyen, Tên đệm: Van, Tên: An, Username: annv.

Phân tích: find(' ') cho dấu cách đầu tiên (kết thúc họ), rfind(' ') cho dấu cách cuối cùng (bắt đầu tên). Phần nằm giữa hai vị trí này là tên đệm, độ dài last - first - 1. Nếu không có dấu cách nào (npos) thì cả chuỗi là tên.

split_name.cpp 
#include <iostream>
#include <string>
#include <cctype>

// Giu nguyen ham normalizeName tu bai tap tren lop (dat o day)

std::string toLowerStr(std::string s) {
    for (int i = 0; i < s.length(); i++) {
        s[i] = std::tolower(s[i]);
    }
    return s;
}

// Username = ten (chu thuong) + chu cai dau cua ho + chu cai dau moi tu ten dem
std::string makeUsername(std::string ho, std::string tenDem, std::string ten) {
    std::string user = toLowerStr(ten);
    if (ho.length() > 0) {
        char c = std::tolower(ho[0]);
        user += c;
    }
    for (int i = 0; i < tenDem.length(); i++) {
        if (i == 0 || tenDem[i - 1] == ' ') {    // Ky tu dau moi tu
            char c = std::tolower(tenDem[i]);
            user += c;
        }
    }
    return user;
}

int main() {
    std::string full;
    std::cout << "Nhap ho ten: ";
    std::getline(std::cin, full);
    full = normalizeName(full);

    std::size_t first = full.find(' ');      // Khoang trang dau tien
    std::size_t last = full.rfind(' ');      // Khoang trang cuoi cung

    std::string ho = "", tenDem = "", ten = "";
    if (first == std::string::npos) {
        ten = full;                          // Chi co 1 tu
    } else {
        ho = full.substr(0, first);
        ten = full.substr(last + 1);
        if (last > first) {
            tenDem = full.substr(first + 1, last - first - 1);
        }
    }

    std::cout << "Ho ten chuan: " << full << "\n";
    std::cout << "Ho:       " << ho << "\n";
    std::cout << "Ten dem:  " << tenDem << "\n";
    std::cout << "Ten:      " << ten << "\n";
    std::cout << "Username: " << makeUsername(ho, tenDem, ten) << "\n";
    return 0;
}

Bài 3 [Hard]: Bảng điều khiển lệnh trong game (Game Console)

Hard (20%)

Viết chương trình đọc liên tục từng dòng bằng getline. Dòng không bắt đầu bằng / là tin nhắn chat, in ra Ten: noi dung. Dòng bắt đầu bằng / là lệnh:

  • /heal n, /damage n: hồi / trừ máu (HP trong khoảng 0–100). n phải là số nguyên dương — tự viết hàm isNumber và toNumber để đổi chuỗi sang số.
  • /rename ten: đổi tên nhân vật (1–12 ký tự).
  • /shout noi dung: in nội dung viết HOA.
  • /status, /help, /quit. Lệnh lạ → báo lỗi.

Phân tích: Mọi lệnh có dạng lenh tham_so. Hàm getCommand cắt phần trước dấu cách đầu tiên, getArgument cắt phần sau. Đổi "123" thành số: mỗi bước value = value * 10 + (c - '0'), vì mã ASCII của '0'…'9' liên tiếp nhau.

game_console.cpp 
#include <iostream>
#include <string>
#include <cctype>

std::string toUpperStr(std::string s) {
    for (int i = 0; i < s.length(); i++) {
        s[i] = std::toupper(s[i]);
    }
    return s;
}

// Ten lenh: phan truoc khoang trang dau tien ("/heal 30" -> "/heal")
std::string getCommand(std::string line) {
    std::size_t pos = line.find(' ');
    if (pos == std::string::npos) return line;
    return line.substr(0, pos);
}

// Tham so: phan sau khoang trang dau tien ("/heal 30" -> "30")
std::string getArgument(std::string line) {
    std::size_t pos = line.find(' ');
    if (pos == std::string::npos) return "";
    return line.substr(pos + 1);
}

// Chuoi chi gom chu so, toi da 4 chu so (tranh tran so)
bool isNumber(std::string s) {
    if (s.length() == 0 || s.length() > 4) return false;
    for (int i = 0; i < s.length(); i++) {
        if (!std::isdigit(s[i])) return false;
    }
    return true;
}

// "123" -> 123: moi buoc nhan 10 roi cong chu so tiep theo
int toNumber(std::string s) {
    int value = 0;
    for (int i = 0; i < s.length(); i++) {
        value = value * 10 + (s[i] - '0');
    }
    return value;
}

int main() {
    const int MAX_HP = 100;
    std::string heroName = "Hero";
    int hp = MAX_HP;
    std::string line;

    std::cout << "=== GAME CONSOLE === (go /help de xem lenh)\n";
    while (true) {
        std::cout << "> ";
        if (!std::getline(std::cin, line)) break;   // Het du lieu nhap -> thoat
        if (line.length() == 0) continue;

        if (line[0] != '/') {                       // Khong phai lenh -> chat thuong
            std::cout << heroName << ": " << line << "\n";
            continue;
        }

        std::string cmd = getCommand(line);
        std::string arg = getArgument(line);

        if (cmd == "/quit") {
            std::cout << "Tam biet!\n";
            break;
        } else if (cmd == "/help") {
            std::cout << "/heal n | /damage n | /rename ten | /shout noi dung | /status | /quit\n";
        } else if (cmd == "/heal" || cmd == "/damage") {
            if (!isNumber(arg)) {
                std::cout << "Loi: can mot so nguyen duong (toi da 4 chu so)\n";
                continue;
            }
            int amount = toNumber(arg);
            if (cmd == "/heal") {
                hp += amount;
                if (hp > MAX_HP) hp = MAX_HP;
            } else {
                hp -= amount;
                if (hp < 0) hp = 0;
            }
            std::cout << heroName << " HP: " << hp << "/" << MAX_HP << "\n";
            if (hp == 0) std::cout << heroName << " da guc nga!\n";
        } else if (cmd == "/rename") {
            if (arg.length() == 0 || arg.length() > 12) {
                std::cout << "Ten phai co tu 1 den 12 ky tu\n";
            } else {
                heroName = arg;
                std::cout << "Doi ten thanh cong: " << heroName << "\n";
            }
        } else if (cmd == "/shout") {
            std::cout << heroName << " HET LON: " << toUpperStr(arg) << "!!!\n";
        } else if (cmd == "/status") {
            std::cout << "Ten: " << heroName << " | HP: " << hp << "/" << MAX_HP << "\n";
        } else {
            std::cout << "Lenh khong hop le: " << cmd << " (go /help)\n";
        }
    }
    return 0;
}
💡 Kiểm thử: /damage 30 → HP 70; /heal 999 → HP 100 (không vượt max); /damage abc → báo lỗi; /heal (thiếu số) → báo lỗi; /rename Shadow Knight → tên có dấu cách vẫn được; /fly → lệnh không hợp lệ.

Bài 4 [Hard]: Dự án tổng hợp — Hệ thống quản lý & thống kê điểm học viên

Hard (20%)

Bài tập tổng hợp toàn bộ Giai đoạn 03 (hàm, mảng, Linear Search, Bubble Sort, chuỗi). Nhập danh sách tối đa 50 học viên gồm họ tên (có dấu cách) và điểm (0–100), lưu bằng 2 mảng song song names[] và scores[]. Viết menu lặp lại đến khi chọn 0:

  1. Bảng điểm: in STT, điểm, xếp loại (Giỏi ≥ 85, Khá ≥ 70, Trung bình ≥ 50, Yếu).
  2. Thống kê: điểm trung bình, cao nhất/thấp nhất kèm tên, số lượng từng xếp loại, tỉ lệ đạt.
  3. Tìm học viên: Linear Search theo tên, không phân biệt hoa thường, cho phép nhập một phần tên.
  4. Xếp hạng: Bubble Sort giảm dần theo điểm — khi đổi chỗ điểm phải đổi chỗ cả tên.
⚠️ Bẫy mảng song song: Nếu chỉ hoán đổi scores[j] mà quên hoán đổi names[j], tên và điểm sẽ bị lệch nhau. Ở Giai đoạn 04, struct sẽ gom tên và điểm vào một đối tượng để tránh lỗi này.

Thiết kế hàm: readInt (nhập an toàn) · grade · printTable · printStats · findByName (Linear Search) · sortByScore (Bubble Sort). Hàm main chỉ còn nhập liệu và điều phối menu.

student_manager.cpp 
#include <iostream>
#include <string>
#include <cctype>

const int MAX = 50;

// Doc mot so nguyen trong khoang [lo, hi], nhap sai thi nhap lai
int readInt(std::string prompt, int lo, int hi) {
    int x;
    while (true) {
        std::cout << prompt;
        if (std::cin >> x && x >= lo && x <= hi) {
            std::cin.ignore(1000, '\n');
            return x;
        }
        std::cin.clear();
        std::cin.ignore(1000, '\n');
        std::cout << "Gia tri khong hop le!\n";
    }
}

std::string grade(int s) {
    if (s >= 85) return "Gioi";
    if (s >= 70) return "Kha";
    if (s >= 50) return "Trung binh";
    return "Yeu";
}

void printTable(std::string names[], int scores[], int n) {
    std::cout << "\nSTT | Diem | Xep loai   | Ho ten\n";
    for (int i = 0; i < n; i++) {
        std::cout << i + 1 << "   | " << scores[i] << "   | " << grade(scores[i])
                  << " | " << names[i] << "\n";
    }
}

// Linear Search: tim theo ten (khong phan biet hoa thuong), tra ve chi so hoac -1
std::string toLowerStr(std::string s) {
    for (int i = 0; i < (int)s.length(); i++) s[i] = std::tolower(s[i]);
    return s;
}

int findByName(std::string names[], int n, std::string key) {
    key = toLowerStr(key);
    for (int i = 0; i < n; i++) {
        if (toLowerStr(names[i]).find(key) != std::string::npos) return i;
    }
    return -1;
}

// Bubble Sort giam dan theo diem, hoan doi ca ten de 2 mang luon khop chi so
void sortByScore(std::string names[], int scores[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (scores[j] < scores[j + 1]) {
                int t = scores[j]; scores[j] = scores[j + 1]; scores[j + 1] = t;
                std::string tn = names[j]; names[j] = names[j + 1]; names[j + 1] = tn;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

void printStats(std::string names[], int scores[], int n) {
    int sum = 0, maxI = 0, minI = 0;
    int cntGioi = 0, cntKha = 0, cntTB = 0, cntYeu = 0;
    for (int i = 0; i < n; i++) {
        sum += scores[i];
        if (scores[i] > scores[maxI]) maxI = i;
        if (scores[i] < scores[minI]) minI = i;
        std::string g = grade(scores[i]);
        if (g == "Gioi") cntGioi++;
        else if (g == "Kha") cntKha++;
        else if (g == "Trung binh") cntTB++;
        else cntYeu++;
    }
    std::cout << "\nDiem trung binh: " << (double)sum / n << "\n";
    std::cout << "Cao nhat: " << names[maxI] << " (" << scores[maxI] << ")\n";
    std::cout << "Thap nhat: " << names[minI] << " (" << scores[minI] << ")\n";
    std::cout << "Gioi: " << cntGioi << " | Kha: " << cntKha
              << " | TB: " << cntTB << " | Yeu: " << cntYeu << "\n";
    std::cout << "Ti le dat (>= 50): " << (n - cntYeu) * 100 / n << "%\n";
}

int main() {
    std::string names[MAX];
    int scores[MAX];
    int n = readInt("So hoc vien (1-50): ", 1, MAX);

    for (int i = 0; i < n; i++) {
        std::cout << "Ho ten hoc vien " << i + 1 << ": ";
        std::getline(std::cin, names[i]);
        scores[i] = readInt("Diem (0-100): ", 0, 100);
    }

    int choice;
    do {
        std::cout << "\n1. Bang diem  2. Thong ke  3. Tim hoc vien  4. Xep hang  0. Thoat\n";
        choice = readInt("Chon: ", 0, 4);
        switch (choice) {
            case 1: printTable(names, scores, n); break;
            case 2: printStats(names, scores, n); break;
            case 3: {
                std::string key;
                std::cout << "Nhap ten can tim: ";
                std::getline(std::cin, key);
                int pos = findByName(names, n, key);
                if (pos == -1) std::cout << "Khong tim thay!\n";
                else std::cout << names[pos] << ": " << scores[pos]
                               << " diem - " << grade(scores[pos]) << "\n";
                break;
            }
            case 4:
                sortByScore(names, scores, n);
                std::cout << "Da sap xep giam dan theo diem.";
                printTable(names, scores, n);
                break;
        }
    } while (choice != 0);
    return 0;
}
