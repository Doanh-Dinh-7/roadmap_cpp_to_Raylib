Tìm Kiếm Cơ Bản: Linear Search

Mục tiêu đầu ra: Cài đặt thuật toán tìm kiếm tuần tự dưới dạng hàm trả về chỉ số hoặc -1; biến thể tìm vị trí cuối, đếm số lần xuất hiện, liệt kê và tìm phần tử đầu tiên thỏa điều kiện — áp dụng cho túi đồ và danh sách kẻ địch trong game.

1. Lý thuyết cốt lõi (35 Phút)

1.1 Ý tưởng tìm kiếm tuần tự

Linear Search (tìm kiếm tuần tự / tuyến tính) là cách tìm đơn giản nhất: kiểm tra lần lượt từng phần tử từ đầu đến cuối, gặp phần tử cần tìm thì dừng và báo vị trí. Nếu đi hết mảng mà không thấy thì báo "không tìm thấy". Giống như bạn lục từng ô trong túi đồ để tìm bình máu.

📋 Các bước thuật toán — tìm target trong mảng arr có n phần tử:
  1. Cho i chạy từ 0 đến n - 1.
  2. Nếu arr[i] == target → trả về i ngay (dừng tìm).
  3. Nếu vòng lặp kết thúc mà chưa trả về → trả về -1.
Vì sao là -1? Vì chỉ số hợp lệ luôn ≥ 0, nên -1 là "giá trị canh gác" không bao giờ trùng với một vị trí thật.
linear_search.cpp 
#include <iostream>

// Tra ve chi so dau tien co gia tri target, hoac -1 neu khong co
int linearSearch(const int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            return i;              // Tim thay -> thoat ham ngay
        }
    }
    return -1;                  // Duyet het ma khong thay
}

int main() {
    const int N = 6;
    int enemyIds[N] = {304, 17, 88, 512, 17, 9};

    int pos = linearSearch(enemyIds, N, 17);
    if (pos != -1) {
        std::cout << "Ke dich 17 o vi tri " << pos << "\n";   // In 1
    } else {
        std::cout << "Khong tim thay!\n";
    }

    std::cout << linearSearch(enemyIds, N, 999) << "\n";   // In -1
    return 0;
}

1.2 Các biến thể thường gặp

Chỉ cần thay đổi một chút ở hướng duyệt, điều kiện hoặc hành động khi tìm thấy, ta có cả "họ" thuật toán tìm kiếm:

Biến thể Điểm khác biệt Trả về
Tìm vị trí đầu tiên Duyệt i = 0 → n-1, gặp là return i Chỉ số hoặc -1
Tìm vị trí cuối cùng Duyệt ngược i = n-1 → 0 Chỉ số hoặc -1
Kiểm tra có tồn tại Gặp là return true, hết vòng return false bool
Đếm số lần xuất hiện Không dừng sớm, gặp thì count++ Số lượng (≥ 0)
Liệt kê tất cả vị trí Không dừng sớm, gặp thì in i void (in ra màn hình)
Tìm theo điều kiện Thay arr[i] == target bằng điều kiện bất kỳ, ví dụ arr[i] < 30 Chỉ số hoặc -1
search_variants.cpp 
int findLast(const int arr[], int n, int target) {
    for (int i = n - 1; i >= 0; i--) {          // Duyet nguoc tu cuoi
        if (arr[i] == target) return i;
    }
    return -1;
}

bool contains(const int arr[], int n, int target) {
    return linearSearch(arr, n, target) != -1;  // Tai su dung ham co san
}

int countOf(const int arr[], int n, int target) {
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) count++;             // Khong return -> duyet het mang
    }
    return count;
}

int findFirstLowHp(const int hp[], int n, int limit) {
    for (int i = 0; i < n; i++) {
        if (hp[i] > 0 && hp[i] < limit) return i; // Con song va yeu mau
    }
    return -1;
}

1.3 Chi phí của Linear Search

Với mảng n phần tử: trường hợp tốt nhất phần tử nằm ngay ô đầu → 1 phép so sánh; trường hợp xấu nhất phần tử ở cuối hoặc không có → n phép so sánh. Số phép so sánh tăng tỉ lệ thuận với n; ở Buổi 30 ta sẽ gọi tên chính xác điều này là độ phức tạp O(n). Ưu điểm lớn: hoạt động trên mọi mảng, không cần mảng đã sắp xếp.

🎮 Mẹo tư duy Game: Linear Search xuất hiện liên tục trong game: "người chơi có chìa khóa vàng trong túi không?" (contains), "ô trống đầu tiên trong túi đồ ở đâu để nhặt vật phẩm?" (tìm phần tử bằng 0), "kẻ địch nào đang yếu máu để kết liễu?" (tìm theo điều kiện). Với vài chục phần tử, máy tính duyệt hết chỉ mất vài phần triệu giây — hoàn toàn đủ nhanh cho 60 khung hình mỗi giây.
⚠️ Lỗi thường gặp:
  • Đặt return -1 trong nhánh else bên trong vòng lặp: if (arr[i] == target) return i; else return -1; — hàm sẽ thoát ngay ở phần tử đầu tiên, chỉ kiểm tra đúng 1 ô! return -1 phải nằm sau vòng lặp.
  • Dùng kết quả mà không kiểm tra -1: arr[linearSearch(arr, n, x)] khi không tìm thấy sẽ thành arr[-1] → truy cập ngoài mảng.
  • Lỡ return trong hàm đếm: hàm đếm/liệt kê phải duyệt hết mảng, không được dừng sớm.
  • Nhầm chỉ số và số thứ tự: hàm trả về chỉ số từ 0; khi in cho người chơi nhớ cộng 1 nếu giao diện đánh số từ 1.

2. Bài tập trên lớp (55 Phút)

Bài 1: Tra cứu túi đồ

Trên lớp

Đề bài: Túi đồ 8 ô int bag[8] = {101, 0, 205, 101, 0, 330, 0, 101}; (0 là ô trống, 101 là Bình máu, 205 là Chìa khóa, 330 là Bom). Người chơi nhập mã vật phẩm cần tìm (nhập -1 để thoát). Với mỗi lần nhập, in: ô đầu tiên chứa vật phẩm (đánh số từ 1), số lượng vật phẩm đó, hoặc báo "Khong co trong tui". Cuối cùng in vị trí ô trống đầu tiên.

bag_lookup.cpp 
#include <iostream>

int linearSearch(const int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

int countOf(const int arr[], int n, int target) {
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) count++;
    }
    return count;
}

int main() {
    const int SIZE = 8;
    int bag[SIZE] = {101, 0, 205, 101, 0, 330, 0, 101};
    int code;

    while (true) {
        std::cout << "\nNhap ma vat pham (-1 de thoat): ";
        std::cin >> code;
        if (code == -1) break;
        if (code == 0) {
            std::cout << "Ma 0 la o trong, hay nhap ma vat pham.\n";
            continue;
        }

        int pos = linearSearch(bag, SIZE, code);
        if (pos == -1) {
            std::cout << "Khong co trong tui.\n";
        } else {
            std::cout << "Tim thay o o so " << pos + 1
                      << ", so luong: " << countOf(bag, SIZE, code) << "\n";
        }
    }

    int emptySlot = linearSearch(bag, SIZE, 0);   // Tim o trong = tim gia tri 0
    if (emptySlot == -1) {
        std::cout << "Tui da day!\n";
    } else {
        std::cout << "O trong dau tien: o so " << emptySlot + 1 << "\n";
    }
    return 0;
}

Bài 2: Radar tìm mục tiêu yếu máu

Trên lớp

Đề bài: Mảng int hp[10] chứa máu của 10 kẻ địch, sinh ngẫu nhiên từ 0 đến 100 (0 = đã chết). Viết các hàm: printAllBelow(hp, n, limit) liệt kê tất cả kẻ địch còn sống có máu dưới limit; countAlive(hp, n) đếm số kẻ địch còn sống; findFirstLowHp(hp, n, limit) trả về chỉ số mục tiêu đầu tiên để kết liễu. Người chơi nhập ngưỡng limit.

low_hp_radar.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

void printAllBelow(const int hp[], int n, int limit) {
    bool any = false;
    for (int i = 0; i < n; i++) {
        if (hp[i] > 0 && hp[i] < limit) {
            std::cout << "  Ke dich #" << i << " - HP " << hp[i] << "\n";
            any = true;
        }
    }
    if (!any) std::cout << "  (Khong co muc tieu nao)\n";
}

int countAlive(const int hp[], int n) {
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (hp[i] > 0) count++;
    }
    return count;
}

int findFirstLowHp(const int hp[], int n, int limit) {
    for (int i = 0; i < n; i++) {
        if (hp[i] > 0 && hp[i] < limit) return i;
    }
    return -1;
}

int main() {
    srand(time(0));
    const int N = 10;
    int hp[N];

    std::cout << "Radar: ";
    for (int i = 0; i < N; i++) {
        hp[i] = rand() % 101;                  // 0..100
        std::cout << hp[i] << " ";
    }
    std::cout << "\nCon song: " << countAlive(hp, N) << "/" << N << "\n";

    int limit;
    std::cout << "Nguong mau yeu: ";
    std::cin >> limit;

    std::cout << "Cac muc tieu yeu mau:\n";
    printAllBelow(hp, N, limit);

    int target = findFirstLowHp(hp, N, limit);
    if (target != -1) {
        std::cout << "Uu tien ket lieu ke dich #" << target << "\n";
    }
    return 0;
}
🎯 Câu hỏi thảo luận: Nếu muốn ưu tiên kẻ địch có máu thấp nhất (thay vì kẻ đầu tiên dưới ngưỡng), ta dùng thuật toán nào của Buổi 27? Gợi ý: tìm Min nhưng bỏ qua các phần tử bằng 0.

3. Bài tập về nhà (Tự luyện tập)

Ba bài dưới đây giúp bạn thành thạo các biến thể của tìm kiếm tuần tự:

Bài 1 [Easy]: Lần cuối cùng đạt điểm tuyệt đối

Easy (40%)

Nhập n (1–20) điểm của các màn chơi (thang 0–100). Viết hàm findFirst và findLast để in ra màn đầu tiên và màn cuối cùng đạt 100 điểm (đánh số màn từ 1). Nếu chưa từng đạt 100, in "Chua co man nao dat diem tuyet doi".

Gợi ý: Nếu findFirst trả về -1 thì chắc chắn findLast cũng trả về -1, chỉ cần kiểm tra một lần.

perfect_score.cpp 
#include <iostream>

int findFirst(const int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

int findLast(const int arr[], int n, int target) {
    for (int i = n - 1; i >= 0; i--) {
        if (arr[i] == target) return i;
    }
    return -1;
}

int main() {
    const int MAX = 20;
    int scores[MAX];
    int n;

    do {
        std::cout << "So man (1-20): ";
        std::cin >> n;
    } while (n < 1 || n > MAX);

    for (int i = 0; i < n; i++) {
        do {
            std::cout << "Diem man " << i + 1 << " (0-100): ";
            std::cin >> scores[i];
        } while (scores[i] < 0 || scores[i] > 100);
    }

    int first = findFirst(scores, n, 100);
    if (first == -1) {
        std::cout << "Chua co man nao dat diem tuyet doi\n";
    } else {
        int last = findLast(scores, n, 100);
        std::cout << "Lan dau dat 100: man " << first + 1 << "\n";
        std::cout << "Lan cuoi dat 100: man " << last + 1 << "\n";
    }
    return 0;
}

Bài 2 [Medium]: Quản lý túi đồ có menu

Medium (40%)

Túi đồ 6 ô, ban đầu trống hết (int bag[6] = {0};). Viết chương trình có menu lặp lại: 1 – Nhặt vật phẩm (nhập mã > 0, đặt vào ô trống đầu tiên; túi đầy thì báo lỗi); 2 – Vứt vật phẩm (nhập mã, xóa ô đầu tiên chứa mã đó về 0; không có thì báo lỗi); 3 – Xem túi; 0 – Thoát. Mọi thao tác tìm kiếm phải dùng chung một hàm linearSearch.

Ý tưởng then chốt: "Tìm ô trống" chính là linearSearch(bag, SIZE, 0); "tìm vật phẩm" là linearSearch(bag, SIZE, code). Một hàm phục vụ cả hai việc.

inventory_menu.cpp 
#include <iostream>

int linearSearch(const int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

void showBag(const int bag[], int n) {
    std::cout << "Tui do: ";
    for (int i = 0; i < n; i++) {
        if (bag[i] == 0) std::cout << "[ -- ] ";
        else             std::cout << "[" << bag[i] << "] ";
    }
    std::cout << "\n";
}

int main() {
    const int SIZE = 6;
    int bag[SIZE] = {0};
    int choice;

    do {
        std::cout << "\n1-Nhat  2-Vut  3-Xem  0-Thoat: ";
        std::cin >> choice;

        switch (choice) {
            case 1: {
                int slot = linearSearch(bag, SIZE, 0);   // O trong dau tien
                if (slot == -1) {
                    std::cout << "Tui da day!\n";
                    break;
                }
                int code;
                do {
                    std::cout << "Ma vat pham (> 0): ";
                    std::cin >> code;
                } while (code <= 0);
                bag[slot] = code;
                std::cout << "Da cat vao o " << slot + 1 << "\n";
                break;
            }
            case 2: {
                int code;
                std::cout << "Ma vat pham can vut: ";
                std::cin >> code;
                int pos = -1;
                if (code > 0) pos = linearSearch(bag, SIZE, code);  // Ma 0 la o trong
                if (pos == -1) {
                    std::cout << "Khong co vat pham nay!\n";
                } else {
                    bag[pos] = 0;
                    std::cout << "Da vut vat pham o o " << pos + 1 << "\n";
                }
                break;
            }
            case 3:
                showBag(bag, SIZE);
                break;
            case 0:
                std::cout << "Tam biet!\n";
                break;
            default:
                std::cout << "Lua chon khong hop le!\n";
        }
    } while (choice != 0);
    return 0;
}
Vì sao case có cặp ngoặc { }? Khi khai báo biến mới (slot, code, pos) bên trong một case, cần bọc trong khối { } để giới hạn phạm vi biến (Buổi 25), nếu không trình biên dịch sẽ báo lỗi "jump to case label".

Bài 3 [Hard]: Săn kho báu trên bản đồ 1 chiều

Hard (20%)

Bản đồ có 20 ô (đánh số 1–20). Máy giấu ngẫu nhiên 3 kho báu ở 3 ô khác nhau — lưu vị trí trong mảng int treasure[3], dùng Linear Search để đảm bảo không sinh trùng. Người chơi có 8 lượt đào: mỗi lượt nhập một ô (1–20, không được đào lại ô đã đào — lưu các ô đã đào trong mảng dug[8]). Nếu trúng kho báu → +1 kho báu tìm được; nếu không → in khoảng cách tới kho báu chưa tìm thấy gần nhất. Thắng khi tìm đủ 3 kho báu; hết lượt thì thua và in vị trí các kho báu.

Gợi ý: Khi đào trúng, đánh dấu kho báu đó đã tìm thấy bằng cách gán treasure[k] = -1 (vị trí không tồn tại). Khi tính khoảng cách gần nhất, bỏ qua các phần tử bằng -1.
treasure_hunt.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

const int MAP_SIZE = 20;
const int NUM_TREASURE = 3;
const int MAX_TURNS = 8;

int linearSearch(const int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

// Khoang cach toi kho bau chua tim thay gan nhat (bo qua o = -1)
int nearestDistance(const int treasure[], int n, int cell) {
    int best = -1;
    for (int i = 0; i < n; i++) {
        if (treasure[i] == -1) continue;
        int d = treasure[i] - cell;
        if (d < 0) d = -d;
        if (best == -1 || d < best) best = d;
    }
    return best;
}

int main() {
    srand(time(0));
    int treasure[NUM_TREASURE];
    int original[NUM_TREASURE];        // Ban sao de in dap an cuoi game

    // 1. Giau kho bau, dung Linear Search de tranh trung vi tri
    int placed = 0;
    while (placed < NUM_TREASURE) {
        int cell = rand() % MAP_SIZE + 1;
        if (linearSearch(treasure, placed, cell) == -1) {  // Chi tim trong phan da dat
            treasure[placed] = cell;
            original[placed] = cell;
            placed++;
        }
    }

    int dug[MAX_TURNS];
    int turns = 0;
    int found = 0;
    std::cout << "=== SAN KHO BAU ===\nCo " << NUM_TREASURE << " kho bau trong "
              << MAP_SIZE << " o. Ban co " << MAX_TURNS << " luot dao.\n";

    // 2. Vong choi
    while (turns < MAX_TURNS && found < NUM_TREASURE) {
        int cell;
        while (true) {
            std::cout << "\n[Luot " << turns + 1 << "/" << MAX_TURNS << "] Dao o (1-20): ";
            std::cin >> cell;
            if (cell < 1 || cell > MAP_SIZE) {
                std::cout << "O khong ton tai!\n";
            } else if (linearSearch(dug, turns, cell) != -1) {
                std::cout << "O nay da dao roi!\n";
            } else {
                break;
            }
        }
        dug[turns] = cell;
        turns++;

        int k = linearSearch(treasure, NUM_TREASURE, cell);
        if (k != -1) {
            treasure[k] = -1;                        // Danh dau da tim thay
            found++;
            std::cout << "KHO BAU! (" << found << "/" << NUM_TREASURE << ")\n";
        } else {
            std::cout << "Trong rong. Kho bau gan nhat cach "
                      << nearestDistance(treasure, NUM_TREASURE, cell) << " o.\n";
        }
    }

    // 3. Ket qua
    if (found == NUM_TREASURE) {
        std::cout << "\nCHIEN THANG! Tim du kho bau sau " << turns << " luot.\n";
    } else {
        std::cout << "\nHET LUOT! Kho bau nam o cac o: ";
        for (int i = 0; i < NUM_TREASURE; i++) std::cout << original[i] << " ";
        std::cout << "\n";
    }
    return 0;
}
💡 Mẹo hay: Lời gọi linearSearch(treasure, placed, cell) chỉ tìm trong placed phần tử đầu — phần đã được gán giá trị. Truyền n nhỏ hơn kích thước thật là kỹ thuật rất hay dùng để làm việc với "phần đã dùng" của mảng, đồng thời tránh đọc các ô chưa khởi tạo.
