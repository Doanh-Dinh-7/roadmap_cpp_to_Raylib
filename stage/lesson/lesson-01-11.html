Mini Project: Number Guessing Game (Game Đoán Số Console)

Mục tiêu đầu ra: Tự tay hoàn thiện một game tương tác hoàn chỉnh trên Console C++, ứng dụng sinh số ngẫu nhiên RNG và cơ chế phản hồi gợi ý.

Danh sách buổi Sang Giai đoạn 02 →

1. Đề tài & Quy trình thiết kế Game (20 Phút)

Chúc mừng bạn đã đến buổi học cuối cùng của Giai đoạn 01! Trong buổi học này, chúng ta sẽ kết nối tất cả các mảnh ghép: Nhập xuất dữ liệu $\rightarrow$ Biến & Ép kiểu $\rightarrow$ Toán tử so sánh $\rightarrow$ Cấu trúc rẽ nhánh để xây dựng một game kinh điển: Đoán số ngẫu nhiên có phản hồi gợi ý.

1.1 Luật chơi (Game Rules)

  1. Hệ thống máy tính bí mật sinh một số nguyên ngẫu nhiên bí mật nằm trong đoạn từ 1 đến 100.
  2. Người chơi quan sát giao diện giới thiệu và nhập vào con số mà mình phán đoán.
  3. Chương trình so sánh số người chơi với số bí mật:
    • Nếu guess > secret: Thông báo "Quá LỚN! Con số bí mật nhỏ hơn số bạn đoán."
    • Nếu guess < secret: Thông báo "Quá NHỎ! Con số bí mật lớn hơn số bạn đoán."
    • Nếu guess == secret: Bùng nổ lời chúc mừng chiến thắng!

1.2 Kỹ thuật sinh số ngẫu nhiên trong C++

Để máy tính tạo ra một số bí mật bất ngờ mỗi lần chơi, chúng ta dùng hàm rand() trong thư viện <cstdlib> kết hợp với hạt giống thời gian srand(time(nullptr)) trong thư viện <ctime>:

rng_example.cpp 
#include <iostream>
#include <cstdlib> // Chứa rand() và srand()
#include <ctime>   // Chứa hàm time()

int main() {
    // Khởi tạo hạt giống ngẫu nhiên theo thời gian thực hiện tại
    srand(static_cast<unsigned int>(time(nullptr)));

    // Công thức sinh số ngẫu nhiên trong khoảng [min, max]:
    // rand() % (max - min + 1) + min
    int secret = rand() % 100 + 1; // Khoảng [1, 100]

    std::cout << "Số ngẫu nhiên tạo ra: " << secret << std::endl;
    return 0;
}
💡 Giải thích toán học về phép chia dư %:
Bất kỳ số nguyên nào chia dư cho 100 cũng chỉ có thể cho ra kết quả từ 0 đến 99. Khi cộng thêm 1, ta sẽ đưa miền giá trị về chính xác đoạn từ 1 đến 100!

2. Triển khai Mini Project tại lớp (45 Phút)

Học viên cùng giảng viên xây dựng toàn bộ mã nguồn của trò chơi trong file main.cpp:

Source code hoàn chỉnh: Guess Number Game v1.0

Mini Project
Ví dụ Input / Output Gameplay 
Output:

      GAME ĐOÁN SỐ MAY MẮN (1 - 100)     
=========================================
Máy tính đã nghĩ ra một số bí mật!
Hãy nhập con số bạn dự đoán:

75

Output:
-----------------------------------------
❌ TIẾC QUÁ! Số bạn đoán QUÁ LỚN.
Gợi ý: Số bí mật nhỏ hơn 75.
Số bí mật thực tế là: 42
=========================================
guess_game.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    // 1. Khởi tạo RNG
    srand(static_cast<unsigned int>(time(nullptr)));
    const int SECRET_NUMBER = rand() % 100 + 1;
    int playerGuess;

    // 2. Banner chào mừng
    std::cout << "=========================================\n";
    std::cout << "      GAME ĐOÁN SỐ MAY MẮN (1 - 100)     \n";
    std::cout << "=========================================\n";
    std::cout << "Máy tính đã nghĩ ra một số bí mật!\n";
    std::cout << "Hãy nhập con số bạn dự đoán: ";
    std::cin >> playerGuess;

    // 3. Xử lý logic và phản hồi gợi ý
    std::cout << "\n-----------------------------------------\n";
    if (playerGuess == SECRET_NUMBER) {
        std::cout << "🎉 XUẤT SẮC! BẠN ĐÃ ĐOÁN CHÍNH XÁC!\n";
        std::cout << "Số bí mật chính là: " << SECRET_NUMBER << "\n";
    } else if (playerGuess > SECRET_NUMBER) {
        std::cout << "❌ TIẾC QUÁ! Số bạn đoán QUÁ LỚN.\n";
        std::cout << "Gợi ý: Số bí mật nhỏ hơn " << playerGuess << ".\n";
        std::cout << "Số bí mật thực tế là: " << SECRET_NUMBER << "\n";
    } else {
        std::cout << "❌ TIẾC QUÁ! Số bạn đoán QUÁ NHỎ.\n";
        std::cout << "Gợi ý: Số bí mật lớn hơn " << playerGuess << ".\n";
        std::cout << "Số bí mật thực tế là: " << SECRET_NUMBER << "\n";
    }
    std::cout << "=========================================\n";

    return 0;
}

3. Bài tập nâng cấp tính năng (Homework)

Học viên mở rộng project Guess Number Game theo 3 mức độ:

Nâng cấp 1 [Easy]: Manh mối gợi ý Chẵn/Lẻ

Easy (40%)

Trước khi người chơi nhập số, hãy in ra một manh mối: "Manh mối: Số bí mật là một số CHẴN" hoặc "Manh mối: Số bí mật là một số LẺ" để người chơi có thêm cơ sở phán đoán.

Ví dụ Output Manh mối 
Output:
💡 Gợi ý đầu tiên: Con số bí mật là một số CHẴN!
hint_feature.cpp 
if (SECRET_NUMBER % 2 == 0) {
    std::cout << "💡 Gợi ý đầu tiên: Con số bí mật là một số CHẴN!\n";
} else {
    std::cout << "💡 Gợi ý đầu tiên: Con số bí mật là một số LẺ!\n";
}

Nâng cấp 2 [Medium]: Hệ thống tính khoảng cách sai lệch (Near Miss)

Medium (40%)

Nếu người chơi đoán sai, hãy tính khoảng cách lệch diff = abs(playerGuess - SECRET_NUMBER). Nếu diff <= 5, in thêm thông báo cổ vũ: "Ôi bạn ơi, bạn đoán SUÝT TRÚNG rồi! Chỉ lệch trong vòng 5 đơn vị!".

Ví dụ Output Cảnh báo 
Output:
🔥 NÓNG RỰC! Bạn đoán cực kỳ sát rồi (lệch không quá 5 đơn vị)!

Lưu ý: Sử dụng hàm abs(x) trong thư viện <cmath> để lấy giá trị tuyệt đối của hiệu số.

near_miss.cpp 
#include <cmath> // Chứa hàm abs()

int diff = abs(playerGuess - SECRET_NUMBER);
if (diff > 0 && diff <= 5) {
    std::cout << "🔥 NÓNG RỰC! Bạn đoán cực kỳ sát rồi (lệch không quá 5 đơn vị)!\n";
}

Nâng cấp 3 [Hard]: Tùy chọn 3 mức độ khó (Difficulty Selector)

Hard (20%)

Trước khi bắt đầu, cho người chơi chọn độ khó:
1. Dễ (Đoán số từ 1 đến 20)
2. Trung bình (Đoán số từ 1 đến 50)
3. Khó (Đoán số từ 1 đến 100)
Áp dụng câu lệnh switch(choice) hoặc if - else if để sinh miền số tương ứng.

Ví dụ Input / Output Độ khó 
Input:
Chọn độ khó:
[1] Dễ (1-20)
[2] Vừa (1-50)
[3] Khó (1-100)
Lựa chọn của bạn: 2

Output:
Đã thiết lập số bí mật trong khoảng 1 đến 50!
difficulty_selector.cpp 
int modeChoice;
int maxRange = 100;

std::cout << "Chọn độ khó:\n[1] Dễ (1-20)\n[2] Vừa (1-50)\n[3] Khó (1-100)\nLựa chọn của bạn: ";
std::cin >> modeChoice;

switch (modeChoice) {
    case 1:
        maxRange = 20;
        break;
    case 2:
        maxRange = 50;
        break;
    default:
        maxRange = 100;
        break;
}

int secret = rand() % maxRange + 1;
std::cout << "Đã thiết lập số bí mật trong khoảng 1 đến " << maxRange << "!\n";
