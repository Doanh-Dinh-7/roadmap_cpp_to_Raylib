Cấu Trúc Rẽ Nhánh If và If-Else Trong C++

Mục tiêu đầu ra: Nắm vững cú pháp ra quyết định điều kiện, xử lý tình huống máu nhân vật (HP), phân định Game Over và tính toán va chạm căn bản.

1. Lý thuyết cốt lõi (20 Phút)

Trong mọi trò chơi điện tử, các quyết định xảy ra liên tục trong từng frame: Nếu nhân vật rơi xuống vực $\rightarrow$ trừ 1 mạng; nếu nhặt được bình máu $\rightarrow$ tăng HP; nếu boss hết máu $\rightarrow$ chiến thắng màn chơi.

1.1 Cú pháp câu lệnh `if` khuyết

Khối lệnh chỉ được thực thi khi biểu thức điều kiện bên trong dấu ngoặc tròn trả về giá trị true (khác 0):

Cú pháp if khuyết 
if (điều_kiện) {
    // Khối lệnh chỉ chạy khi điều_kiện đúng (true)
}

1.2 Cú pháp câu lệnh `if-else` đầy đủ

Khi muốn xử lý cả 2 kịch bản loại trừ lẫn nhau (ĐÚNG làm việc A, SAI làm việc B):

Cú pháp if-else 
#include <iostream>

int main() {
    int playerHP = 0;

    if (playerHP > 0) {
        std::cout << "Chiến binh vẫn còn sống! HP hiện tại: " << playerHP << std::endl;
    } else {
        std::cout << "GAME OVER! Bạn đã bị tiêu diệt." << std::endl;
    }

    return 0;
}
⚠️ Lỗi kinh điển của người mới: Nhầm = và ==!
Toán tử == là so sánh bằng. Toán tử = là phép gán.
Nếu viết if (hp = 0) thì chương trình sẽ gán hp = 0 và biểu thức điều kiện nhận giá trị 0 (tương đương false)! Hãy luôn kiểm tra kỹ dấu bằng.

2. Thực hành tại lớp — Live Coding (45 Phút)

Thực hành 01: Hệ thống kiểm tra nhặt thuốc trị thương (HP Potion)

Easy

Nhập vào máu hiện tại của nhân vật (currentHP) và mức máu tối đa cho phép (maxHP = 100). Nếu nhân vật nhặt được bình thuốc trị thương hồi phục +30 HP:

  • Nếu sau khi cộng máu vượt quá maxHP, hãy giới hạn (clamp) máu về đúng 100 và in thông báo "Máu đã hồi phục tối đa!".
  • Ngược lại, in ra lượng máu mới sau khi hồi phục.
Ví dụ Input / Output 
Input:
Nhập lượng máu hiện tại (0 - 100): 85

Output:
[THÔNG BÁO] Hồi máu thành công! Máu đã đạt mức tối đa: 100 HP
heal_potion.cpp 
#include <iostream>

int main() {
    const int MAX_HP = 100;
    int currentHP;

    std::cout << "Nhập lượng máu hiện tại (0 - 100): ";
    std::cin >> currentHP;

    // Nhặt bình máu +30 HP
    currentHP = currentHP + 30;

    if (currentHP >= MAX_HP) {
        currentHP = MAX_HP;
        std::cout << "[THÔNG BÁO] Hồi máu thành công! Máu đã đạt mức tối đa: " << currentHP << " HP\n";
    } else {
        std::cout << "[THÔNG BÁO] Hồi máu thành công! Máu hiện tại: " << currentHP << " HP\n";
    }

    return 0;
}

3. Bài tập về nhà (3 Cấp độ)

Bài 1 [Easy]: Kiểm tra số chẵn hay lẻ (Xác định lượt đi Game Cờ)

Easy (40%)

Nhập vào số thứ tự lượt chơi turnNumber (số nguyên dương). Nếu là lượt chẵn thì in "Lượt của Người chơi 2 (O)", nếu là lượt lẻ thì in "Lượt của Người chơi 1 (X)".

Ví dụ Input / Output 
Input:
Nhập số lượt chơi: 4

Output:
Lượt của Người chơi 2 (O)

Gợi ý: Số chẵn là số chia lấy dư cho 2 bằng 0 (turnNumber % 2 == 0).

solution_turn.cpp 
#include <iostream>

int main() {
    int turnNumber;
    std::cout << "Nhập số lượt chơi: ";
    std::cin >> turnNumber;

    if (turnNumber % 2 == 0) {
        std::cout << "Lượt của Người chơi 2 (O)\n";
    } else {
        std::cout << "Lượt của Người chơi 1 (X)\n";
    }
    return 0;
}

Bài 2 [Medium]: Hệ thống tính sát thương chí mạng (Critical Damage)

Medium (40%)

Nhập vào lượng sát thương cơ bản (baseDamage) và tỷ lệ chí mạng (critRoll từ 1 đến 100). Nếu critRoll >= 75 thì tính là đòn đánh chí mạng (Sát thương x2), ngược lại chỉ gây sát thương bình thường.

Ví dụ Input / Output 
Input:
Nhập sát thương cơ bản: 50
Nhập chỉ số xúc xắc chí mạng (1-100): 80

Output:
💥 CHÍ MẠNG (CRITICAL HIT)! Sát thương gây ra: 100
solution_crit.cpp 
#include <iostream>

int main() {
    float baseDamage;
    int critRoll;

    std::cout << "Nhập sát thương cơ bản: ";
    std::cin >> baseDamage;
    std::cout << "Nhập chỉ số xúc xắc chí mạng (1-100): ";
    std::cin >> critRoll;

    if (critRoll >= 75) {
        float finalDamage = baseDamage * 2.0f;
        std::cout << "💥 CHÍ MẠNG (CRITICAL HIT)! Sát thương gây ra: " << finalDamage << "\n";
    } else {
        std::cout << "Đòn đánh thường. Sát thương gây ra: " << baseDamage << "\n";
    }

    return 0;
}

Bài 3 [Hard]: Kiểm tra va chạm biên màn hình Game 1D

Hard (20%)

Màn hình game có bề rộng từ tọa độ X = 0 đến X = 800. Nhân vật có kích thước bán kính radius = 20 và tọa độ tâm playerX. Viết chương trình kiểm tra:

  • Nếu mép trái nhân vật (playerX - radius <= 0) $\rightarrow$ In "Chạm biên trái màn hình!"
  • Nếu mép phải nhân vật (playerX + radius >= 800) $\rightarrow$ In "Chạm biên phải màn hình!"
  • Nếu nằm an toàn trong màn hình $\rightarrow$ In "Vị trí hợp lệ, nhân vật đang di chuyển bình thường."
Ví dụ Input / Output 
Input:
Nhập tọa độ tâm X của nhân vật: 15

Output:
⚠️ Chạm biên trái màn hình!
collision_1d.cpp 
#include <iostream>

int main() {
    const int SCREEN_WIDTH = 800;
    const int RADIUS = 20;
    int playerX;

    std::cout << "Nhập tọa độ tâm X của nhân vật: ";
    std::cin >> playerX;

    if (playerX - RADIUS <= 0) {
        std::cout << "⚠️ Chạm biên trái màn hình!\n";
    } else if (playerX + RADIUS >= SCREEN_WIDTH) {
        std::cout << "⚠️ Chạm biên phải màn hình!\n";
    } else {
        std::cout << "✓ Vị trí hợp lệ, nhân vật đang di chuyển bình thường.\n";
    }

    return 0;
}
