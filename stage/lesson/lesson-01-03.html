Biến và Các Kiểu Dữ Liệu Cơ Bản Trong C++

Mục tiêu đầu ra: Hiểu rõ cơ chế cấp phát ô nhớ RAM, chọn đúng kiểu dữ liệu tối ưu dung lượng và tuân thủ chuẩn đặt tên biến trong lập trình game.

1. Lý thuyết cốt lõi (20 Phút)

Trong máy tính, Biến (Variable) là một định danh đại diện cho một ô nhớ trên RAM. Khi bạn khai báo một biến, hệ điều hành sẽ trích ra một lượng byte bộ nhớ nhất định để cất giữ giá trị đó.

1.1 Bảng kiểu dữ liệu nguyên thủy thường dùng trong Game C++

Kiểu dữ liệu Kích thước Miền giá trị đại diện Ví dụ áp dụng trong Game
int 4 bytes -2.1 tỷ đến +2.1 tỷ Máu (HP), Điểm số (Score), Tiền vàng
float 4 bytes Số thực (chính xác ~7 chữ số) Tọa độ X, Y; Vận tốc vx, vy; Góc quay
double 8 bytes Số thực kép (chính xác ~15 chữ số) Vật lý thiên văn, giả lập độ chính xác cao
char 1 byte 1 ký tự ASCII ('A', '9') Phím điều khiển ('W', 'S', 'A', 'D')
bool 1 byte true (1) hoặc false (0) Trạng thái: isJumping, isAlive

1.2 Quy tắc đặt tên biến chuẩn trong Game Dev

  • Tên biến chỉ gồm chữ cái, chữ số và dấu gạch dưới _. Không được bắt đầu bằng chữ số.
  • C++ phân biệt chữ hoa và chữ thường: score khác với Score.
  • Áp dụng quy tắc camelCase: Từ đầu viết thường, các từ sau viết hoa chữ cái đầu (Ví dụ: playerSpeed, enemyAttackDamage).
  • Với biến boolean, luôn bắt đầu bằng tiền tố trạng thái: isGrounded, hasKey, canShoot.

2. Thực hành tại lớp — Live Coding (45 Phút)

Thực hành: Khai báo và in trạng thái đối tượng Player 2D

Easy

Khai báo các biến đại diện cho nhân vật: Tọa độ posX = 120.5f, posY = 300.0f, Vận tốc speed = 5.5f, Máu health = 100, Trạng thái isAlive = true và Phím di chuyển đang nhấn inputKey = 'D'.

Ví dụ Output 
Output:
=== TRẠNG THÁI PLAYER 2D ===
Tọa độ: (120.5, 300)
Vận tốc: 5.5 px/frame
Máu: 100 HP
Phím đang nhấn: D
Còn sống: ĐANG SỐNG
player_state.cpp 
#include <iostream>

int main() {
    // Khai báo biến với các kiểu dữ liệu thích hợp
    float posX = 120.5f;
    float posY = 300.0f;
    float speed = 5.5f;
    int health = 100;
    bool isAlive = true;
    char inputKey = 'D';

    std::cout << "=== TRẠNG THÁI PLAYER 2D ===\n";
    std::cout << "Tọa độ: (" << posX << ", " << posY << ")\n";
    std::cout << "Vận tốc: " << speed << " px/frame\n";
    std::cout << "Máu: " << health << " HP\n";
    std::cout << "Phím đang nhấn: " << inputKey << "\n";
    std::cout << "Còn sống: " << (isAlive ? "ĐANG SỐNG" : "ĐÃ CHẾT") << "\n";

    return 0;
}

3. Bài tập về nhà (3 Cấp độ)

Bài 1 [Easy]: Khám phá kích thước bộ nhớ với toán tử sizeof()

Easy (40%)

Sử dụng toán tử sizeof() để in ra số byte thực tế mà máy tính của bạn cấp phát cho các kiểu: int, float, double, char, bool và long long.

Ví dụ Output 
Output:
Kích thước int: 4 bytes
Kích thước float: 4 bytes
Kích thước double: 8 bytes
Kích thước char: 1 byte
Kích thước bool: 1 byte
Kích thước long long: 8 bytes
sizeof_demo.cpp 
#include <iostream>

int main() {
    std::cout << "Kích thước int: " << sizeof(int) << " bytes\n";
    std::cout << "Kích thước float: " << sizeof(float) << " bytes\n";
    std::cout << "Kích thước double: " << sizeof(double) << " bytes\n";
    std::cout << "Kích thước char: " << sizeof(char) << " byte\n";
    std::cout << "Kích thước bool: " << sizeof(bool) << " byte\n";
    std::cout << "Kích thước long long: " << sizeof(long long) << " bytes\n";
    return 0;
}

Bài 2 [Medium]: Hoán đổi 2 trang bị giữa Tay Trái và Tay Phải (Swap Variables)

Medium (40%)

Nhập vào mã định danh của 2 vũ khí leftHand = 101 (Kiếm) và rightHand = 205 (Khiên). Hãy thực hiện thuật toán hoán vị sử dụng một biến tạm temp để chuyển Kiếm sang tay phải và Khiên sang tay trái.

Ví dụ Input / Output 
Input:
Nhập ID vũ khí tay trái: 101
Nhập ID vũ khí tay phải: 205

Output:
=== SAU KHI ĐỔI TAY ===
Tay trái đang cầm vũ khí: 205
Tay phải đang cầm vũ khí: 101
swap_weapons.cpp 
#include <iostream>

int main() {
    int leftHand, rightHand;
    std::cout << "Nhập ID vũ khí tay trái: ";
    std::cin >> leftHand;
    std::cout << "Nhập ID vũ khí tay phải: ";
    std::cin >> rightHand;

    // Thuật toán tráo đổi bằng biến tạm
    int temp = leftHand;
    leftHand = rightHand;
    rightHand = temp;

    std::cout << "\n=== SAU KHI ĐỔI TAY ===\n";
    std::cout << "Tay trái đang cầm vũ khí: " << leftHand << "\n";
    std::cout << "Tay phải đang cầm vũ khí: " << rightHand << "\n";

    return 0;
}

Bài 3 [Hard]: Tính toán chỉ số sau khi cường hóa trang bị

Hard (20%)

Vũ khí ban đầu có sát thương cơ bản baseAtk = 50. Nhập cấp độ cường hóa level (1 đến 15) và bậc phẩm chất rarityMultiplier = 1.25f. Mỗi cấp cường hóa tăng thêm 8% sát thương cơ bản. Tính sát thương cuối cùng theo công thức: finalAtk = (baseAtk + baseAtk * 0.08f * level) * rarityMultiplier.

Ví dụ Input / Output 
Input:
Nhập lực công cơ bản của vũ khí: 50
Nhập cấp độ cường hóa (+): 10

Output:
Lực chiến sau cường hóa (+ 10): 112.5 DMG
upgrade_weapon.cpp 
#include <iostream>

int main() {
    float baseAtk;
    int upgradeLevel;
    const float RARITY_MULTIPLIER = 1.25f;

    std::cout << "Nhập lực công cơ bản của vũ khí: ";
    std::cin >> baseAtk;
    std::cout << "Nhập cấp độ cường hóa (+): ";
    std::cin >> upgradeLevel;

    float finalAtk = (baseAtk + baseAtk * 0.08f * upgradeLevel) * RARITY_MULTIPLIER;

    std::cout << "\nLực chiến sau cường hóa (+ " << upgradeLevel << "): " << finalAtk << " DMG\n";
    return 0;
}
