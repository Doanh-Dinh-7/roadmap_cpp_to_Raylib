Cấu Trúc Chương Trình C++, Mô Hình IPO & Nhập Xuất Dữ Liệu

Mục tiêu đầu ra: Hiểu sâu mô hình IPO (Input - Process - Output), sử dụng thành thạo std::cin và std::cout để tương tác với người dùng qua console.

1. Lý thuyết cốt lõi (20 Phút)

Hầu như mọi phần mềm hoặc game trên thế giới đều hoạt động theo một vòng tuần hoàn gồm 3 bước cơ bản được gọi là Mô hình IPO:

1. INPUT

Nhận dữ liệu từ người chơi: bấm phím, click chuột, nhập số từ bàn phím.

2. PROCESS

CPU xử lý thuật toán: tính toán tọa độ, trừ máu, kiểm tra va chạm.

3. OUTPUT

Xuất kết quả: in chữ ra console, vẽ hình ảnh ra màn hình, phát âm thanh.

1.1 Nhập dữ liệu với `std::cin`

Đối tượng std::cin (Console Input) nằm trong thư viện <iostream>, sử dụng toán tử trích xuất >> để đọc dữ liệu người dùng gõ từ bàn phím và lưu vào biến.

cin_example.cpp 
#include <iostream>

int main() {
    int playerLevel;

    // Hướng dẫn người dùng nhập dữ liệu
    std::cout << "Nhập level hiện tại của nhân vật: ";
    std::cin >> playerLevel;

    // Xử lý và xuất kết quả
    std::cout << "Chào mừng Chiến binh Level " << playerLevel << " gia nhập thế giới!\n";

    return 0;
}
🎮 Mẹo phân biệt hướng mũi tên:
- Xuất ra màn hình: std::cout << du_lieu (Mũi tên chĩa ra màn hình).
- Nhập từ bàn phím: std::cin >> bien_chua (Mũi tên chĩa vào biến để nhồi dữ liệu vào).

2. Thực hành tại lớp — Live Coding (45 Phút)

Thực hành: Tạo bảng thông số nhân vật RPG (Character Stat Sheet)

Easy

Viết chương trình yêu cầu người chơi nhập vào: Số lượng máu ban đầu (int hp), Tốc độ di chuyển (float speed) và Số lượng vàng đang có (int gold). Sau đó in ra bảng thông số tổng kết theo định dạng đẹp mắt.

Ví dụ Input / Output 
Input:
Nhập lượng máu (HP): 100
Nhập tốc độ chạy (Speed): 5.5
Nhập số vàng ban đầu (Gold): 250

Output:
============================
   THÔNG SỐ CHIẾN BINH      
============================
❤️  Máu (HP)    : 100
⚡ Tốc độ       : 5.5 pixel/s
💰 Tiền vàng    : 250 Gold
============================
character_sheet.cpp 
#include <iostream>

int main() {
    int hp;
    float speed;
    int gold;

    // INPUT: Nhận dữ liệu
    std::cout << "=== KHỞI TẠO NHÂN VẬT ===\n";
    std::cout << "Nhập lượng máu (HP): ";
    std::cin >> hp;
    std::cout << "Nhập tốc độ chạy (Speed): ";
    std::cin >> speed;
    std::cout << "Nhập số vàng ban đầu (Gold): ";
    std::cin >> gold;

    // OUTPUT: Xuất kết quả
    std::cout << "\n============================\n";
    std::cout << "   THÔNG SỐ CHIẾN BINH      \n";
    std::cout << "============================\n";
    std::cout << "❤️  Máu (HP)    : " << hp << "\n";
    std::cout << "⚡ Tốc độ       : " << speed << " pixel/s\n";
    std::cout << "💰 Tiền vàng    : " << gold << " Gold\n";
    std::cout << "============================\n";

    return 0;
}

3. Bài tập về nhà (3 Cấp độ)

Bài 1 [Easy]: Tính chu vi và diện tích khu vực bản đồ chữ nhật

Easy (40%)

Nhập vào chiều dài (length) và chiều rộng (width) của một khu vực bản đồ chữ nhật (kiểu số nguyên). Tính chu vi và diện tích của khu vực đó theo công thức: Chu vi = (dài + rộng) * 2 và Diện tích = dài * rộng.

Ví dụ Input / Output 
Input:
Nhập chiều dài: 20
Nhập chiều rộng: 10

Output:
Chu vi bản đồ: 60
Diện tích bản đồ: 200
rectangle_map.cpp 
#include <iostream>

int main() {
    int length, width;
    std::cout << "Nhập chiều dài: ";
    std::cin >> length;
    std::cout << "Nhập chiều rộng: ";
    std::cin >> width;

    int perimeter = (length + width) * 2;
    int area = length * width;

    std::cout << "Chu vi bản đồ: " << perimeter << "\n";
    std::cout << "Diện tích bản đồ: " << area << "\n";
    return 0;
}

Bài 2 [Medium]: Quy đổi tổng số giây sinh tồn thành Giờ : Phút : Giây

Medium (40%)

Trong game sinh tồn, thời gian sống sót của người chơi được tính bằng giây (totalSeconds). Hãy viết chương trình đổi tổng số giây nhập từ bàn phím thành định dạng Giờ : Phút : Giây (Ví dụ: 3665 giây = 1 giờ, 1 phút, 5 giây).

Ví dụ Input / Output 
Input:
Nhập tổng số giây sinh tồn: 3665

Output:
Thời gian sinh tồn: 1 giờ, 1 phút, 5 giây.

Gợi ý: 1 giờ = 3600 giây; 1 phút = 60 giây. Sử dụng phép chia lấy phần nguyên / và chia lấy dư %.

time_converter.cpp 
#include <iostream>

int main() {
    int totalSeconds;
    std::cout << "Nhập tổng số giây sinh tồn: ";
    std::cin >> totalSeconds;

    int hours = totalSeconds / 3600;
    int minutes = (totalSeconds % 3600) / 60;
    int seconds = totalSeconds % 60;

    std::cout << "Thời gian sinh tồn: " << hours << " giờ, " 
              << minutes << " phút, " << seconds << " giây.\n";
    return 0;
}

Bài 3 [Hard]: Tính toán phần thưởng kinh nghiệm (EXP Calculation)

Hard (20%)

Người chơi tiêu diệt được sl_slime con quái Slime (mỗi con cho 15 EXP), sl_goblin con Goblin (mỗi con cho 45 EXP) và sl_boss con Boss (mỗi con cho 300 EXP). Nhập số lượng tiêu diệt từng loại và tính:
1. Tổng điểm kinh nghiệm nhận được.
2. Cấp độ mới sau trận đấu biết rằng mỗi cấp độ cần đúng 100 EXP và cấp độ ban đầu là 1.

Ví dụ Input / Output 
Input:
Nhập số lượng Slime tiêu diệt: 4
Nhập số lượng Goblin tiêu diệt: 2
Nhập số lượng Boss tiêu diệt: 1

Output:
=== KẾT QUẢ TRẬN ĐẤU ===
Tổng kinh nghiệm: 450 EXP
Cấp độ mới      : Level 5
EXP dư cho cấp sau: 50 / 100
exp_calculator.cpp 
#include <iostream>

int main() {
    int slSlime, slGoblin, slBoss;
    std::cout << "Nhập số lượng Slime tiêu diệt: ";
    std::cin >> slSlime;
    std::cout << "Nhập số lượng Goblin tiêu diệt: ";
    std::cin >> slGoblin;
    std::cout << "Nhập số lượng Boss tiêu diệt: ";
    std::cin >> slBoss;

    int totalEXP = slSlime * 15 + slGoblin * 45 + slBoss * 300;
    int levelGained = totalEXP / 100;
    int currentLevel = 1 + levelGained;
    int expRemaining = totalEXP % 100;

    std::cout << "\n=== KẾT QUẢ TRẬN ĐẤU ===\n";
    std::cout << "Tổng kinh nghiệm: " << totalEXP << " EXP\n";
    std::cout << "Cấp độ mới      : Level " << currentLevel << "\n";
    std::cout << "EXP dư cho cấp sau: " << expRemaining << " / 100\n";

    return 0;
}
