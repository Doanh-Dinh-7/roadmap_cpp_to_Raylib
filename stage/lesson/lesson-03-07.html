Sắp Xếp Cơ Bản: Bubble Sort

Mục tiêu đầu ra: Hiểu cơ chế so sánh và hoán đổi cặp phần tử liền kề, tự viết hàm sắp xếp mảng tăng/giảm dần, tối ưu dừng sớm khi không còn hoán đổi và áp dụng để dựng bảng xếp hạng điểm người chơi.

1. Lý thuyết cốt lõi (35 Phút)

1.1 Sắp xếp là gì? Vì sao game cần sắp xếp?

Sắp xếp (Sorting) là sắp đặt lại các phần tử của mảng theo một thứ tự: tăng dần (nhỏ → lớn) hoặc giảm dần (lớn → nhỏ). Trong game, sắp xếp có mặt khắp nơi: bảng xếp hạng điểm cao, danh sách vật phẩm theo giá, quái vật theo lượng máu, lượt đánh theo tốc độ nhân vật...

Bubble Sort (sắp xếp nổi bọt) là thuật toán sắp xếp đơn giản nhất: đi từ đầu mảng, so sánh từng cặp phần tử liền kề arr[j] và arr[j + 1]; nếu sai thứ tự thì hoán đổi chúng. Sau mỗi lượt duyệt, phần tử lớn nhất còn lại sẽ "nổi" dần về cuối mảng — giống bọt khí nổi lên mặt nước.

1.2 Mô phỏng từng lượt với mảng {5, 1, 4, 2, 8}

Lượt (i) Các cặp được so sánh Mảng sau lượt Số lần hoán đổi
Lượt 1 (i = 0) (5,1) đổi, (5,4) đổi, (5,2) đổi, (5,8) giữ 1 4 2 5 [8] 3
Lượt 2 (i = 1) (1,4) giữ, (4,2) đổi, (4,5) giữ 1 2 4 [5 8] 1
Lượt 3 (i = 2) (1,2) giữ, (2,4) giữ 1 2 [4 5 8] 0 → có thể dừng sớm!
Lượt 4 (i = 3) (1,2) giữ [1 2 4 5 8] 0

Phần trong ngoặc vuông [...] là các phần tử đã nằm đúng chỗ. Nhận xét: sau lượt thứ i, cuối mảng đã có i + 1 phần tử cố định, nên vòng lặp trong chỉ cần chạy đến j < n - 1 - i. Mảng n phần tử cần tối đa n - 1 lượt.

1.3 Bảng tóm tắt cú pháp

Thành phần Mã C++ Ý nghĩa
Vòng lặp ngoài (số lượt) for (int i = 0; i < n - 1; i++) Tối đa n - 1 lượt duyệt
Vòng lặp trong (cặp liền kề) for (int j = 0; j < n - 1 - i; j++) Bỏ qua i phần tử cuối đã đúng chỗ
Điều kiện tăng dần if (arr[j] > arr[j + 1]) Số trước lớn hơn số sau → sai thứ tự
Điều kiện giảm dần if (arr[j] < arr[j + 1]) Chỉ cần đảo dấu so sánh
Hoán đổi bằng biến tạm int temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp; Đổi chỗ hai phần tử mà không mất dữ liệu
Cờ dừng sớm bool swapped = false; … if (!swapped) break; Lượt nào không đổi gì → mảng đã sắp xong

1.4 Code mẫu: Bubble Sort tăng dần

bubble_basic.cpp 
#include <iostream>

// In mang tren mot dong
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        std::cout << arr[i] << " ";
    }
    std::cout << "\n";
}

// Sap xep tang dan bang Bubble Sort
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {            // Moi luot day 1 so lon nhat ve cuoi
        for (int j = 0; j < n - 1 - i; j++) {    // Bo qua i phan tu da dung cho
            if (arr[j] > arr[j + 1]) {           // Sai thu tu -> hoan doi
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main() {
    int scores[5] = {5, 1, 4, 2, 8};
    std::cout << "Truoc: ";
    printArray(scores, 5);

    bubbleSort(scores, 5);                     // Mang goc bi sap xep truc tiep

    std::cout << "Sau:   ";
    printArray(scores, 5);
    return 0;
}
📌 Ghi nhớ: Khi truyền mảng vào hàm dạng int arr[], int n, hàm làm việc trực tiếp trên mảng gốc — sau khi gọi bubbleSort(scores, 5), mảng scores trong main đã được sắp xếp. Cơ chế bên trong (địa chỉ, con trỏ) sẽ được giải thích ở Giai đoạn 04.

1.5 Tối ưu: Dừng sớm khi không còn hoán đổi

Ở bảng mô phỏng, lượt 3 không có hoán đổi nào → mảng đã sắp xếp xong, lượt 4 là thừa. Ta thêm cờ swapped: nếu cả một lượt không đổi chỗ lần nào thì break ngay. Với mảng gần như đã sắp xếp (rất hay gặp khi bảng xếp hạng chỉ thay đổi 1–2 người), cách này tiết kiệm rất nhiều phép so sánh.

bubble_early_stop.cpp (hàm thay thế) 
void bubbleSortFast(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;                  // Dat lai co o dau moi luot
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) {
            break;                               // Khong doi lan nao -> da sap xong
        }
    }
}
🎮 Mẹo tư duy Game: Bảng xếp hạng (Leaderboard) thực chất chỉ là một mảng điểm được sắp xếp giảm dần: phần tử [0] là Top 1, [1] là Top 2... Sau mỗi ván, chỉ có điểm của 1 người thay đổi nên mảng "gần như đã sắp xếp" — Bubble Sort có dừng sớm xử lý trường hợp này rất nhanh. Ở Giai đoạn 06, bạn sẽ dùng chính hàm này để vẽ bảng Top 5 lên màn hình Raylib.
⚠️ Lỗi thường gặp:
  • Vượt biên mảng: viết j < n thay vì j < n - 1 - i → khi j = n - 1, biểu thức arr[j + 1] đọc ô arr[n] không tồn tại (out-of-bounds, Buổi 26). Chương trình có thể không báo lỗi nhưng kết quả sai ngẫu nhiên.
  • Hoán đổi thiếu biến tạm: arr[j] = arr[j + 1]; arr[j + 1] = arr[j]; → cả hai ô cùng một giá trị, mất dữ liệu.
  • Đặt swapped = false ngoài vòng lặp ngoài: cờ không được đặt lại mỗi lượt → không bao giờ dừng sớm.

2. Bài tập trên lớp (45 Phút)

Bài 1: Bảng xếp hạng điểm cao (giảm dần)

Trên lớp

Đề bài: Cho mảng điểm của 8 người chơi {1200, 850, 2300, 990, 1750, 400, 2300, 1600}. Viết hàm sortDescending sắp xếp giảm dần (có dừng sớm), sau đó in bảng xếp hạng và đánh dấu [TOP 1], [TOP 2], [TOP 3].

leaderboard.cpp 
#include <iostream>

// Sap xep giam dan: chi dao dau so sanh
void sortDescending(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] < arr[j + 1]) {           // So truoc NHO hon -> doi
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

int main() {
    const int N = 8;
    int scores[N] = {1200, 850, 2300, 990, 1750, 400, 2300, 1600};

    sortDescending(scores, N);

    std::cout << "===== BANG XEP HANG =====\n";
    for (int i = 0; i < N; i++) {
        std::cout << "Hang " << i + 1 << ": " << scores[i] << " diem";
        if (i < 3) {
            std::cout << "  [TOP " << i + 1 << "]";
        }
        std::cout << "\n";
    }
    return 0;
}
Câu hỏi thảo luận: Hai người cùng 2300 điểm đứng Hạng 1 và Hạng 2. Có công bằng không? Bài tập về nhà [Hard] sẽ xử lý trường hợp đồng hạng.

Bài 2: Nhập điểm và đếm số lượt sắp xếp

Trên lớp

Đề bài: Nhập số lượng người chơi n (1–20, nhập lại nếu sai) và điểm từng người. Viết hàm int bubbleSortPasses(int arr[], int n) sắp xếp tăng dần có dừng sớm và trả về số lượt đã thực sự chạy. Thử với dữ liệu đã sắp sẵn (1 2 3 4 5) và dữ liệu ngược (5 4 3 2 1) để so sánh.

count_passes.cpp 
#include <iostream>

int bubbleSortPasses(int arr[], int n) {
    int passes = 0;
    for (int i = 0; i < n - 1; i++) {
        passes++;                                 // Bat dau mot luot moi
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
    return passes;
}

int main() {
    const int MAX = 20;
    int scores[MAX];
    int n;

    do {
        std::cout << "So nguoi choi (1-" << MAX << "): ";
        std::cin >> n;
    } while (n < 1 || n > MAX);

    for (int i = 0; i < n; i++) {
        std::cout << "Diem nguoi choi " << i + 1 << ": ";
        std::cin >> scores[i];
    }

    int passes = bubbleSortPasses(scores, n);

    std::cout << "Sau sap xep: ";
    for (int i = 0; i < n; i++) {
        std::cout << scores[i] << " ";
    }
    std::cout << "\nSo luot da chay: " << passes
              << " (toi da " << n - 1 << ")\n";
    return 0;
}
🎯 Kết quả mong đợi: Nhập 1 2 3 4 5 → chỉ 1 lượt (không đổi gì nên dừng ngay). Nhập 5 4 3 2 1 → đủ 4 lượt. Đây là bước đệm cho Buổi 30, nơi ta đo hiệu năng thuật toán một cách bài bản.

3. Bài tập về nhà (Tự luyện tập)

Hoàn thành cả 3 bài, tự kiểm tra với ít nhất một mảng đã sắp sẵn và một mảng sắp ngược:

Bài 1 [Easy]: Sắp xếp kho vật phẩm theo giá

Easy (40%)

Cửa hàng trong game có 6 vật phẩm với giá {350, 120, 990, 45, 600, 120} vàng. Sắp xếp tăng dần bằng Bubble Sort, in mảng trước và sau khi sắp xếp, rồi in giá rẻ nhất và đắt nhất (lấy trực tiếp từ đầu và cuối mảng đã sắp).

Gợi ý: Sau khi sắp xếp tăng dần, giá rẻ nhất luôn ở prices[0], đắt nhất ở prices[n - 1] — không cần vòng lặp tìm Max/Min như Buổi 27.

shop_sort.cpp 
#include <iostream>

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        std::cout << arr[i] << " ";
    }
    std::cout << "\n";
}

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

int main() {
    const int N = 6;
    int prices[N] = {350, 120, 990, 45, 600, 120};

    std::cout << "Gia truoc khi sap xep: ";
    printArray(prices, N);

    bubbleSort(prices, N);

    std::cout << "Gia sau khi sap xep:  ";
    printArray(prices, N);

    std::cout << "Re nhat: " << prices[0] << " vang\n";
    std::cout << "Dat nhat: " << prices[N - 1] << " vang\n";
    return 0;
}

Bài 2 [Medium]: Một hàm sắp xếp cho cả hai chiều

Medium (40%)

Viết một hàm void sortArray(int arr[], int n, bool ascending): nếu ascending là true thì sắp tăng dần, ngược lại sắp giảm dần. Áp dụng cho mảng máu (HP) của 7 con quái {80, 250, 40, 150, 40, 300, 95}: người chơi nhập 1 để xem quái yếu nhất trước, 2 để xem quái mạnh nhất trước (nhập lại nếu không phải 1 hoặc 2).

Phân tích: Hai chiều sắp xếp chỉ khác nhau ở phép so sánh. Ta tính một biến wrongOrder ("cặp này đang sai thứ tự?") dựa vào ascending, phần hoán đổi giữ nguyên — tránh phải viết hai hàm gần giống hệt nhau.

monster_hp_sort.cpp 
#include <iostream>

void sortArray(int arr[], int n, bool ascending) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            bool wrongOrder;
            if (ascending) {
                wrongOrder = arr[j] > arr[j + 1];
            } else {
                wrongOrder = arr[j] < arr[j + 1];
            }

            if (wrongOrder) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

int main() {
    const int N = 7;
    int hp[N] = {80, 250, 40, 150, 40, 300, 95};
    int choice;

    do {
        std::cout << "1 - Quai yeu truoc | 2 - Quai manh truoc: ";
        std::cin >> choice;
    } while (choice != 1 && choice != 2);

    sortArray(hp, N, choice == 1);          // choice == 1 -> true -> tang dan

    std::cout << "Danh sach HP quai: ";
    for (int i = 0; i < N; i++) {
        std::cout << hp[i] << " ";
    }
    std::cout << "\n";
    return 0;
}

Bài 3 [Hard]: Bảng xếp hạng có mã người chơi & đồng hạng

Hard (20%)

Dùng hai mảng song song: ids[i] là mã người chơi (gán tự động 101, 102, ...) và scores[i] là điểm của người đó. Nhập n (1–10) và điểm từng người, sau đó:

  • Sắp xếp theo điểm giảm dần; nếu bằng điểm thì người có mã nhỏ hơn đứng trước.
  • Mỗi lần hoán đổi phải đổi cả hai mảng để mã và điểm luôn đi cùng nhau.
  • In bảng xếp hạng có đồng hạng: điểm 900, 700, 700, 500 → hạng 1, 2, 2, 4.
Gợi ý: Tách hàm bool shouldSwap(int ids[], int scores[], int a, int b) trả về true khi người ở vị trí a phải đứng sau người ở vị trí b, và hàm void swapAt(int arr[], int a, int b) để hoán đổi hai ô của một mảng.
leaderboard_ranked.cpp 
#include <iostream>

// Hoan doi 2 o a va b cua mot mang
void swapAt(int arr[], int a, int b) {
    int temp = arr[a];
    arr[a] = arr[b];
    arr[b] = temp;
}

// true neu nguoi o vi tri a phai dung SAU nguoi o vi tri b
bool shouldSwap(int ids[], int scores[], int a, int b) {
    if (scores[a] != scores[b]) {
        return scores[a] < scores[b];            // Diem cao len truoc
    }
    return ids[a] > ids[b];                      // Bang diem: ma nho len truoc
}

void sortLeaderboard(int ids[], int scores[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (shouldSwap(ids, scores, j, j + 1)) {
                swapAt(scores, j, j + 1);
                swapAt(ids, j, j + 1);          // Doi CA HAI mang de giu cap
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

int main() {
    const int MAX = 10;
    int ids[MAX];
    int scores[MAX];
    int n;

    do {
        std::cout << "So nguoi choi (1-" << MAX << "): ";
        std::cin >> n;
    } while (n < 1 || n > MAX);

    for (int i = 0; i < n; i++) {
        ids[i] = 101 + i;
        std::cout << "Diem cua nguoi choi #" << ids[i] << ": ";
        std::cin >> scores[i];
    }

    sortLeaderboard(ids, scores, n);

    std::cout << "\n===== BANG XEP HANG =====\n";
    int rank = 1;
    for (int i = 0; i < n; i++) {
        if (i > 0 && scores[i] != scores[i - 1]) {
            rank = i + 1;                            // Khac diem nguoi truoc -> hang moi
        }
        std::cout << "Hang " << rank << " | #" << ids[i]
                  << " | " << scores[i] << " diem\n";
    }
    return 0;
}
💡 Vì sao hạng là 1, 2, 2, 4 chứ không phải 1, 2, 2, 3? Đây là kiểu xếp hạng thể thao chuẩn: hai người đồng hạng 2 đã "chiếm" hai vị trí, nên người tiếp theo đứng thứ 4. Công thức rank = i + 1 (vị trí thực trong mảng) cho ra đúng kết quả này.
