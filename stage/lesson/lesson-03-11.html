Mini Project: Tic Tac Toe Console

Mục tiêu đầu ra: Xây dựng hoàn chỉnh cờ caro 3x3 cho hai người chơi trên console — lưu bàn cờ bằng mảng char board[9], chia chương trình thành các hàm drawBoard, getMove, checkWin, isFull, kiểm tra nước đi hợp lệ, vòng lặp game và chơi lại nhiều ván — vận dụng toàn bộ kiến thức Hàm và Mảng của Giai đoạn 03.

1. Lý thuyết cốt lõi — Phân tích & Thiết kế game (20 Phút)

1.1 Luật chơi và ánh xạ sang kiến thức đã học

Hai người chơi lần lượt đánh X và O vào bàn cờ 3x3. Ai có 3 quân thẳng hàng (ngang, dọc hoặc chéo) trước sẽ thắng; nếu kín 9 ô mà không ai thắng thì hòa. Mỗi phần của game tương ứng với một kiến thức bạn đã học:

1.2 Biểu diễn bàn cờ 3x3 bằng mảng 1 chiều

Ta chưa học mảng 2 chiều (Giai đoạn 04), nhưng chỉ cần đánh số 9 ô theo hàng, từ trái sang phải, trên xuống dưới. Người chơi nhập số 1–9, còn chỉ số mảng là 0–8 → index = cell - 1. Ô ở hàng row, cột col có chỉ số row * 3 + col.

Cột 0Cột 1Cột 2
Hàng 0Ô 1 → board[0]Ô 2 → board[1]Ô 3 → board[2]
Hàng 1Ô 4 → board[3]Ô 5 → board[4]Ô 6 → board[5]
Hàng 2Ô 7 → board[6]Ô 8 → board[7]Ô 9 → board[8]

Mẹo hiển thị: khởi tạo ô trống bằng chính ký tự số '1'…'9' (board[i] = '1' + i) để người chơi nhìn bàn cờ là biết số ô. Ô còn trống ⇔ ô đó không phải 'X' và không phải 'O'.

1.3 Tám đường thắng — dùng 3 mảng song song

LoạiCác bộ 3 chỉ sốSố đường
Hàng ngang(0,1,2) (3,4,5) (6,7,8)3
Cột dọc(0,3,6) (1,4,7) (2,5,8)3
Đường chéo(0,4,8) (2,4,6)2

Thay vì viết 8 câu if dài, ta lưu ô thứ nhất, thứ hai, thứ ba của mỗi đường vào ba mảng hằng WIN_A, WIN_B, WIN_C (cùng chỉ số k → cùng một đường — giống mảng song song tên/điểm ở Buổi 27) rồi duyệt bằng một vòng for.

📋 Luồng chạy một ván (Game Loop):
  1. START → initBoard, người đi đầu là X.
  2. Vẽ bàn cờ (drawBoard).
  3. Nhập nước đi hợp lệ (getMove) → cập nhật board[index] = current.
  4. Kiểm tra: checkWin đúng → người hiện tại thắng, kết thúc ván. isFull đúng → hòa, kết thúc ván.
  5. Chưa kết thúc → đổi lượt (switchPlayer) → quay lại bước 2.
🎮 Mẹo tư duy Game: Vòng lặp Vẽ → Nhập → Cập nhật → Kiểm tra chính là Game Loop của mọi trò chơi. Trong Raylib (Giai đoạn 06), mỗi khung hình cũng làm đúng các bước này: đọc chuột/bàn phím, cập nhật dữ liệu, rồi BeginDrawing()…EndDrawing(). Hàm drawBoard hôm nay sau này chỉ cần thay std::cout bằng DrawRectangle, DrawText là thành Tic Tac Toe đồ họa — phần logic checkWin, isFull giữ nguyên!
⚠️ Lỗi thường gặp:
  • Lệch chỉ số 1: quên cell - 1 → người chọn ô 9 sẽ ghi vào board[9], vượt ngoài mảng (Buổi 26) và có thể làm hỏng biến khác.
  • Không kiểm tra ô đã có quân → người chơi đè lên quân của đối thủ.
  • Kiểm tra hòa trước khi kiểm tra thắng: nước thứ 9 vừa tạo thành 3 quân thẳng hàng sẽ bị báo nhầm là hòa. Luôn gọi checkWin trước isFull.
  • Mảng truyền vào hàm bị sửa trực tiếp: khác với int hay std::string (được sao chép), khi gọi initBoard(board) thì hàm thay đổi chính mảng board của main — nhờ vậy các hàm mới dùng chung được bàn cờ. Cơ chế bên trong sẽ được giải thích ở Giai đoạn 04 (con trỏ).

2. Bài tập trên lớp — Xây dựng game từng bước (70 Phút)

Bước 1: Khởi tạo và vẽ bàn cờ

Trên lớp

Đề bài: Viết initBoard và drawBoard. Trong main, thử đặt vài quân rồi vẽ để kiểm tra bàn cờ hiển thị đúng vị trí.

step1_board.cpp 
#include <iostream>

// Dat lai ban co: o trong hien so '1'..'9' de nguoi choi de chon
void initBoard(char board[]) {
    for (int i = 0; i < 9; i++) {
        board[i] = '1' + i;
    }
}

// Ve ban co 3x3 tu mang 1 chieu 9 phan tu
void drawBoard(char board[]) {
    std::cout << "\n";
    for (int row = 0; row < 3; row++) {
        int start = row * 3;                     // Chi so o dau tien cua hang
        std::cout << " " << board[start] << " | " << board[start + 1]
                  << " | " << board[start + 2] << "\n";
        if (row < 2) {
            std::cout << "---+---+---\n";
        }
    }
    std::cout << "\n";
}

int main() {
    char board[9];
    initBoard(board);
    board[4] = 'X';                              // Thu dat X vao o giua (o so 5)
    board[0] = 'O';                              // Thu dat O vao goc trai tren (o so 1)
    drawBoard(board);
    return 0;
}
Kết quả mong đợi: hàng đầu in O | 2 | 3, hàng giữa 4 | X | 6, hàng cuối 7 | 8 | 9, giữa các hàng là ---+---+---.

Bước 2: Nhập nước đi hợp lệ

Trên lớp

Đề bài: Viết isEmptyCell và getMove. getMove lặp đến khi người chơi nhập một số từ 1–9 ứng với ô còn trống; gõ chữ, số ngoài khoảng hay ô đã có quân đều phải báo lỗi và hỏi lại.

step2_getmove.cpp (thêm vào trước main) 
// O con trong khi chua bi danh X hoac O
bool isEmptyCell(char board[], int index) {
    return board[index] != 'X' && board[index] != 'O';
}

// Hoi nuoc di den khi hop le, tra ve chi so mang 0-8
int getMove(char board[], char player) {
    int cell = 0;
    while (true) {
        std::cout << "Nguoi choi " << player << ", chon o (1-9): ";
        if (!(std::cin >> cell)) {               // Go chu -> cin bi loi
            std::cin.clear();
            std::cin.ignore(1000, '\n');
            std::cout << "Vui long nhap mot so!\n";
        } else if (cell < 1 || cell > 9) {
            std::cout << "Chi duoc chon o tu 1 den 9!\n";
        } else if (!isEmptyCell(board, cell - 1)) {
            std::cout << "O nay da co quan co, chon o khac!\n";
        } else {
            return cell - 1;                     // So 1-9 cua nguoi choi -> chi so 0-8
        }
    }
}

Bước 3: Kiểm tra thắng và hòa

Trên lớp

Đề bài: Khai báo ba mảng hằng chứa 8 đường thắng, viết checkWin (duyệt 8 đường) và isFull (tìm kiếm tuyến tính một ô trống).

step3_checkwin.cpp (thêm vào trước main) 
// 8 duong thang: duong thu k gom 3 o WIN_A[k], WIN_B[k], WIN_C[k]
//                  hang 1  hang 2  hang 3  cot 1   cot 2   cot 3   cheo \  cheo /
const int WIN_A[8] = {0,      3,      6,      0,      1,      2,      0,      2};
const int WIN_B[8] = {1,      4,      7,      3,      4,      5,      4,      4};
const int WIN_C[8] = {2,      5,      8,      6,      7,      8,      8,      6};

bool checkWin(char board[], char player) {
    for (int k = 0; k < 8; k++) {
        if (board[WIN_A[k]] == player &&
            board[WIN_B[k]] == player &&
            board[WIN_C[k]] == player) {
            return true;                         // Du 3 o thang hang
        }
    }
    return false;
}

bool isFull(char board[]) {
    for (int i = 0; i < 9; i++) {
        if (isEmptyCell(board, i)) {
            return false;                        // Con it nhat 1 o trong
        }
    }
    return true;
}
Vì sao WIN_A, WIN_B, WIN_C là biến toàn cục? Đây là hằng số (const) dùng chung, không bao giờ thay đổi — trường hợp hợp lý để khai báo toàn cục (Buổi 25). Biến có thể thay đổi như board vẫn nên để cục bộ và truyền qua tham số.

Bước 4: Ghép hoàn chỉnh — Game loop, tỉ số, chơi lại

Mini Project

Đề bài: Viết switchPlayer và playRound theo luồng ở mục 1.4. Trong main, bọc playRound trong vòng do-while "Chơi lại?", đếm số ván X thắng, O thắng và hòa.

tic_tac_toe.cpp 
#include <iostream>

// ===== DU LIEU: 8 duong thang de thang =====
const int WIN_A[8] = {0, 3, 6, 0, 1, 2, 0, 2};
const int WIN_B[8] = {1, 4, 7, 3, 4, 5, 4, 4};
const int WIN_C[8] = {2, 5, 8, 6, 7, 8, 8, 6};

void initBoard(char board[]) {
    for (int i = 0; i < 9; i++) {
        board[i] = '1' + i;
    }
}

void drawBoard(char board[]) {
    std::cout << "\n";
    for (int row = 0; row < 3; row++) {
        int start = row * 3;
        std::cout << " " << board[start] << " | " << board[start + 1]
                  << " | " << board[start + 2] << "\n";
        if (row < 2) std::cout << "---+---+---\n";
    }
    std::cout << "\n";
}

bool isEmptyCell(char board[], int index) {
    return board[index] != 'X' && board[index] != 'O';
}

int getMove(char board[], char player) {
    int cell = 0;
    while (true) {
        std::cout << "Nguoi choi " << player << ", chon o (1-9): ";
        if (!(std::cin >> cell)) {
            std::cin.clear();
            std::cin.ignore(1000, '\n');
            std::cout << "Vui long nhap mot so!\n";
        } else if (cell < 1 || cell > 9) {
            std::cout << "Chi duoc chon o tu 1 den 9!\n";
        } else if (!isEmptyCell(board, cell - 1)) {
            std::cout << "O nay da co quan co, chon o khac!\n";
        } else {
            return cell - 1;
        }
    }
}

bool checkWin(char board[], char player) {
    for (int k = 0; k < 8; k++) {
        if (board[WIN_A[k]] == player &&
            board[WIN_B[k]] == player &&
            board[WIN_C[k]] == player) {
            return true;
        }
    }
    return false;
}

bool isFull(char board[]) {
    for (int i = 0; i < 9; i++) {
        if (isEmptyCell(board, i)) return false;
    }
    return true;
}

char switchPlayer(char player) {
    if (player == 'X') return 'O';
    return 'X';
}

// Choi 1 van. Tra ve 'X' hoac 'O' neu co nguoi thang, 'D' neu hoa
char playRound(char firstPlayer) {
    char board[9];
    initBoard(board);
    char current = firstPlayer;

    while (true) {                               // GAME LOOP
        drawBoard(board);                        // 1. Ve ban co
        int index = getMove(board, current);     // 2. Nhan nuoc di hop le
        board[index] = current;                  // 3. Cap nhat ban co

        if (checkWin(board, current)) {          // 4. Kiem tra ket thuc
            drawBoard(board);
            std::cout << ">>> Nguoi choi " << current << " THANG! <<<\n";
            return current;
        }
        if (isFull(board)) {
            drawBoard(board);
            std::cout << ">>> HOA! Ban co da day. <<<\n";
            return 'D';
        }
        current = switchPlayer(current);         // 5. Doi luot
    }
}

int main() {
    int winsX = 0, winsO = 0, draws = 0;
    char again = 'y';

    std::cout << "===== TIC TAC TOE =====\n";
    do {
        char result = playRound('X');
        if (result == 'X') winsX++;
        else if (result == 'O') winsO++;
        else draws++;

        std::cout << "Ti so -> X: " << winsX << " | O: " << winsO
                  << " | Hoa: " << draws << "\n";
        std::cout << "Choi lai? (y/n): ";
        std::cin >> again;
    } while (again == 'y' || again == 'Y');

    std::cout << "Cam on ban da choi!\n";
    return 0;
}
🎯 Kiểm thử bắt buộc trước khi nộp: (1) X thắng hàng ngang 1-2-3; (2) O thắng cột dọc; (3) thắng đường chéo 3-5-7; (4) ván hòa kín 9 ô; (5) thắng đúng ở nước thứ 9 (phải báo thắng, không báo hòa); (6) nhập chữ abc; (7) nhập 0 hoặc 10; (8) chọn ô đã có quân; (9) chơi 3 ván rồi kiểm tra tỉ số.

3. Bài tập về nhà (Hoàn thiện Tic Tac Toe)

Học viên làm cả 3 bài để hoàn thiện sản phẩm cuối Giai đoạn 03:

Bài 1 [Easy]: Tên người chơi & đổi lượt đi trước

Easy (40%)

Đầu chương trình nhập tên hai người chơi bằng std::getline. Mỗi lượt in "Luot cua An (X)"; khi thắng in tên người thắng. Sau mỗi ván in bảng tỉ số theo tên, và ván sau đổi người đi trước (ván 1 X đi trước, ván 2 O đi trước, …).

Gợi ý: Truyền thêm tham số std::string cho getMove và playRound. Biến first nằm ngoài vòng ván chơi, cuối mỗi ván gọi first = switchPlayer(first). Các hàm không liệt kê bên dưới giữ nguyên như bản hoàn chỉnh trên lớp.

#include <iostream>
#include <string>

// Giu nguyen: WIN_A/B/C, initBoard, drawBoard, isEmptyCell,
//             checkWin, isFull, switchPlayer (nhu tic_tac_toe.cpp)

// getMove nhan them ten nguoi choi de hien thi
int getMove(char board[], char player, std::string name) {
    int cell = 0;
    while (true) {
        std::cout << "Luot cua " << name << " (" << player << "), chon o (1-9): ";

        } else {
            return cell - 1;
        }
    }
}

char playRound(char firstPlayer, std::string nameX, std::string nameO) {
    char board[9];
    initBoard(board);
    char current = firstPlayer;

    while (true) {
        drawBoard(board);
        std::string name = nameX;
        if (current == 'O') name = nameO;        // Ten cua nguoi dang toi luot

        int index = getMove(board, current, name);
        board[index] = current;

        if (checkWin(board, current)) {
            drawBoard(board);
            std::cout << ">>> " << name << " (" << current << ") THANG! <<<\n";
            return current;
        }
        if (isFull(board)) {
            drawBoard(board);
            std::cout << ">>> HOA! <<<\n";
            return 'D';
        }
        current = switchPlayer(current);
    }
}

int main() {
    std::string nameX, nameO;
    std::cout << "Ten nguoi choi X: ";
    std::getline(std::cin, nameX);

    std::getline(std::cin, nameO);

    int winsX = 0, winsO = 0, draws = 0;
    char first = 'X';
    char again = 'y';

    do {
        std::cout << "\n--- Van moi: " << first << " di truoc ---\n";
        char result = playRound(first, nameX, nameO);
        if (result == 'X') winsX++;
        else if (result == 'O') winsO++;
        else draws++;

        std::cout << "BANG TI SO: " << nameX << " " << winsX << " - "
                  << winsO << " " << nameO << " (Hoa: " << draws << ")\n";

        first = switchPlayer(first);             // Van sau doi nguoi di truoc
        std::cout << "Choi lai? (y/n): ";
        std::cin >> again;
    } while (again == 'y' || again == 'Y');

    return 0;
}

Bài 2 [Medium]: Hoàn tác nước đi (Undo)

Medium (40%)

Cho phép người chơi nhập 0 để hoàn tác nước đi gần nhất: ô đó trở lại trống và lượt quay về người vừa đánh. Có thể hoàn tác liên tiếp nhiều nước cho đến khi bàn cờ trống. Khi thắng, in thêm tổng số nước đã đi.

Phân tích: Dùng mảng int moves[9] làm lịch sử các ô đã đánh và biến moveCount. Đánh → ghi vào moves[moveCount] rồi tăng; hoàn tác → giảm moveCount, lấy moves[moveCount] và trả ô về '1' + index. Khi đã có moveCount thì kiểm tra hòa chỉ cần moveCount == 9.

tic_tac_toe_undo.cpp 
// Giu nguyen: WIN_A/B/C, initBoard, drawBoard, isEmptyCell,
//             checkWin, isFull, switchPlayer, main (nhu tic_tac_toe.cpp)

// Nhap 0 de hoan tac -> tra ve -1
int getMove(char board[], char player) {
    int cell = 0;
    while (true) {
        std::cout << "Nguoi choi " << player << ", chon o (1-9, 0 = hoan tac): ";
        if (!(std::cin >> cell)) {
            std::cin.clear();
            std::cin.ignore(1000, '\n');
            std::cout << "Vui long nhap mot so!\n";
        } else if (cell == 0) {
            return -1;                           // Tin hieu xin hoan tac
        } else if (cell < 1 || cell > 9) {
            std::cout << "Chi duoc chon o tu 0 den 9!\n";
        } else if (!isEmptyCell(board, cell - 1)) {
            std::cout << "O nay da co quan co, chon o khac!\n";
        } else {
            return cell - 1;
        }
    }
}

char playRound(char firstPlayer) {
    char board[9];
    initBoard(board);
    char current = firstPlayer;

    int moves[9];                                // Lich su: chi so o theo thu tu da danh
    int moveCount = 0;

    while (true) {
        drawBoard(board);
        int index = getMove(board, current);

        if (index == -1) {                       // ----- HOAN TAC -----
            if (moveCount == 0) {
                std::cout << "Chua co nuoc nao de hoan tac!\n";
                continue;
            }
            moveCount--;
            int last = moves[moveCount];         // O vua danh gan nhat
            board[last] = '1' + last;            // Tra o ve trang thai trong
            current = switchPlayer(current);     // Tra luot cho nguoi vua danh
            std::cout << "Da hoan tac nuoc di o so " << last + 1 << "\n";
            continue;
        }

        board[index] = current;
        moves[moveCount] = index;                // Ghi vao lich su
        moveCount++;

        if (checkWin(board, current)) {
            drawBoard(board);
            std::cout << ">>> Nguoi choi " << current << " THANG sau "
                      << moveCount << " nuoc! <<<\n";
            return current;
        }
        if (moveCount == 9) {                    // Thay cho isFull: da danh du 9 o
            drawBoard(board);
            std::cout << ">>> HOA! <<<\n";
            return 'D';
        }
        current = switchPlayer(current);
    }
}

Bài 3 [Hard]: Chơi với máy tính (AI đơn giản)

Hard (20%)

Thêm menu chọn chế độ: 1 hai người, 2 máy dễ — máy (cầm O) chọn ngẫu nhiên một ô trống, 3 máy khó — máy suy nghĩ theo thứ tự ưu tiên:

  1. Nếu có ô đánh vào là thắng ngay → đánh ô đó.
  2. Nếu người chơi có ô sắp thắng → chặn ô đó.
  3. Nếu ô giữa (ô 5) còn trống → chiếm ô giữa.
  4. Còn lại → chọn ngẫu nhiên một ô trống.

Ý tưởng "thử rồi hoàn lại": Hàm findWinningMove lần lượt thử đặt quân vào từng ô trống, gọi checkWin, rồi trả ô về như cũ. Gọi với quân của máy → tìm nước thắng; gọi với quân của người → tìm nước cần chặn. Để chọn ngẫu nhiên, gom chỉ số các ô trống vào mảng empty[] rồi lấy empty[rand() % count].

tic_tac_toe_ai.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

// Giu nguyen: WIN_A/B/C, initBoard, drawBoard, isEmptyCell, getMove,
//             checkWin, isFull, switchPlayer (nhu tic_tac_toe.cpp)

// ===== AI CUA MAY =====

// Chon ngau nhien 1 o trong (chi goi khi ban co chua day)
int getRandomEmptyCell(char board[]) {
    int empty[9];                                // Danh sach chi so cac o trong
    int count = 0;
    for (int i = 0; i < 9; i++) {
        if (isEmptyCell(board, i)) {
            empty[count] = i;
            count++;
        }
    }
    return empty[rand() % count];
}

// Thu tung o trong: neu player danh vao do ma thang -> tra ve o do, khong co -> -1
int findWinningMove(char board[], char player) {
    for (int i = 0; i < 9; i++) {
        if (isEmptyCell(board, i)) {
            char backup = board[i];
            board[i] = player;                   // Thu danh
            bool win = checkWin(board, player);
            board[i] = backup;                   // Hoan lai nhu cu
            if (win) return i;
        }
    }
    return -1;
}

int getSmartMove(char board[], char computer, char human) {
    int move = findWinningMove(board, computer); // 1. Thang duoc thi thang ngay
    if (move != -1) return move;
    move = findWinningMove(board, human);        // 2. Doi thu sap thang -> chan
    if (move != -1) return move;
    if (isEmptyCell(board, 4)) return 4;         // 3. Chiem o giua
    return getRandomEmptyCell(board);            // 4. Con lai: chon ngau nhien
}

// mode: 1 = hai nguoi, 2 = may de (ngau nhien), 3 = may kho (thang/chan)
char playRound(int mode) {
    char board[9];
    initBoard(board);
    char current = 'X';                          // Nguoi luon cam X va di truoc

    while (true) {
        drawBoard(board);
        int index;
        if (mode != 1 && current == 'O') {       // Luot cua may
            if (mode == 2) index = getRandomEmptyCell(board);
            else index = getSmartMove(board, 'O', 'X');
            std::cout << "May danh vao o " << index + 1 << "\n";
        } else {
            index = getMove(board, current);
        }
        board[index] = current;

        if (checkWin(board, current)) {
            drawBoard(board);
            if (mode != 1 && current == 'O') std::cout << ">>> MAY THANG! <<<\n";
            else std::cout << ">>> Nguoi choi " << current << " THANG! <<<\n";
            return current;
        }
        if (isFull(board)) {
            drawBoard(board);
            std::cout << ">>> HOA! <<<\n";
            return 'D';
        }
        current = switchPlayer(current);
    }
}

int main() {
    srand(time(0));
    int winsX = 0, winsO = 0, draws = 0;
    char again = 'y';

    std::cout << "===== TIC TAC TOE vs MAY =====\n";
    do {
        int mode = 0;
        do {
            std::cout << "Che do: 1-Hai nguoi  2-May de  3-May kho : ";
            if (!(std::cin >> mode)) {
                std::cin.clear();
                std::cin.ignore(1000, '\n');
                mode = 0;
            }
        } while (mode < 1 || mode > 3);

        char result = playRound(mode);
        if (result == 'X') winsX++;
        else if (result == 'O') winsO++;
        else draws++;

        std::cout << "Ti so -> X: " << winsX << " | O: " << winsO
                  << " | Hoa: " << draws << "\n";
        std::cout << "Choi lai? (y/n): ";
        std::cin >> again;
    } while (again == 'y' || again == 'Y');

    return 0;
}
