Flowchart (Lưu Đồ Thuật Toán) & Quy Trình Phân Tích

Mục tiêu đầu ra: Hiểu và sử dụng thành thạo 5 ký hiệu Flowchart chuẩn, áp dụng quy trình 4 bước thiết kế thuật toán từ đề bài đến code C++.

← Buổi 19 Buổi 21 →

1. Lý thuyết cốt lõi (25 Phút)

Flowchart (Lưu đồ thuật toán) là công cụ trực quan hóa thuật toán bằng các ký hiệu hình học chuẩn. Thay vì giải thích bằng lời, ta vẽ từng bước xử lý, giúp dễ dàng phát hiện lỗi logic trước khi viết code.

1.1 Năm ký hiệu Flowchart chính

📐 Bảng ký hiệu chuẩn:
Ký hiệu Hình dạng Ý nghĩa Ví dụ
Start / End Hình oval (elip) Bắt đầu / Kết thúc chương trình BẮT ĐẦU, KẾT THÚC
Input / Output Hình bình hành Nhập / Xuất dữ liệu Nhập n, In "tong"
Process Hình chữ nhật Thao tác xử lý, tính toán tong += i, i = 1
Decision Hình thoi Điều kiện rẽ nhánh (Yes/No) i <= n?
Flow Mũi tên Luồng điều khiển → Có / → Không

1.2 Quy trình 4 bước thiết kế thuật toán

🔄 Quy trình chuẩn:
  1. Bước 1 — Đọc đề: Xác định rõ Input (đầu vào) và Output (đầu ra) mong muốn.
  2. Bước 2 — Liệt kê: Viết ra từng bước xử lý bằng ngôn ngữ tự nhiên (tiếng Việt).
  3. Bước 3 — Vẽ Flowchart: Chuyển các bước thành sơ đồ ký hiệu hình học chuẩn.
  4. Bước 4 — Viết code: Dịch Flowchart thành code C++ tương ứng.

1.3 Ứng dụng Game: Flowchart Game Loop

🎮 Kết nối Game Dev: Mọi game đều chạy theo một vòng lặp cố định gọi là Game Loop. Flowchart giúp ta thiết kế luồng này trước khi code:

Init → Handle Input → Update State → Draw → Check End Condition → Loop lại

1.4 Ví dụ hoàn chỉnh: Tính tổng 1 + 2 + ... + n

Flowchart mô tả thuật toán tính tổng từ 1 đến n:

Flowchart (ASCII) 
      ┌─────────────┐
      │   BẮT ĐẦU   │
      └──────┬──────┘
             │
      ┌──────▼──────┐
      │   Nhập n    │
      └──────┬──────┘
             │
      ┌──────▼──────┐
      │   i = 1     │
      │  tong = 0   │
      └──────┬──────┘
             │
      ┌──────▼──────┐
   ┌──┤  i <= n?    ├──Không──┐
   │  └─────────────┘         │
  Có                          │
   │  ┌──────────────┐        │
   └─▶│  tong += i   │        │
      │     i++      │        │
      └──────┬───────┘        │
             │                │
             └────────────────┘
                              │
                    ┌─────────▼──────┐
                    │  In "tong"     │
                    └────────┬───────┘
                             │
                    ┌────────▼───────┐
                    │   KẾT THÚC    │
                    └────────────────┘

Code C++ tương ứng với Flowchart trên:

tinh_tong.cpp 
#include <iostream>

int main() {
    int n, tong = 0;
    std::cout << "Nhap n: ";
    std::cin >> n;

    // Vong lap tuong ung voi Decision trong Flowchart
    for (int i = 1; i <= n; i++) {
        tong += i;         // Process: tong += i
    }                      // i++ la update cuoi moi vong

    std::cout << "Tong 1 den " << n << " = " << tong << std::endl;
    return 0;
}
💡 Nhận xét: Mỗi ký hiệu Flowchart ánh xạ trực tiếp sang một cấu trúc code:
  • Hình thoi i <= n? → điều kiện for / while
  • Hình chữ nhật tong += i → dòng xử lý trong thân lặp
  • Hình bình hành Nhập n → std::cin >> n

2. Bài tập trên lớp — Live Coding (40 Phút)

Thực hành: Tìm số lớn nhất trong 3 số

Trên lớp

Đề bài: Vẽ Flowchart cho bài toán "Tìm số lớn nhất trong 3 số a, b, c nhập từ bàn phím". Sau đó chuyển Flowchart thành code C++ hoàn chỉnh.

Gợi ý quy trình:
  1. Input: 3 số nguyên a, b, c
  2. Output: Số lớn nhất trong 3 số
  3. Dùng biến max khởi tạo bằng a, rồi so sánh lần lượt với b và c
  4. Mỗi so sánh là một hình thoi trong Flowchart
Flowchart (mô tả) 
BẮT ĐẦU
  │
  ▼
Nhập a, b, c
  │
  ▼
max = a
  │
  ▼
b > max? ──Có──▶ max = b
  │                  │
  Không             │
  │◀─────────────────┘
  ▼
c > max? ──Có──▶ max = c
  │                  │
  Không             │
  │◀─────────────────┘
  ▼
In "max"
  │
  ▼
KẾT THÚC
so_lon_nhat.cpp 
#include <iostream>

int main() {
    int a, b, c;
    std::cout << "Nhap 3 so a, b, c: ";
    std::cin >> a >> b >> c;

    int max = a;           // Khoi tao max bang a
    if (b > max) max = b;  // So sanh voi b
    if (c > max) max = c;  // So sanh voi c

    std::cout << "So lon nhat la: " << max << std::endl;
    return 0;
}

3. Bài tập về nhà (Tự luyện tập)

Học viên hoàn thành các bài tập sau, mỗi bài phải vẽ Flowchart trước rồi mới viết code:

Bài 1 [Easy]: Kiểm tra số chẵn hay lẻ

Easy (40%)

Vẽ Flowchart kiểm tra một số nguyên n nhập từ bàn phím là chẵn hay lẻ. Sau đó chuyển Flowchart thành code C++ và test với n = 7, n = 12.

Gợi ý Flowchart: Hình thoi duy nhất: n % 2 == 0? → Có: in "Chan" / Không: in "Le".

chan_le.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap so n: ";
    std::cin >> n;

    if (n % 2 == 0) {
        std::cout << n << " la so CHAN." << std::endl;
    } else {
        std::cout << n << " la so LE." << std::endl;
    }
    return 0;
}

Bài 2 [Medium]: Tính giai thừa n! bằng vòng lặp

Medium (40%)

Vẽ Flowchart tính giai thừa n! bằng vòng lặp (không dùng đệ quy). Chuyển thành code C++ và test với n = 10. Lưu ý: 10! = 3.628.800.

Gợi ý: Dùng long long để chứa giá trị lớn. Flowchart tương tự tính tổng nhưng thay tong += bằng gt *=.

giai_thua.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap n: ";
    std::cin >> n;

    long long gt = 1;
    for (int i = 1; i <= n; i++) {
        gt *= i;
    }

    std::cout << n << "! = " << gt << std::endl;
    // Test: n=10 → 3628800
    return 0;
}

Bài 3 [Hard]: Flowchart Game Đoán Số (nhiều lượt)

Hard (20%)

Vẽ Flowchart hoàn chỉnh cho game đoán số nhiều lượt: người chơi đoán nhiều lần, mỗi lần nhận phản hồi "lớn hơn" / "nhỏ hơn", dừng khi đoán đúng. Yêu cầu: mô tả rõ ràng các nút quyết định (Decision) và vòng lặp trong Flowchart.

⚠️ Yêu cầu Flowchart phải có:
  • Nút Decision: guess == secret?
  • Nút Decision: guess < secret?
  • Vòng lặp quay lại từ "In phản hồi" → "Nhập đoán mới"
  • Điểm thoát: khi đoán đúng
Flowchart Game Đoán Số (ASCII) 
BẮT ĐẦU
  │
  ▼
Sinh secret = rand() % 100 + 1
  │
  ▼  ◀──────────────────────────┐
Nhập guess                      │
  │                             │
  ▼                             │
guess == secret? ──Có──▶ In "Chuc mung!" ──▶ KẾT THÚC
  │
 Không
  │
  ▼
guess < secret? ──Có──▶ In "Lon hon!"
  │                          │
 Không                       │
  │                          │
  ▼                          │
In "Nho hon!"                │
  │◀────────────────────────┘
  │
  └────────────────────────────┘ (quay lai nhap)
doan_so_nhieu_luot.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    srand(time(0));
    int secret = rand() % 100 + 1;
    int guess;

    std::cout << "Doan so tu 1 den 100:" << std::endl;

    do {
        std::cout << "Nhap doan cua ban: ";
        std::cin >> guess;

        if (guess == secret) {
            std::cout << "Chuc mung! Ban doan dung!" << std::endl;
        } else if (guess < secret) {
            std::cout << "Lon hon! Thu lai." << std::endl;
        } else {
            std::cout << "Nho hon! Thu lai." << std::endl;
        }
    } while (guess != secret);

    return 0;
}
