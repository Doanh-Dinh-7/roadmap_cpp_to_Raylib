1. Lý thuyết cốt lõi (20 Phút)

Sau 4 buổi đầu tiên, học viên thường gặp phải các lỗi logic tiềm ẩn khi xử lý dữ liệu số lớn và khi in kết quả ra màn hình.

1.1 Hiện tượng Tràn số nguyên (Integer Overflow)

Kiểu int 4 byte chỉ chứa tối đa số 2,147,483,647. Nếu bạn cộng thêm 1, biến sẽ bị "cuộn vòng" (wrap-around) thành số âm -2,147,483,648!
$\rightarrow$ Giải pháp trong Game: Dùng kiểu long long (8 byte, lên tới 9 tỷ tỷ) khi quản lý số lượng tiền tệ, kinh nghiệm tích lũy hoặc thời gian miligiây.

1.2 Định dạng bảng dữ liệu với thư viện `<iomanip>`

Để căn lề và định dạng số thập phân đẹp mắt, C++ cung cấp 3 công cụ đắc lực:

  • std::setw(n): Đặt độ rộng hiển thị của cột là n ký tự.
  • std::fixed: Hiển thị số thực ở dạng thông thường (tránh bị nhảy sang ký hiệu khoa học như 1e+06).
  • std::setprecision(k): Cố định đúng k chữ số sau dấu phẩy thập phân.
iomanip_demo.cpp 
#include <iostream>
#include <iomanip> // Thư viện thao tác định dạng

int main() {
    float playerFPS = 59.98765f;

    std::cout << std::fixed << std::setprecision(2);
    std::cout << "FPS trung bình: " << playerFPS << "\n"; // In ra 59.99

    return 0;
}

2. Thực hành tại lớp — Chữa bài tập tổng hợp (45 Phút)

Thực hành: Dựng Bảng Xếp Hạng (Leaderboard) căn lề hoàn hảo

Medium

Nhập thông tin 2 người chơi dẫn đầu: Tên người chơi 1, Điểm số (float), Tên người chơi 2, Điểm số (float). Sử dụng std::setw và std::setprecision(1) để in ra bảng xếp hạng có các cột thẳng hàng tăm tắp.

Ví dụ Output 
Output:
====================================
TOP     TÊN NGƯỜI CHƠI      ĐIỂM SỐ
------------------------------------
#1      DragonSlayer         9850.5
#2      ShadowNinja          7420.0
====================================
leaderboard.cpp 
#include <iostream>
#include <iomanip>
#include <string>

int main() {
    std::string p1Name = "DragonSlayer";
    float p1Score = 9850.54f;

    std::string p2Name = "ShadowNinja";
    float p2Score = 7420.00f;

    std::cout << "====================================\n";
    std::cout << std::left << std::setw(8) << "TOP" 
              << std::setw(18) << "TÊN NGƯỜI CHƠI" 
              << std::right << std::setw(10) << "ĐIỂM SỐ" << "\n";
    std::cout << "------------------------------------\n";

    std::cout << std::fixed << std::setprecision(1);
    std::cout << std::left << std::setw(8) << "#1" 
              << std::setw(18) << p1Name 
              << std::right << std::setw(10) << p1Score << "\n";

    std::cout << std::left << std::setw(8) << "#2" 
              << std::setw(18) << p2Name 
              << std::right << std::setw(10) << p2Score << "\n";
    std::cout << "====================================\n";

    return 0;
}

3. Bài tập về nhà (3 Cấp độ)

Bài 1 [Easy]: Chuyển đổi nhiệt độ môi trường Game (Celsius sang Fahrenheit)

Easy (40%)

Nhập vào nhiệt độ môi trường bản đồ theo độ Celsius (float c). Tính và in ra độ Fahrenheit (float f) với định dạng cố định 1 chữ số thập phân. Công thức: f = (c * 9.0f / 5.0f) + 32.0f.

Ví dụ Input / Output 
Input:
Nhập nhiệt độ môi trường (°C): 32.5

Output:
Nhiệt độ tương đương: 90.5 °F
temperature.cpp 
#include <iostream>
#include <iomanip>

int main() {
    float c;
    std::cout << "Nhập nhiệt độ môi trường (°C): ";
    std::cin >> c;

    float f = (c * 9.0f / 5.0f) + 32.0f;

    std::cout << std::fixed << std::setprecision(1);
    std::cout << "Nhiệt độ tương đương: " << f << " °F\n";
    return 0;
}

Bài 2 [Medium]: Ngăn chặn tràn số tài khoản khi nạp Kim Cương khổng lồ

Medium (40%)

Nhập vào số kim cương ban đầu diamonds = 1500000000 và số kim cương nạp thêm recharge = 1000000000. Giải thích vì sao nếu dùng int sẽ bị âm số, và viết chương trình sử dụng đúng kiểu dữ liệu long long để lưu kết quả chính xác 2.5 tỷ kim cương.

Ví dụ Input / Output 
Input:
Nhập số kim cương hiện tại (VD: 1500000000): 1500000000
Nhập số kim cương nạp thêm (VD: 1000000000): 1000000000

Output:
Tổng kim cương an toàn không tràn số: 2500000000 💎
overflow_fix.cpp 
#include <iostream>

int main() {
    long long currentDiamonds;
    long long addDiamonds;

    std::cout << "Nhập số kim cương hiện tại (VD: 1500000000): ";
    std::cin >> currentDiamonds;
    std::cout << "Nhập số kim cương nạp thêm (VD: 1000000000): ";
    std::cin >> addDiamonds;

    long long total = currentDiamonds + addDiamonds;
    std::cout << "\nTổng kim cương an toàn không tràn số: " << total << " 💎\n";
    return 0;
}

Bài 3 [Hard]: Tính vector vận tốc đạn pháo theo góc phóng (Trigonometry)

Hard (20%)

Pháo binh bắn một viên đạn với vận tốc tổng hợp speed = 100.0f và góc bắn angleDeg (tính bằng độ từ 0 đến 90 độ). Sử dụng thư viện <cmath> để tính thành phần vận tốc ngang vx = speed * cos(rad) và vận tốc dọc vy = speed * sin(rad). (Lưu ý: rad = angleDeg * 3.14159265f / 180.0f).

Ví dụ Input / Output 
Input:
Nhập tốc độ ban đầu của đạn pháo: 100
Nhập góc bắn (0 - 90 độ): 45

Output:
Vector vận tốc của viên đạn:
- Vận tốc ngang (Vx): 70.71 px/frame
- Vận tốc dọc (Vy)  : 70.71 px/frame
bullet_vector.cpp 
#include <iostream>
#include <cmath>
#include <iomanip>

int main() {
    const float PI = 3.14159265f;
    float speed, angleDeg;

    std::cout << "Nhập tốc độ ban đầu của đạn pháo: ";
    std::cin >> speed;
    std::cout << "Nhập góc bắn (0 - 90 độ): ";
    std::cin >> angleDeg;

    float angleRad = angleDeg * (PI / 180.0f);
    float vx = speed * cos(angleRad);
    float vy = speed * sin(angleRad);

    std::cout << std::fixed << std::setprecision(2);
    std::cout << "\nVector vận tốc của viên đạn:\n";
    std::cout << "- Vận tốc ngang (Vx): " << vx << " px/frame\n";
    std::cout << "- Vận tốc dọc (Vy)  : " << vy << " px/frame\n";

    return 0;
}
