Hằng Số (Constants) & Ép Kiểu Dữ Liệu (Type Casting)

Mục tiêu đầu ra: Sử dụng const để bảo vệ các thông số vật lý game bất biến và thành thạo kỹ thuật ép kiểu tường minh static_cast để tránh lỗi làm tròn số học.

1. Lý thuyết cốt lõi (20 Phút)

Trong quá trình làm game, có rất nhiều đại lượng không bao giờ được phép thay đổi trong suốt vòng đời của game (như kích thước cửa sổ game, trọng lực Trái Đất, số khung hình mục tiêu 60 FPS).

1.1 Hằng số với từ khóa `const`

Khi đặt từ khóa const trước kiểu dữ liệu, giá trị của biến phải được gán ngay khi khởi tạo và trình biên dịch sẽ chặn đứng mọi hành vi cố tình ghi đè giá trị này.

constants.cpp 
const int SCREEN_WIDTH = 800;
const int SCREEN_HEIGHT = 450;
const float GRAVITY = 9.8f;
const int TARGET_FPS = 60;

// SCREEN_WIDTH = 1024; // LỖI BIÊN DỊCH: Không thể thay đổi hằng số!

1.2 Cạm bẫy phép chia nguyên & Kỹ thuật Ép kiểu (Type Casting)

Trong C++, khi lấy số nguyên chia cho số nguyên, kết quả nhận được luôn là phần nguyên, toàn bộ phần thập phân bị cắt cụt (truncated):

  • 5 / 2 cho kết quả là 2 (chứ không phải 2.5).
  • Để nhận được số thực, ít nhất 1 trong 2 toán hạng phải là số thực: 5.0f / 2 hoặc ép kiểu với static_cast<float>.
casting_demo.cpp 
int totalKills = 7;
int totalMatches = 2;

// Sai lầm: kdr = 3.0f do phép chia nguyên xảy ra trước khi gán
float wrongKDR = totalKills / totalMatches; 

// Chuẩn mực C++: Ép kiểu tường minh bằng static_cast
float correctKDR = static_cast<float>(totalKills) / totalMatches; // Kết quả: 3.5f

2. Thực hành tại lớp — Live Coding (45 Phút)

Thực hành: Tính thanh phần trăm máu (HP Bar Percentage)

Easy

Nhập lượng máu hiện tại currentHP (kiểu int) và lượng máu tối đa maxHP = 150 (kiểu hằng số const int). Tính chính xác tỷ lệ phần trăm máu của boss hiển thị ra thanh máu với 2 chữ số thập phân.

Ví dụ Input / Output 
Input:
Nhập máu hiện tại của Boss: 75

Output:
[THANH MÁU BOSS] 75 / 150 (50.00%)
hp_percentage.cpp 
#include <iostream>

int main() {
    const int MAX_HP = 150;
    int currentHP;

    std::cout << "Nhập máu hiện tại của Boss: ";
    std::cin >> currentHP;

    // Ép kiểu sang float trước khi chia để giữ phần thập phân
    float percent = (static_cast<float>(currentHP) / MAX_HP) * 100.0f;

    std::cout << "[THANH MÁU BOSS] " << currentHP << " / " << MAX_HP 
              << " (" << percent << "%)\n";

    return 0;
}

3. Bài tập về nhà (3 Cấp độ)

Bài 1 [Easy]: Chuyển đổi mã ký tự bàn phím sang số nguyên ASCII

Easy (40%)

Nhập vào một ký tự bất kỳ từ bàn phím (ví dụ 'A', 'z', '0'). Sử dụng static_cast<int> để in ra mã ASCII số học tương ứng của ký tự đó.

Ví dụ Input / Output 
Input:
Nhấn một phím ký tự bất kỳ: A

Output:
Ký tự 'A' có mã ASCII là: 65
ascii_converter.cpp 
#include <iostream>

int main() {
    char key;
    std::cout << "Nhấn một phím ký tự bất kỳ: ";
    std::cin >> key;

    int asciiCode = static_cast<int>(key);
    std::cout << "Ký tự '" << key << "' có mã ASCII là: " << asciiCode << "\n";
    return 0;
}

Bài 2 [Medium]: Tính chỉ số KDA trung bình trong MOBA Game

Medium (40%)

Nhập vào 3 chỉ số nguyên: Số mạng tiêu diệt kills, Số mạng hỗ trợ assists và Số lần bị hạ gục deaths. Tính chỉ số KDA theo công thức: KDA = (kills + assists) / max(1, deaths). Kết quả phải là số thực có phần thập phân.

Ví dụ Input / Output 
Input:
Nhập Kills: 7
Nhập Deaths: 2
Nhập Assists: 5

Output:
Chỉ số KDA của bạn: 6
kda_calc.cpp 
#include <iostream>

int main() {
    int kills, assists, deaths;
    std::cout << "Nhập Kills: ";
    std::cin >> kills;
    std::cout << "Nhập Deaths: ";
    std::cin >> deaths;
    std::cout << "Nhập Assists: ";
    std::cin >> assists;

    int divisor = (deaths == 0) ? 1 : deaths;
    float kda = static_cast<float>(kills + assists) / divisor;

    std::cout << "Chỉ số KDA của bạn: " << kda << "\n";
    return 0;
}

Bài 3 [Hard]: Tọa độ Camera căn giữa nhân vật màn hình 2D

Hard (20%)

Khai báo 2 hằng số màn hình const int VIEW_WIDTH = 1280 và const int VIEW_HEIGHT = 720. Nhập vào tọa độ thế giới (World Coordinate) của nhân vật: playerWorldX, playerWorldY (số thực). Tính tọa độ góc trên-trái của Camera camX, camY sao cho nhân vật luôn nằm chính giữa màn hình hiển thị.

Ví dụ Input / Output 
Input:
Nhập tọa độ nhân vật World X: 1500
Nhập tọa độ nhân vật World Y: 800

Output:
Camera cần đặt tại góc (860, 440) để nhân vật nằm giữa tâm.

Công thức: camX = playerWorldX - (VIEW_WIDTH / 2.0f); camY = playerWorldY - (VIEW_HEIGHT / 2.0f).

camera_center.cpp 
#include <iostream>

int main() {
    const int VIEW_WIDTH = 1280;
    const int VIEW_HEIGHT = 720;

    float playerWorldX, playerWorldY;
    std::cout << "Nhập tọa độ nhân vật World X: ";
    std::cin >> playerWorldX;
    std::cout << "Nhập tọa độ nhân vật World Y: ";
    std::cin >> playerWorldY;

    float camX = playerWorldX - (VIEW_WIDTH / 2.0f);
    float camY = playerWorldY - (VIEW_HEIGHT / 2.0f);

    std::cout << "\nCamera cần đặt tại góc (" << camX << ", " << camY << ") để nhân vật nằm giữa tâm.\n";
    return 0;
}
