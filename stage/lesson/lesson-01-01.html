1. Lý thuyết cốt lõi (20 Phút)

Lập trình bản chất là việc đưa ra một chuỗi chỉ thị chính xác để máy tính thực thi. Với game, máy tính sẽ liên tục tính toán tọa độ nhân vật, kiểm tra va chạm và vẽ hàng chục khung hình mỗi giây.

1.1 Quy trình thực thi mã nguồn C++

C++ là một ngôn ngữ biên dịch (Compiled Language). Khác với các ngôn ngữ thông dịch như Python, mã nguồn C++ của bạn cần trải qua trình biên dịch (Compiler) để chuyển thành mã máy nhị phân (Machine code - file .exe trên Windows) trước khi CPU có thể chạy trực tiếp với hiệu năng cực đại.

🎮 Tại sao C++ được dùng làm Game chuyên nghiệp?
C++ cung cấp khả năng can thiệp trực tiếp vào bộ nhớ RAM, không bị dừng đột ngột để dọn rác bộ nhớ (Garbage Collection Pause), giúp duy trì tốc độ khung hình ổn định 60–144 FPS cho game.

1.2 Cấu trúc chương trình C++ tối thiểu

Mỗi chương trình C++ bắt buộc phải có một hàm xuất phát điểm duy nhất là main().

main.cpp 
// Thư viện nhập xuất chuẩn
#include <iostream>

// Điểm khởi đầu của mọi chương trình C++
int main() {
    // In dòng chữ chào mừng ra màn hình console
    std::cout << "Hello, World! Chào mừng bạn đến với C++ & Raylib!" << std::endl;
    
    // Trả về 0 báo hiệu chương trình kết thúc thành công
    return 0;
}

1.3 Giải thích các thành phần:

  • #include <iostream>: Chỉ thị tiền xử lý báo cho trình biên dịch nạp thư viện Input/Output.
  • int main(): Hàm chính trả về số nguyên (int), nơi hệ điều hành bắt đầu thực thi code.
  • std::cout: Đối tượng luồng xuất dữ liệu chuẩn ra màn hình Console.
  • <<: Toán tử chèn (insertion operator), đẩy chuỗi văn bản vào luồng xuất.
  • std::endl: Xuống dòng mới và xả bộ đệm (flush buffer).
  • return 0;: Trả về mã lỗi 0 (nghĩa là chương trình chạy mượt mà, không gặp lỗi hệ thống).

3. Bài tập về nhà (Tự luyện tập)

Học viên hoàn thành các bài tập sau để củng cố thao tác gõ code và in dữ liệu định dạng chuẩn:

Bài 1 [Easy]: Vẽ phi thuyền không gian bằng ký tự (ASCII Art)

Easy (40%)

Sử dụng các lệnh std::cout để in ra hình một phi thuyền không gian đơn giản từ các ký tự ^, |, /, \ và = trên console.

Ví dụ Output 
Output:
      /\      
     /  \     
    | -- |    
    |RAY |    
   /|LIB |\   
  /_|====|_\  
    * * *

Lưu ý: Ký tự gạch chéo ngược \ trong chuỗi C++ là ký tự escape, nên khi muốn in 1 dấu \ ta phải gõ \\.

solution_bai1.cpp 
#include <iostream>

int main() {
    std::cout << "      /\\      \n";
    std::cout << "     /  \\     \n";
    std::cout << "    | -- |    \n";
    std::cout << "    |RAY |    \n";
    std::cout << "   /|LIB |\\   \n";
    std::cout << "  /_|====|_\\  \n";
    std::cout << "    * * *     \n";
    return 0;
}

Bài 2 [Medium]: In hóa đơn nạp kim cương trong Game

Medium (40%)

Viết chương trình in ra một hóa đơn thanh toán vật phẩm game gồm các cột: Tên gói, Số lượng, Đơn giá và Thành tiền được căn lề thẳng hàng đẹp mắt.

Ví dụ Output 
Output:
========================================
          HÓA ĐƠN MUA VẬT PHẨM         
========================================
Gói vật phẩm	SL	Đơn giá		Tổng
Kim Cương 500	02	100.000đ	200.000đ
Thẻ Tháng VIP	01	150.000đ	150.000đ
----------------------------------------
TỔNG CỘNG:				350.000đ
========================================

Sử dụng ký tự tab \t hoặc chuỗi khoảng trắng cố định để các cột thẳng cột với nhau.

solution_bai2.cpp 
#include <iostream>

int main() {
    std::cout << "========================================\n";
    std::cout << "          HÓA ĐƠN MUA VẬT PHẨM         \n";
    std::cout << "========================================\n";
    std::cout << "Gói vật phẩm\tSL\tĐơn giá\t\tTổng\n";
    std::cout << "Kim Cương 500\t02\t100.000đ\t200.000đ\n";
    std::cout << "Thẻ Tháng VIP\t01\t150.000đ\t150.000đ\n";
    std::cout << "----------------------------------------\n";
    std::cout << "TỔNG CỘNG:\t\t\t\t350.000đ\n";
    std::cout << "========================================\n";
    return 0;
}
