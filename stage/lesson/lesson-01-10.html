1. Lý thuyết cốt lõi (20 Phút)

1.1 Bẫy logic: Nhánh chết (Dead Code) và Điều kiện bị che khuất

Thứ tự sắp xếp các câu lệnh if - else if quyết định tính đúng đắn của logic. Nếu bạn đặt điều kiện bao hàm lên trước, các điều kiện con bên dưới sẽ không bao giờ được chạm tới!

buggy_logic.cpp 
int score = 95;

// LỖI: Điểm 95 thỏa mãn >= 50 nên nhận danh hiệu "Học sinh Khá" rồi thoát luôn!
if (score >= 50) {
    std::cout << "Khá\n";
} else if (score >= 90) {
    std::cout << "Xuất Sắc\n"; // DEAD CODE: Không bao giờ chạy tới đây!
}
🧠 Quy tắc vàng: Luôn kiểm tra từ điều kiện chặt chẽ / giá trị cao nhất xuống dần điều kiện lỏng lẻo hơn (hoặc ngược lại).

2. Thực hành tại lớp — Live Coding (45 Phút)

Thực hành: Hệ thống tính giá vé Hội chợ Game (Game Expo Ticketing)

Medium

Vé vào cổng cơ bản là 200.000đ. Tính giá vé sau khi áp dụng các chính sách:
- Trẻ em dưới 6 tuổi: Miễn phí 100%.
- Học sinh/Sinh viên (từ 6 đến 22 tuổi): Giảm 50%.
- Người cao tuổi (từ 60 tuổi trở lên): Giảm 70%.
- Nếu là thành viên VIP, giảm thêm 20.000đ trên giá vé đã tính.

ticket_pricing.cpp 
#include <iostream>

int main() {
    const int BASE_PRICE = 200000;
    int age;
    bool isVIP;

    std::cout << "Nhập tuổi của khách tham quan: ";
    std::cin >> age;
    std::cout << "Có thẻ thành viên VIP không? (1: Có, 0: Không): ";
    std::cin >> isVIP;

    int finalPrice = BASE_PRICE;

    if (age < 6) {
        finalPrice = 0;
    } else if (age <= 22) {
        finalPrice = BASE_PRICE / 2; // Giảm 50%
    } else if (age >= 60) {
        finalPrice = static_cast<int>(BASE_PRICE * 0.3f); // Giảm 70%
    }

    // Áp dụng ưu đãi VIP nếu vé lớn hơn 0
    if (isVIP && finalPrice > 20000) {
        finalPrice -= 20000;
    }

    std::cout << "\n-> Giá vé thực tế cần thanh toán: " << finalPrice << " VNĐ\n";
    return 0;
}

3. Bài tập về nhà (3 Cấp độ)

Bài 1 [Easy]: Tìm số lớn nhất trong 3 chỉ số sức mạnh (Find Max of 3)

Easy (40%)

Nhập vào 3 chỉ số: atk (Tấn công), def (Phòng ngự), agi (Nhanh nhẹn). Sử dụng các câu lệnh if để tìm ra chỉ số cao nhất và in ra thông báo tương ứng.

find_max_stat.cpp 
#include <iostream>

int main() {
    int atk, def, agi;
    std::cout << "Nhập ATK, DEF, AGI: ";
    std::cin >> atk >> def >> agi;

    int maxStat = atk;
    if (def > maxStat) maxStat = def;
    if (agi > maxStat) maxStat = agi;

    std::cout << "Chỉ số vượt trội nhất là: " << maxStat << "\n";
    return 0;
}

Bài 2 [Medium]: Game Oẳn Tù Tì 1 Lượt (Rock - Paper - Scissors)

Medium (40%)

Quy ước: 1 = Kéo, 2 = Búa, 3 = Bao. Người chơi nhập lựa chọn playerChoice, máy tính chọn botChoice = 2 (Búa). Phân định kết quả: "Hòa!", "Bạn Thắng!", hoặc "Bạn Thua!".

rock_paper_scissors.cpp 
#include <iostream>

int main() {
    int player, bot = 2; // Máy ra Búa

    std::cout << "Chọn: [1] Kéo | [2] Búa | [3] Bao: ";
    std::cin >> player;

    std::cout << "Máy tính ra: BÚA\n";

    if (player == bot) {
        std::cout << "🤝 KẾT QUẢ: HÒA NHAU!\n";
    } else if ((player == 1 && bot == 3) || 
               (player == 2 && bot == 1) || 
               (player == 3 && bot == 2)) {
        std::cout << "🎉 KẾT QUẢ: BẠN ĐÃ CHIẾN THẮNG!\n";
    } else {
        std::cout << "💀 KẾT QUẢ: BẠN ĐÃ THUA!\n";
    }

    return 0;
}

Bài 3 [Hard]: Tương tác Hệ Nguyên Tố (Elemental Weakness & Resistance)

Hard (20%)

Hệ thống gồm 3 nguyên tố: 1 = Lửa (Fire), 2 = Nước (Water), 3 = Cây (Grass). Nhập nguyên tố của người chơi và nguyên tố của quái vật.
- Tương khắc: Nước thắng Lửa, Lửa thắng Cây, Cây thắng Nước $\rightarrow$ Sát thương x2.0.
- Bị khắc chế: Sát thương giảm 50% (x0.5).
- Cùng hệ: Sát thương giữ nguyên x1.0.

Ví dụ Input / Output 
Input:
Chọn hệ nhân vật [1: Lửa, 2: Nước, 3: Cây]: 2
Nhập hệ quái vật [1: Lửa, 2: Nước, 3: Cây]: 1

Output:
🔥 ĐÒN ĐÁNH TƯƠNG KHẮC NGUYÊN TỐ (DAMAGE X2)!
Sát thương thực tế gây ra: 200 HP
elemental_combat.cpp 
#include <iostream>

int main() {
    int pElement, mElement;
    float baseDamage = 100.0f;
    float multiplier = 1.0f;

    std::cout << "Chọn hệ nhân vật [1: Lửa, 2: Nước, 3: Cây]: ";
    std::cin >> pElement;
    std::cout << "Nhập hệ quái vật [1: Lửa, 2: Nước, 3: Cây]: ";
    std::cin >> mElement;

    if (pElement == mElement) {
        multiplier = 1.0f;
    } else if ((pElement == 2 && mElement == 1) || 
               (pElement == 1 && mElement == 3) || 
               (pElement == 3 && mElement == 2)) {
        multiplier = 2.0f; // Khắc chế quái
        std::cout << "🔥 ĐÒN ĐÁNH TƯƠNG KHẮC NGUYÊN TỐ (DAMAGE X2)!\n";
    } else {
        multiplier = 0.5f; // Bị quái kháng
        std::cout << "🛡️ ĐÒN ĐÁNH BỊ KHÁNG NGUYÊN TỐ (DAMAGE GIẢM 50%)!\n";
    }

    float finalDamage = baseDamage * multiplier;
    std::cout << "Sát thương thực tế gây ra: " << finalDamage << " HP\n";

    return 0;
}
