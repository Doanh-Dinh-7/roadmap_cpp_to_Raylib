Cấu Trúc Rẽ Nhánh Else If và Switch/Case

Mục tiêu đầu ra: Làm chủ việc phân nhánh nhiều điều kiện với chuỗi else if và xây dựng hệ thống menu chọn lựa chuyên nghiệp với switch/case.

1. Lý thuyết cốt lõi (20 Phút)

1.1 Chuỗi `else if` cho bài toán khoảng giá trị

Khi có nhiều điều kiện độc lập cần kiểm tra lần lượt từ trên xuống dưới:

rank_check.cpp 
if (score >= 1000) {
    std::cout << "Hạng: Cao Thủ (Master)\n";
} else if (score >= 500) {
    std::cout << "Hạng: Kim Cương (Diamond)\n";
} else {
    std::cout << "Hạng: Tân Thủ (Bronze)\n";
}

1.2 Cấu trúc `switch/case` cho bài toán chọn lựa cụ thể

Rất thích hợp khi biến so sánh là kiểu số nguyên (int) hoặc ký tự (char) với các giá trị rời rạc cố định:

switch_demo.cpp 
switch (biến_lựa_chọn) {
    case 1:
        // Khối lệnh khi chọn 1
        break; // BẮT BUỘC: Thoát khỏi switch
    case 2:
        // Khối lệnh khi chọn 2
        break;
    default:
        // Chạy khi không khớp với bất kỳ case nào ở trên
        break;
}
⚠️ Chú ý từ khóa `break;`:
Nếu bạn quên viết break;, chương trình sẽ tiếp tục chạy tuột xuống các case bên dưới (hiện tượng Fall-through), dẫn đến hành vi sai logic nghiêm trọng trong Game Menu!

2. Thực hành tại lớp — Live Coding (45 Phút)

Thực hành: Xây dựng hệ thống Main Menu Game tương tác

Medium

Vẽ màn hình menu gồm 4 mục: [1] Bắt đầu chơi, [2] Cài đặt, [3] Giới thiệu, [4] Thoát game. Người dùng nhập số lựa chọn từ 1 đến 4, chương trình sử dụng switch/case để phản hồi màn hình tương ứng hoặc báo lỗi nếu nhập số ngoài vùng.

Ví dụ Input / Output 
Input:
Nhập lựa chọn của bạn (1-4): 1

Output:
⚔️ Đang tải thế giới... Khởi hành cuộc phiêu lưu!
main_menu.cpp 
#include <iostream>

int main() {
    int choice;

    std::cout << "======================================\n";
    std::cout << "       RAYLIB RPG CHRONICLES          \n";
    std::cout << "======================================\n";
    std::cout << "[1] Bắt đầu trò chơi mới\n";
    std::cout << "[2] Cài đặt âm thanh & đồ họa\n";
    std::cout << "[3] Bảng vàng vinh danh\n";
    std::cout << "[4] Thoát trò chơi\n";
    std::cout << "======================================\n";
    std::cout << "Nhập lựa chọn của bạn (1-4): ";
    std::cin >> choice;

    switch (choice) {
        case 1:
            std::cout << "\n⚔️ Đang tải thế giới... Khởi hành cuộc phiêu lưu!\n";
            break;
        case 2:
            std::cout << "\n⚙️ Mở bảng Cài đặt: Âm lượng 100%, Độ phân giải 1280x720.\n";
            break;
        case 3:
            std::cout << "\n🏆 Top 1 Server: DragonHunter - 99999 Pts.\n";
            break;
        case 4:
            std::cout << "\n👋 Hẹn gặp lại bạn ở chuyến hành trình tiếp theo!\n";
            break;
        default:
            std::cout << "\n❌ Lựa chọn không hợp lệ! Vui lòng chỉ nhập từ 1 đến 4.\n";
            break;
    }

    return 0;
}

3. Bài tập về nhà (3 Cấp độ)

Bài 1 [Easy]: Điều hướng phím di chuyển nhân vật (WASD Controller)

Easy (40%)

Nhập vào một ký tự phím bấm key: 'W' hoặc 'w' (Đi lên), 'S' hoặc 's' (Đi xuống), 'A' hoặc 'a' (Sang trái), 'D' hoặc 'd' (Sang phải). Sử dụng switch/case gộp nhánh để in ra hướng di chuyển tương ứng.

Ví dụ Input / Output 
Input:
Nhấn phím di chuyển (W/A/S/D): w

Output:
⬆️ Nhân vật di chuyển LÊN TRÊN
wasd_switch.cpp 
#include <iostream>

int main() {
    char key;
    std::cout << "Nhấn phím di chuyển (W/A/S/D): ";
    std::cin >> key;

    switch (key) {
        case 'W':
        case 'w':
            std::cout << "⬆️ Nhân vật di chuyển LÊN TRÊN\n";
            break;
        case 'S':
        case 's':
            std::cout << "⬇️ Nhân vật di chuyển XUỐNG DƯỚI\n";
            break;
        case 'A':
        case 'a':
            std::cout << "⬅️ Nhân vật di chuyển SANG TRÁI\n";
            break;
        case 'D':
        case 'd':
            std::cout << "➡️ Nhân vật di chuyển SANG PHẢI\n";
            break;
        default:
            std::cout << "Phím không hợp lệ!\n";
            break;
    }
    return 0;
}

Bài 2 [Medium]: Khởi tạo thuộc tính Lớp Nhân Vật (Character Class Pick)

Medium (40%)

Cho người chơi chọn 1 trong 3 lớp:
1. Warrior (Máu: 200, Công: 25, Mana: 20)
2. Mage (Máu: 80, Công: 55, Mana: 120)
3. Archer (Máu: 120, Công: 40, Mana: 50)
Áp dụng switch/case gán các biến hp, atk, mana tương ứng và in ra bảng tổng kết.

Ví dụ Input / Output 
Input:
Chọn hệ phái: [1] Warrior | [2] Mage | [3] Archer: 2

Output:
Bạn đã chọn: Pháp Sư (Mage)
❤️ HP: 80 | ⚔️ ATK: 55 | 🔮 MANA: 120
pick_class.cpp 
#include <iostream>
#include <string>

int main() {
    int choice;
    std::string className;
    int hp, atk, mana;

    std::cout << "Chọn hệ phái: [1] Warrior | [2] Mage | [3] Archer: ";
    std::cin >> choice;

    switch (choice) {
        case 1:
            className = "Chiến Binh (Warrior)";
            hp = 200; atk = 25; mana = 20;
            break;
        case 2:
            className = "Pháp Sư (Mage)";
            hp = 80; atk = 55; mana = 120;
            break;
        case 3:
            className = "Cung Thủ (Archer)";
            hp = 120; atk = 40; mana = 50;
            break;
        default:
            std::cout << "Hệ phái không tồn tại!\n";
            return 1;
    }

    std::cout << "\nBạn đã chọn: " << className << "\n";
    std::cout << "❤️ HP: " << hp << " | ⚔️ ATK: " << atk << " | 🔮 MANA: " << mana << "\n";
    return 0;
}

Bài 3 [Hard]: Máy tính bỏ túi dành cho Game Master (GM Calculator)

Hard (20%)

Nhập vào 2 số thực num1, num2 và 1 toán tử op (kiểu char: '+', '-', '*', '/'). Áp dụng switch(op) để tính và in kết quả. Với phép chia, kiểm tra điều kiện num2 == 0 để tránh lỗi sập chương trình (Divide by Zero Crash).

Ví dụ Input / Output 
Input:
Nhập biểu thức (VD: 15.5 * 3): 20 / 4

Output:
Kết quả: 5
gm_calculator.cpp 
#include <iostream>

int main() {
    float num1, num2;
    char op;

    std::cout << "Nhập biểu thức (VD: 15.5 * 3): ";
    std::cin >> num1 >> op >> num2;

    switch (op) {
        case '+':
            std::cout << "Kết quả: " << (num1 + num2) << "\n";
            break;
        case '-':
            std::cout << "Kết quả: " << (num1 - num2) << "\n";
            break;
        case '*':
            std::cout << "Kết quả: " << (num1 * num2) << "\n";
            break;
        case '/':
            if (num2 == 0) {
                std::cout << "LỖI: Không thể chia cho 0!\n";
            } else {
                std::cout << "Kết quả: " << (num1 / num2) << "\n";
            }
            break;
        default:
            std::cout << "Toán tử không hợp lệ!\n";
            break;
    }
    return 0;
}
