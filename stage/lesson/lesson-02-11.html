Mini Project: Hoàn Thiện Number Guessing Game

1. Phân tích & Thiết kế game (20 Phút)

1.1 Từ phiên bản 1 lượt đến phiên bản hoàn chỉnh

Ở Buổi 11, game chỉ cho đoán một lần rồi kết thúc. Với kiến thức vòng lặp của Giai đoạn 02, ta có thể biến nó thành một trò chơi thực thụ. Bảng dưới đây ánh xạ từng tính năng mới với kiến thức đã học:

Tính năng mới Kiến thức áp dụng Buổi học
Đoán nhiều lần đến khi đúng hoặc hết lượt Vòng lặp while + điều kiện dừng kép Buổi 12
Kiểm tra số nhập nằm trong khoảng hợp lệ Vòng lặp do-while kiểm tra đầu vào Buổi 15

1.2 Bảng cấu hình độ khó

Cấp độ Khoảng số bí mật Số lượt tối đa Hệ số điểm
1. Dễ1 – 5010×1
2. Thường1 – 1007×2
3. Khó1 – 5009×3

Công thức điểm một ván thắng: score = (maxTries - tries + 1) * 10 * multiplier. Đoán đúng càng sớm → còn dư càng nhiều lượt → điểm càng cao. Thua ván thì được 0 điểm.

1.3 Flowchart tổng thể (Game Loop console)

📋 Luồng chạy chương trình:
  1. START → khởi tạo bộ sinh số ngẫu nhiên srand(time(0)), totalScore = 0.
  2. [Vòng ván chơi — do-while] Hiện menu, nhập độ khó (lặp lại nếu không phải 1–3).
  3. Gán maxNumber, maxTries, multiplier theo độ khó; sinh secret.
  4. [Vòng đoán — while] Còn lượt? → nhập guess (kiểm tra hợp lệ) → so sánh:
    • guess < secret → "Lớn hơn!"
    • guess > secret → "Nhỏ hơn!"
    • guess == secret → tính điểm, break
  5. Hết lượt mà chưa đúng → in đáp án, ván thua.
  6. Hỏi "Chơi tiếp? (y/n)" → y quay lại bước 2, n → in tổng kết → END.
🎮 Mẹo tư duy Game: Mọi game — từ console đến Raylib — đều có cùng khung: vòng lặp ngoài giữ chương trình sống (game loop / menu), vòng lặp trong xử lý từng lượt chơi. Ở Giai đoạn 06, vòng while (!WindowShouldClose()) của Raylib chính là vòng ngoài này, chạy 60 lần mỗi giây.
⚠️ Bẫy nhập liệu: Nếu người chơi gõ chữ thay vì số, std::cin rơi vào trạng thái lỗi và các lần đọc tiếp theo bị bỏ qua → vòng lặp vô hạn. Cách xử lý: kiểm tra if (!(std::cin >> x)), rồi gọi std::cin.clear() và std::cin.ignore(1000, '\n') để dọn bộ đệm.

2. Bài tập trên lớp — Xây dựng game từng bước (50 Phút)

Bước 1: Vòng đoán có giới hạn lượt

Trên lớp

Đề bài: Sinh số bí mật từ 1 đến 100. Cho người chơi đoán tối đa 7 lần, mỗi lần gợi ý "Lớn hơn" / "Nhỏ hơn". Đoán đúng thì thông báo số lần đã đoán và dừng ngay.

step1_guess_loop.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    srand(time(0));
    const int MAX_TRIES = 7;
    int secret = rand() % 100 + 1;
    int guess = 0;
    int tries = 0;
    bool won = false;

    while (tries < MAX_TRIES) {
        std::cout << "Luot " << tries + 1 << "/" << MAX_TRIES << " - Nhap so: ";
        std::cin >> guess;
        tries++;

        if (guess == secret) {
            won = true;
            break;                        // Dung -> thoat vong ngay
        } else if (guess < secret) {
            std::cout << "Lon hon!\n";
        } else {
            std::cout << "Nho hon!\n";
        }
    }

    if (won) {
        std::cout << "Chinh xac! Ban doan dung sau " << tries << " lan.\n";
    } else {
        std::cout << "Het luot! So bi mat la " << secret << ".\n";
    }
    return 0;
}
Vì sao cần biến won? Sau vòng lặp, tries == MAX_TRIES có thể xảy ra cả khi người chơi đoán đúng ở lượt cuối. Dùng cờ won giúp phân biệt rõ "thắng" và "hết lượt" mà không phải so sánh lại.

Bước 2: Kiểm tra đầu vào hợp lệ bằng do-while

Trên lớp

Đề bài: Thay dòng std::cin >> guess; bằng đoạn lặp yêu cầu nhập lại khi số nằm ngoài khoảng 1..maxNumber hoặc người chơi gõ chữ. Lượt nhập sai không bị tính vào số lần đoán.

step2_validate.cpp (đoạn thay thế) 
bool valid = false;
do {
    std::cout << "Nhap so (1-" << maxNumber << "): ";
    if (!(std::cin >> guess)) {             // Go chu -> cin bi loi
        std::cin.clear();                     // Xoa trang thai loi
        std::cin.ignore(1000, '\n');         // Bo phan rac trong bo dem
        std::cout << "Vui long nhap mot so nguyen!\n";
    } else if (guess < 1 || guess > maxNumber) {
        std::cout << "So phai nam trong khoang 1-" << maxNumber << "!\n";
    } else {
        valid = true;
    }
} while (!valid);
tries++;                                       // Chi tinh luot khi nhap hop le

Bước 3: Ghép hoàn chỉnh — Độ khó, nhiều ván, tính điểm

Mini Project

Đề bài: Bọc toàn bộ phần chơi trong vòng do-while "Chơi tiếp?". Mỗi ván cho chọn độ khó bằng switch, tính điểm theo công thức ở mục 1.2 và cộng dồn vào totalScore. Khi thoát, in tổng kết: số ván, số ván thắng, tổng điểm.

guess_game_v2.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    srand(time(0));
    int totalScore = 0, rounds = 0, wins = 0;
    char again;

    std::cout << "===== NUMBER GUESSING GAME v2 =====\n";

    do {                                                // VONG NGOAI: moi van choi
        // --- 1. Chon do kho (lap den khi hop le) ---
        int level = 0;
        do {
            std::cout << "\nChon do kho: 1-De  2-Thuong  3-Kho : ";
            if (!(std::cin >> level)) {
                std::cin.clear();
                std::cin.ignore(1000, '\n');
                level = 0;
            }
        } while (level < 1 || level > 3);

        int maxNumber, maxTries, multiplier;
        switch (level) {
            case 1:  maxNumber = 50;  maxTries = 10; multiplier = 1; break;
            case 2:  maxNumber = 100; maxTries = 7;  multiplier = 2; break;
            default: maxNumber = 500; maxTries = 9;  multiplier = 3; break;
        }

        int secret = rand() % maxNumber + 1;
        int tries = 0, guess = 0;
        bool won = false;
        rounds++;
        std::cout << "Toi da nghi mot so tu 1 den " << maxNumber
                  << ". Ban co " << maxTries << " luot.\n";

        // --- 2. Vong doan ---
        while (tries < maxTries) {                           // VONG TRONG: moi luot doan
            bool valid = false;
            do {
                std::cout << "[Luot " << tries + 1 << "/" << maxTries << "] Nhap so: ";
                if (!(std::cin >> guess)) {
                    std::cin.clear();
                    std::cin.ignore(1000, '\n');
                    std::cout << "Vui long nhap so nguyen!\n";
                } else if (guess < 1 || guess > maxNumber) {
                    std::cout << "Ngoai khoang 1-" << maxNumber << "!\n";
                } else {
                    valid = true;
                }
            } while (!valid);
            tries++;

            if (guess == secret) { won = true; break; }
            if (guess < secret) std::cout << "  -> Lon hon!\n";
            else                std::cout << "  -> Nho hon!\n";
        }

        // --- 3. Ket qua van ---
        if (won) {
            int score = (maxTries - tries + 1) * 10 * multiplier;
            totalScore += score;
            wins++;
            std::cout << "CHINH XAC! Doan dung sau " << tries
                      << " lan. +" << score << " diem.\n";
        } else {
            std::cout << "HET LUOT! So bi mat la " << secret << ".\n";
        }
        std::cout << "Tong diem hien tai: " << totalScore << "\n";

        std::cout << "Choi tiep? (y/n): ";
        std::cin >> again;
    } while (again == 'y' || again == 'Y');

    // --- 4. Tong ket ---
    std::cout << "\n===== TONG KET =====\n";
    std::cout << "So van: " << rounds << " | Thang: " << wins
              << " | Tong diem: " << totalScore << "\n";
    std::cout << "Cam on ban da choi!\n";
    return 0;
}
🎯 Kiểm thử bắt buộc trước khi nộp: (1) Đoán đúng ở lượt 1; (2) Đoán đúng ở lượt cuối cùng; (3) Thua hết lượt; (4) Nhập chữ abc; (5) Nhập số ngoài khoảng; (6) Chọn độ khó 0 hoặc 4; (7) Chơi 3 ván liên tiếp rồi kiểm tra tổng điểm.

3. Bài tập về nhà (Mở rộng game)

Học viên chọn làm cả 3 bài để hoàn thiện sản phẩm cuối Giai đoạn 02:

Bài 1 [Easy]: Gợi ý "Nóng / Lạnh"

Easy (40%)

Ngoài gợi ý "Lớn hơn / Nhỏ hơn", thêm thông báo độ gần: nếu khoảng cách |guess - secret| <= 5 in "Rat nong!", <= 15 in "Nong", còn lại in "Lanh".

Gợi ý: Tự tính trị tuyệt đối bằng if (chưa cần thư viện), đặt đoạn này ngay sau gợi ý Lớn/Nhỏ trong vòng đoán.

hot_cold.cpp (đoạn thêm vào) 
int distance = guess - secret;
if (distance < 0) distance = -distance;     // Tri tuyet doi

if (distance <= 5) {
    std::cout << "  (Rat nong!)\n";
} else if (distance <= 15) {
    std::cout << "  (Nong)\n";
} else {
    std::cout << "  (Lanh)\n";
}

Bài 2 [Medium]: Kỷ lục & Thu hẹp khoảng gợi ý

Medium (40%)

(a) Lưu bestTries — số lượt ít nhất mà người chơi từng thắng trong phiên chơi; khi phá kỷ lục in "KY LUC MOI!".
(b) Sau mỗi lần đoán sai, in khoảng còn khả thi, ví dụ "So bi mat nam trong [38, 100]", bằng cách cập nhật hai biến low và high.

Phân tích: Khởi tạo bestTries ngoài vòng ván chơi (để giữ qua nhiều ván) với giá trị lớn bất kỳ, ví dụ 9999. Còn low/high phải khởi tạo trong mỗi ván vì mỗi ván có số bí mật mới.

record_range.cpp (các đoạn thêm vào) 
// Truoc vong do-while van choi:
int bestTries = 9999;

// Dau moi van, sau khi sinh secret:
int low = 1, high = maxNumber;

// Trong vong doan, thay phan goi y:
if (guess < secret) {
    std::cout << "  -> Lon hon!\n";
    if (guess + 1 > low) low = guess + 1;
} else {
    std::cout << "  -> Nho hon!\n";
    if (guess - 1 < high) high = guess - 1;
}
std::cout << "  So bi mat nam trong [" << low << ", " << high << "]\n";

// Trong nhanh thang (if won):
if (tries < bestTries) {
    bestTries = tries;
    std::cout << "KY LUC MOI: " << bestTries << " luot!\n";
}

Bài 3 [Hard]: Đổi vai — Máy tính đoán số của bạn

Hard (20%)

Người chơi nghĩ một số từ 1 đến 100 (không nhập vào máy). Máy đoán, người chơi trả lời bằng ký tự: l (số của tôi lớn hơn), n (nhỏ hơn), d (đúng). Máy phải luôn đoán ra trong tối đa 7 lượt. Nếu người chơi trả lời mâu thuẫn (khoảng còn lại rỗng) → in "Ban gian lan roi!".

Gợi ý thuật toán: Luôn đoán số ở giữa khoảng mid = (low + high) / 2. Mỗi câu trả lời loại bỏ một nửa khoảng → 100 → 50 → 25 → 13 → 7 → 4 → 2 → 1, tức 7 lượt là đủ. Đây chính là ý tưởng Tìm kiếm nhị phân (Binary Search) mà bạn sẽ gặp lại ở Giai đoạn 03.
computer_guess.cpp 
#include <iostream>

int main() {
    int low = 1, high = 100, tries = 0;
    char answer;
    std::cout << "Hay nghi mot so tu 1 den 100. May se doan!\n";

    while (true) {
        if (low > high) {                        // Khoang rong -> tra loi mau thuan
            std::cout << "Ban gian lan roi!\n";
            break;
        }
        int mid = (low + high) / 2;
        tries++;
        std::cout << "Lan " << tries << ": May doan " << mid
                  << ". (l = lon hon, n = nho hon, d = dung): ";

        do {
            std::cin >> answer;
        } while (answer != 'l' && answer != 'n' && answer != 'd');

        if (answer == 'd') {
            std::cout << "May doan dung sau " << tries << " lan!\n";
            break;
        } else if (answer == 'l') {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }
    return 0;
}
💡 Vì sao luôn ≤ 7 lượt? Vì 27 = 128 ≥ 100. Mỗi lượt chia đôi khoảng tìm kiếm, nên sau 7 lượt khoảng chỉ còn tối đa 1 số.
