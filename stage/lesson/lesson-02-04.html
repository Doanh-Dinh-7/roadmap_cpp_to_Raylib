Vòng Lặp do-while

Mục tiêu đầu ra: Nắm vững cú pháp do-while, hiểu điểm khác biệt "chạy ít nhất 1 lần", áp dụng validate đầu vào và xây dựng menu game console hoàn chỉnh.

1. Lý thuyết cốt lõi (20 Phút)

Vòng lặp do-while là biến thể đặc biệt: thân lặp luôn chạy ít nhất 1 lần dù điều kiện sai ngay từ đầu. Điều này làm nó trở thành lựa chọn hoàn hảo cho các tình huống "làm trước, hỏi sau".

1.1 Cú pháp do-while

⚠️ Chú ý quan trọng: Vòng lặp do-while bắt buộc có dấu chấm phẩy ; sau dấu ngoặc đóng ) ở cuối. Thiếu dấu này sẽ gây lỗi biên dịch!
Cú pháp 
do {
    /* thân lặp — chạy ÍT NHẤT 1 LẦN */
} while (condition); // <-- dau ; bat buoc!

1.2 So sánh 3 vòng lặp

Bảng so sánh 3 vòng lặp:
Vòng lặp Kiểm tra điều kiện Chạy ít nhất
while Trước thân lặp 0 lần
for Trước thân lặp 0 lần
do-while Sau thân lặp 1 lần

1.3 Ứng dụng: Validate đầu vào

Trường hợp điển hình nhất của do-while: hiển thị yêu cầu, nhận đầu vào, kiểm tra — nếu sai thì hỏi lại. Người dùng bắt buộc phải nhập ít nhất một lần.

validate_dau_vao.cpp 
int choice;
do {
    std::cout << "Chon do kho (1-3): ";
    std::cin >> choice;
    if (choice < 1 || choice > 3) {
        std::cout << "Lua chon khong hop le!\n";
    }
} while (choice < 1 || choice > 3);
std::cout << "Da chon do kho: " << choice << std::endl;

1.4 Ứng dụng Game: Menu chính console

🎮 Kết nối Game Dev: Màn hình menu chính của game luôn hiển thị ít nhất 1 lần trước khi nhận lựa chọn. do-while là cấu trúc tự nhiên nhất cho vòng lặp menu!
menu_game.cpp 
int option;
do {
    std::cout << "\n=== MENU GAME ===" << std::endl;
    std::cout << "1. Choi moi" << std::endl;
    std::cout << "2. Xem bang diem" << std::endl;
    std::cout << "0. Thoat" << std::endl;
    std::cout << "Lua chon: ";
    std::cin >> option;
    if (option == 1) std::cout << "Bat dau tro choi!\n";
    else if (option == 2) std::cout << "Bang diem: (chua co)\n";
} while (option != 0);
std::cout << "Hen gap lai!\n";

2. Bài tập trên lớp — Live Coding (40 Phút)

Thực hành: Mô phỏng ATM đơn giản

Trên lớp

Viết chương trình ATM đơn giản với số dư ban đầu 2.000.000 đồng. Liên tục hỏi số tiền muốn rút — điều kiện hợp lệ: phải chia hết cho 50.000 và không vượt quá số dư. Dùng do-while để validate từng lần nhập. Cập nhật số dư sau mỗi lần rút thành công.

Gợi ý:
• Kiểm tra amount % 50000 == 0 để đảm bảo chia hết
• Kiểm tra amount <= balance để không vượt số dư
• Dùng do-while bên trong để validate, while (tiep_tuc) bên ngoài để hỏi rút tiếp không
atm_don_gian.cpp 
#include <iostream>

int main() {
    int balance = 2000000;
    char tiep;
    do {
        std::cout << "So du hien tai: " << balance << " dong\n";
        int amount;
        do {
            std::cout << "Nhap so tien muon rut (boi so 50000): ";
            std::cin >> amount;
            if (amount % 50000 != 0)
                std::cout << "Phai la boi so cua 50.000!\n";
            else if (amount > balance)
                std::cout << "Vuot qua so du!\n";
        } while (amount % 50000 != 0 || amount > balance);
        balance -= amount;
        std::cout << "Da rut: " << amount << " dong. Con lai: " << balance << " dong\n";
        std::cout << "Rut tiep? (y/n): ";
        std::cin >> tiep;
    } while (tiep == 'y' && balance > 0);
    std::cout << "Cam on quy khach!\n";
    return 0;
}

3. Bài tập về nhà (Tự luyện tập)

Học viên hoàn thành các bài tập sau để nắm vững vòng lặp do-while:

Bài 1 [Easy]: Nhập mật khẩu đến khi đúng

Easy (40%)

Dùng do-while để liên tục nhập mật khẩu đến khi người dùng nhập đúng chuỗi "12345". In thông báo thành công khi nhập đúng.

Mẹo: Dùng kiểu std::string để so sánh chuỗi, nhớ #include <string>.

nhap_mat_khau.cpp 
#include <iostream>
#include <string>

int main() {
    std::string pwd;
    do {
        std::cout << "Nhap mat khau: ";
        std::cin >> pwd;
        if (pwd != "12345")
            std::cout << "Sai mat khau! Thu lai.\n";
    } while (pwd != "12345");
    std::cout << "Dang nhap thanh cong!\n";
    return 0;
}

Bài 2 [Medium]: Chương trình "Chơi lại?"

Medium (40%)

Viết chương trình game đơn giản (chỉ in "Ban da choi 1 van!"). Sau mỗi ván, hỏi "Choi lai? (y/n):". Dùng do-while bọc toàn bộ logic, lặp lại khi người dùng nhập 'y'.

Ý tưởng: do { /* logic game */ cout << "Choi lai? (y/n): "; cin >> again; } while (again == 'y');

choi_lai.cpp 
#include <iostream>

int main() {
    char again;
    int vanCount = 0;
    do {
        vanCount++;
        std::cout << "Ban da choi van thu " << vanCount << "!\n";
        std::cout << "Choi lai? (y/n): ";
        std::cin >> again;
    } while (again == 'y');
    std::cout << "Da choi " << vanCount << " van. Tam biet!\n";
    return 0;
}

Bài 3 [Hard]: Máy tính console với validate chia cho 0

Hard (20%)

Tạo máy tính console: nhập 2 số và phép tính (+, -, *, /), hiển thị kết quả. Validate chia cho 0. Hỏi "Tính tiếp?" ở cuối. Dùng do-while bọc ngoài và switch-case cho phép tính.

Ý tưởng: Dùng do-while bọc ngoài, bên trong dùng switch-case cho op, kiểm tra b != 0 trước khi chia.

may_tinh_console.cpp 
#include <iostream>

int main() {
    char tiep;
    do {
        double a, b;
        char op;
        std::cout << "Nhap: a op b (vd: 5 + 3): ";
        std::cin >> a >> op >> b;
        switch (op) {
            case '+': std::cout << "= " << a + b << "\n"; break;
            case '-': std::cout << "= " << a - b << "\n"; break;
            case '*': std::cout << "= " << a * b << "\n"; break;
            case '/':
                if (b != 0) std::cout << "= " << a / b << "\n";
                else std::cout << "Loi: Khong chia duoc cho 0!\n";
                break;
            default: std::cout << "Phep tinh khong hop le!\n";
        }
        std::cout << "Tinh tiep? (y/n): ";
        std::cin >> tiep;
    } while (tiep == 'y');
    std::cout << "Tam biet!\n";
    return 0;
}
