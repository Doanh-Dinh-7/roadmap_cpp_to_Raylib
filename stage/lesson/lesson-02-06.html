1. Lý thuyết cốt lõi — Kỹ thuật vẽ hình ký tự (20 Phút)

Vẽ hình bằng ký tự là bài tập kinh điển giúp rèn luyện tư duy lập trình 2D. Vòng ngoài điều khiển hàng (row), vòng trong điều khiển cột (column). Mỗi hình tương ứng một công thức điều kiện khác nhau.

1.1 Bảng Tổng Hợp Các Hình & Công Thức

Hình Công thức (hàng i từ 1→n) Mô tả
Chữ nhật đặc j từ 1→m: luôn in * n hàng, mỗi hàng m dấu *
Tam giác vuông j từ 1→i: in * Hàng i in i dấu *
Tam giác cân (n-i) cách + (2i-1) dấu * Căn giữa, hàng n có 2n-1 dấu *
Kim cương Tam giác cân + tam giác cân ngược 2n-1 hàng tổng

1.2 Code Mẫu: Tam Giác Vuông Trái

right_triangle.cpp 
int n = 5;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        std::cout << "* ";
    }
    std::cout << "\n";
}
// Output:
// *
// * *
// * * *
// * * * *
// * * * * *

1.3 Code Mẫu: Tam Giác Cân

isosceles_triangle.cpp 
int n = 5;
for (int i = 1; i <= n; i++) {
    // In khoang trang ben trai
    for (int j = 1; j <= n - i; j++) std::cout << " ";
    // In dau sao (2*i - 1 dau)
    for (int j = 1; j <= 2 * i - 1; j++) std::cout << "*";
    std::cout << "\n";
}
// Output:
//     *
//    ***
//   *****
//  *******
// *********
💡 Liên hệ Game Dev: Hiểu cách render từng ô theo hàng/cột chính là nền tảng để hiểu tilemap rendering, pixel art và hệ thống vẽ lưới trong Raylib sau này. Mỗi vòng lặp lồng nhau = một lần quét toàn bộ lưới màn hình!

2. Bài tập trên lớp (25 Phút)

Vẽ Hình Chữ Nhật Rỗng Nhập Từ Bàn Phím

Thực hành

Đề bài: Nhập vào chiều rộng w và chiều cao h từ bàn phím. Vẽ hình chữ nhật rỗng (chỉ in viền) kích thước w × h: ô viền in #, ô bên trong in dấu cách.

Ví dụ: w=8, h=4 
########
#      #
#      #
########
hollow_rectangle.cpp 
#include <iostream>

int main() {
    int w, h;
    std::cout << "Nhap chieu rong (w): "; std::cin >> w;
    std::cout << "Nhap chieu cao  (h): "; std::cin >> h;

    for (int i = 0; i < h; i++) {
        for (int j = 0; j < w; j++) {
            if (i == 0 || i == h - 1 || j == 0 || j == w - 1) {
                std::cout << '#';
            } else {
                std::cout << ' ';
            }
        }
        std::cout << "\n";
    }
    return 0;
}

3. Bài tập về nhà (Tự luyện tập)

Hoàn thành 3 bài tập sau ở nhà, nộp trước buổi học tiếp theo:

Bài 1 [Easy]: Tam Giác Vuông Ngược

Easy (40%)

Vẽ tam giác vuông ngược: hàng 1 có nhiều dấu * nhất (n dấu), hàng n chỉ có 1 dấu. Nhập n từ bàn phím.

Ví dụ Output (n=5) 
* * * * *
* * * *
* * *
* *
*
solution_easy.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap n: "; std::cin >> n;

    for (int i = n; i >= 1; i--) {
        for (int j = 1; j <= i; j++) {
            std::cout << "* ";
        }
        std::cout << "\n";
    }
    return 0;
}
💡 Mẹo: Chỉ cần đổi chiều vòng ngoài: thay i = 1; i <= n; i++ thành i = n; i >= 1; i--.

Bài 2 [Medium]: Hình Kim Cương

Medium (40%)

Vẽ hình kim cương với n hàng phần trên và n-1 hàng phần dưới (tổng 2n-1 hàng). Nhập n từ bàn phím.

Ví dụ Output (n=4) 
   *
  ***
 *****
*******
 *****
  ***
   *
solution_medium.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap n: "; std::cin >> n;

    // Nua tren (n hang): i tu 1 den n
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) std::cout << " ";
        for (int j = 1; j <= 2 * i - 1; j++) std::cout << "*";
        std::cout << "\n";
    }

    // Nua duoi (n-1 hang): i tu n-1 ve 1
    for (int i = n - 1; i >= 1; i--) {
        for (int j = 1; j <= n - i; j++) std::cout << " ";
        for (int j = 1; j <= 2 * i - 1; j++) std::cout << "*";
        std::cout << "\n";
    }

    return 0;
}

Bài 3 [Hard]: Mê Cung Đơn Giản 7×15

Hard (20%)

Vẽ "mê cung đơn giản" 7 hàng × 15 cột: biên là #. Bên trong tạo một hành lang đơn giản: hàng 3 (giữa) in toàn ., cột 7 (giữa) của mỗi hàng bên trong cũng in .. Phần còn lại in #.

Ví dụ Output (7×15) 
###############
######.########
######.########
...............
######.########
######.########
###############
solution_hard.cpp 
#include <iostream>

int main() {
    const int ROWS = 7;
    const int COLS = 15;
    const int MID_ROW = ROWS / 2;   // = 3 (hang giua)
    const int MID_COL = COLS / 2;   // = 7 (cot giua)

    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLS; j++) {
            // O bien
            if (i == 0 || i == ROWS - 1 || j == 0 || j == COLS - 1) {
                std::cout << '#';
            }
            // Hang di ngang (hanh lang ngang)
            else if (i == MID_ROW) {
                std::cout << '.';
            }
            // Cot di doc (hanh lang doc)
            else if (j == MID_COL) {
                std::cout << '.';
            }
            else {
                std::cout << '#';
            }
        }
        std::cout << "\n";
    }
    return 0;
}
💡 Mở rộng: Bạn có thể thêm nhiều hành lang bằng cách thêm điều kiện || i == X || j == Y. Đây chính là cách đơn giản nhất để "vẽ" layout của một màn chơi trước khi code game thực sự!
