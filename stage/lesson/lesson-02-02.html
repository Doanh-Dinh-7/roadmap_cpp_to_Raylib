Vòng Lặp For

Mục tiêu đầu ra: Nắm vững cú pháp for 3 phần, phân biệt khi nào dùng for hay while, áp dụng in bảng điểm top 10 và bảng cửu chương trong game.

1. Lý thuyết cốt lõi (20 Phút)

Vòng lặp for là lựa chọn tốt nhất khi bạn biết trước số lần lặp. Nó gộp 3 bước (khởi tạo, kiểm tra, cập nhật) vào một dòng duy nhất, giúp code ngắn gọn và dễ đọc hơn.

1.1 Cú pháp vòng lặp for 3 phần

Cú pháp 
for (init; condition; update) {
    /* thân lặp */
}
// init    : khởi tạo biến đếm, chạy 1 lần duy nhất
// condition: kiểm tra trước mỗi vòng, false thì thoát
// update  : cập nhật biến đếm sau mỗi vòng
for_co_ban.cpp 
for (int i = 0; i < 5; i++) {
    std::cout << "i = " << i << std::endl;
}
// Bien i chi ton tai trong block for — an toan, khong gay xung dot

1.2 So sánh while vs for

Bảng so sánh:
Tình huống while for
Số lần lặp không biết trước ✓
Số lần lặp biết trước ✓
Lặp đến khi người dùng thoát ✓
Duyệt từ 0 đến n-1 ✓

1.3 Ứng dụng Game: In bảng điểm top 5

🎮 Kết nối Game Dev: Vòng lặp for thường dùng để vẽ n kẻ thù, in bảng điểm top 10, tạo thanh HP nhiều ô, duyệt danh sách vật phẩm trong túi đồ.
bang_diem_cao.cpp 
int scores[] = {980, 750, 620, 500, 340};
std::cout << "=== BANG DIEM CAO ===" << std::endl;
for (int rank = 0; rank < 5; rank++) {
    std::cout << "Hang " << (rank + 1) << ": " << scores[rank] << " diem" << std::endl;
}

2. Bài tập trên lớp — Live Coding (40 Phút)

Thực hành: In bảng cửu chương

Trên lớp

Viết chương trình nhập số n từ bàn phím (1 ≤ n ≤ 9), dùng vòng lặp for để in bảng cửu chương của số đó từ 1 đến 10.

Gợi ý: Vòng lặp chạy từ i = 1 đến i <= 10. Kết quả mỗi dòng là n * i.
cuu_chuong.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap so (1-9): ";
    std::cin >> n;
    std::cout << "=== Bang cuu chuong " << n << " ===" << std::endl;
    for (int i = 1; i <= 10; i++) {
        std::cout << n << " x " << i << " = " << n * i << std::endl;
    }
    return 0;
}

3. Bài tập về nhà (Tự luyện tập)

Học viên hoàn thành các bài tập sau để nắm vững vòng lặp for:

Bài 1 [Easy]: In số chẵn từ 2 đến 20

Easy (40%)

Dùng vòng lặp for để in tất cả các số chẵn từ 2 đến 20 ra màn hình, cách nhau bởi dấu cách.

Mẹo: Bước nhảy i += 2 thay vì i++ để bỏ qua số lẻ.

so_chan.cpp 
#include <iostream>

int main() {
    for (int i = 2; i <= 20; i += 2) {
        std::cout << i << " ";
    }
    std::cout << std::endl;
    return 0;
}

Bài 2 [Medium]: Tính n! giai thừa

Medium (40%)

Nhập số nguyên n từ bàn phím (n ≤ 12), dùng vòng lặp for tính n! (giai thừa) và in kết quả.

Lưu ý: Dùng long long để chứa giá trị lớn (12! = 479.001.600).

giai_thua.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap n (n <= 12): ";
    std::cin >> n;
    long long fact = 1;
    for (int i = 1; i <= n; i++) fact *= i;
    std::cout << n << "! = " << fact << std::endl;
    return 0;
}

Bài 3 [Hard]: Vẽ hình tam giác vuông bằng dấu *

Hard (20%)

Nhập số nguyên n từ bàn phím. Dùng vòng lặp for lồng nhau để vẽ hình tam giác vuông: hàng 1 có 1 dấu *, hàng 2 có 2 dấu *, ..., hàng n có n dấu *.

Ý tưởng: Vòng lặp ngoài chạy theo hàng (i từ 1 đến n), vòng lặp trong chạy theo cột (j từ 1 đến i).

tam_giac.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap so hang n: ";
    std::cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) std::cout << "* ";
        std::cout << "\n";
    }
    return 0;
}
