Hàm (Functions) Cơ Bản: Định Nghĩa và Gọi Hàm

Mục tiêu đầu ra: Hiểu hàm là gì và vì sao cần hàm; tự định nghĩa và gọi hàm void, viết nguyên mẫu (prototype) đúng chỗ; tách các khối lệnh lặp lại trong chương trình thành các hàm riêng có tên rõ nghĩa.

1. Lý thuyết cốt lõi (35 Phút)

1.1 Vì sao cần Hàm?

Nhìn lại game đoán số ở Buổi 22: hàm main() dài hơn 70 dòng, đoạn kiểm tra đầu vào bị viết lặp lại ở nhiều chỗ, muốn sửa một lỗi thì phải sửa ở 2–3 nơi. Khi chương trình lớn dần, cách viết "dồn hết vào main" sẽ nhanh chóng trở nên khó đọc và khó sửa.

Hàm (Function) là một khối lệnh được đặt tên, thực hiện một nhiệm vụ cụ thể, và có thể được gọi lại nhiều lần ở bất kỳ đâu. Thực ra bạn đã dùng hàm từ lâu: main(), rand(), srand(), time() đều là hàm. Hôm nay bạn sẽ tự viết hàm của mình.

  • Tái sử dụng: Viết một lần, gọi nhiều lần (nguyên tắc DRY — Don't Repeat Yourself).
  • Dễ đọc: main chỉ còn là "mục lục" gồm các lời gọi hàm có tên rõ nghĩa.
  • Dễ sửa: Sửa lỗi ở một chỗ, mọi nơi gọi hàm đều được cập nhật.

1.2 Cấu trúc một hàm

function_anatomy.cpp 
// kieu_tra_ve  ten_ham ( danh_sach_tham_so )
void printLine() {                 // Dau ham (function header)
    std::cout << "====================\n";   // Than ham (function body)
}
  • Kiểu trả về: void nghĩa là hàm chỉ làm việc, không gửi lại giá trị nào. (Hàm trả về giá trị sẽ học ở Buổi 24.)
  • Tên hàm: Đặt theo quy tắc như tên biến; nên là động từ mô tả việc làm: printLine, showMenu, drawMap.
  • Cặp ngoặc (): Chứa danh sách tham số. Hôm nay ta dùng hàm không tham số nên để trống.
  • Thân hàm { }: Các câu lệnh sẽ chạy mỗi khi hàm được gọi.

1.3 Bảng tóm tắt cú pháp

Thao tác Cú pháp Ghi chú
Định nghĩa hàm void showMenu() { ... } Viết bên ngoài mọi hàm khác (không lồng trong main)
Gọi hàm showMenu(); Bắt buộc có () và dấu ;
Khai báo nguyên mẫu (prototype) void showMenu(); Chỉ có đầu hàm + dấu ;, đặt trên main
Thoát hàm void sớm return; Kết thúc hàm ngay, quay về chỗ gọi
Hàm gọi hàm void showTitle() { printLine(); ... } Hàm được gọi phải được khai báo trước

1.4 Luồng chạy khi gọi hàm

Chương trình luôn bắt đầu từ main(). Khi gặp lời gọi hàm, máy tính "nhảy" vào thân hàm, chạy hết, rồi quay lại đúng vị trí đã gọi để chạy tiếp.

call_flow.cpp 
#include <iostream>

void printLine() {
    std::cout << "--------------------\n";
}

void showTitle() {
    printLine();                        // Ham goi ham
    std::cout << "   DUNGEON QUEST\n";
    printLine();
}

int main() {
    std::cout << "Dang khoi dong game...\n";   // (1)
    showTitle();                                // (2) nhay vao showTitle
    std::cout << "Nhan Enter de bat dau!\n";   // (3) quay ve chay tiep
    return 0;
}
📋 Thứ tự in ra màn hình:
  1. main in "Dang khoi dong game...".
  2. main gọi showTitle() → showTitle gọi printLine() in dòng gạch → quay về showTitle in tên game → gọi printLine() lần nữa.
  3. showTitle chạy xong → quay về main in "Nhan Enter de bat dau!".

1.5 Thứ tự khai báo & Nguyên mẫu hàm (Prototype)

Trình biên dịch đọc file từ trên xuống dưới. Nếu main gọi một hàm được định nghĩa phía dưới nó, trình biên dịch sẽ báo lỗi 'showMenu' was not declared in this scope. Có hai cách xử lý: (1) định nghĩa hàm phía trên main, hoặc (2) viết nguyên mẫu ở đầu file — giống như "mục lục" báo trước rằng hàm này tồn tại.

prototype_demo.cpp 
#include <iostream>

// ===== NGUYEN MAU HAM (PROTOTYPE) =====
void showMenu();
void showHelp();

// ===== HAM MAIN: doc nhu muc luc =====
int main() {
    showMenu();
    showHelp();
    return 0;
}

// ===== DINH NGHIA HAM =====
void showMenu() {
    std::cout << "1. Choi moi\n";
    std::cout << "2. Huong dan\n";
    std::cout << "0. Thoat\n";
}

void showHelp() {
    std::cout << "Dung W A S D de di chuyen.\n";
}

Cách (2) được dùng phổ biến vì main nằm ở đầu file, người đọc nhìn vào là hiểu ngay chương trình làm gì mà chưa cần xem chi tiết từng hàm.

🎮 Mẹo tư duy Game: Một game Raylib (Giai đoạn 06) trông giống hệt "mục lục" này: InitWindow(), BeginDrawing(), DrawText(), EndDrawing()... đều là hàm do người khác viết sẵn. Khi tự làm game, bạn sẽ chia code thành updatePlayer(), drawMap(), drawHUD() — mỗi hàm lo đúng một phần của khung hình.
⚠️ Lỗi thường gặp:
  • Quên () khi gọi: viết showMenu; — hàm không được gọi, chương trình im lặng không in gì.
  • Định nghĩa hàm bên trong main: C++ không cho phép lồng định nghĩa hàm → lỗi biên dịch.
  • Thêm ; sau đầu hàm khi định nghĩa: void showMenu(); { ... } → khối { } bị tách rời, lỗi biên dịch.
  • Quên ; ở cuối prototype hoặc prototype khác tên/kiểu với định nghĩa (ví dụ showmenu và showMenu) → lỗi liên kết undefined reference.

2. Bài tập trên lớp (55 Phút)

Bài 1: Refactor bảng thông tin nhân vật

Trên lớp

Đề bài: Đoạn code dưới đây in bảng thông tin của 2 nhân vật, các dòng kẻ bị viết lặp lại 6 lần. Hãy tách dòng kẻ thành hàm printLine(), phần tiêu đề thành hàm printHeader(), rồi viết lại main cho gọn.

before_refactor.cpp (code ban đầu) 
#include <iostream>

int main() {
    std::cout << "+------------------+\n";
    std::cout << "|  THONG TIN HERO  |\n";
    std::cout << "+------------------+\n";
    std::cout << "Ten: Knight  HP: 120  ATK: 15\n";
    std::cout << "+------------------+\n";
    std::cout << "|  THONG TIN HERO  |\n";
    std::cout << "+------------------+\n";
    std::cout << "Ten: Archer  HP: 80   ATK: 22\n";
    std::cout << "+------------------+\n";
    return 0;
}

Lời giải mẫu:

after_refactor.cpp 
#include <iostream>

void printLine();
void printHeader();

int main() {
    printHeader();
    std::cout << "Ten: Knight  HP: 120  ATK: 15\n";
    printHeader();
    std::cout << "Ten: Archer  HP: 80   ATK: 22\n";
    printLine();
    return 0;
}

// In mot dong ke ngang
void printLine() {
    std::cout << "+------------------+\n";
}

// In khung tieu de (dung lai printLine)
void printHeader() {
    printLine();
    std::cout << "|  THONG TIN HERO  |\n";
    printLine();
}
Thử thay đổi: Muốn đổi khung từ +---+ sang *===*? Giờ chỉ cần sửa một dòng trong printLine() thay vì 6 dòng. Đó chính là sức mạnh của hàm.

Bài 2: Menu game gồm nhiều hàm

Trên lớp

Đề bài: Viết chương trình menu lặp lại đến khi người chơi chọn 0. Mỗi lựa chọn gọi một hàm riêng: showMenu(), startGame() (in câu chuyện mở đầu), showHelp(), showCredits(). Dùng prototype, đặt main ngay sau phần khai báo.

game_menu.cpp 
#include <iostream>

void showMenu();
void startGame();
void showHelp();
void showCredits();

int main() {
    int choice;
    do {
        showMenu();
        std::cin >> choice;
        switch (choice) {
            case 1: startGame();   break;
            case 2: showHelp();    break;
            case 3: showCredits(); break;
            case 0: std::cout << "Tam biet!\n"; break;
            default: std::cout << "Lua chon khong hop le!\n";
        }
    } while (choice != 0);
    return 0;
}

void showMenu() {
    std::cout << "\n===== DUNGEON QUEST =====\n";
    std::cout << "1. Choi moi\n";
    std::cout << "2. Huong dan\n";
    std::cout << "3. Tac gia\n";
    std::cout << "0. Thoat\n";
    std::cout << "Lua chon: ";
}

void startGame() {
    std::cout << "Ban tinh day trong mot ham nguc toi tam...\n";
    std::cout << "Phia truoc co mot canh cua go cu ky.\n";
}

void showHelp() {
    std::cout << "W A S D: di chuyen | E: nhat do | Q: dung binh mau\n";
}

void showCredits() {
    std::cout << "Game duoc lam boi hoc vien InnoMind.\n";
}
🎯 Nhận xét: Đọc main bây giờ giống đọc sơ đồ của game: hiện menu → nhận lựa chọn → chuyển đến màn hình tương ứng. Muốn thêm màn hình "Cài đặt", chỉ cần viết thêm một hàm và một case.

3. Bài tập về nhà (Tự luyện tập)

Bài 1 [Easy]: Thanh mạng sống bằng trái tim

Easy (40%)

Viết hàm printHeart() in ra ký hiệu <3 (không xuống dòng). Trong main, dùng vòng for gọi hàm 3 lần để in thanh mạng sống Lives: <3 <3 <3, sau đó in thêm dòng "Ban bi trung don!" và in lại thanh mạng với 2 trái tim.

lives_bar.cpp 
#include <iostream>

void printHeart();

int main() {
    std::cout << "Lives: ";
    for (int i = 0; i < 3; i++) {
        printHeart();
    }
    std::cout << "\n";

    std::cout << "Ban bi trung don!\n";

    std::cout << "Lives: ";
    for (int i = 0; i < 2; i++) {
        printHeart();
    }
    std::cout << "\n";
    return 0;
}

void printHeart() {
    std::cout << "<3 ";
}

Bài 2 [Medium]: Tung xúc xắc may mắn

Medium (40%)

Viết hàm rollDice(): bên trong tự sinh 2 số ngẫu nhiên từ 1 đến 6, in ra 2 mặt xúc xắc và tổng. Nếu tổng bằng 12 in thêm "CRITICAL HIT!", nếu tổng bằng 2 in "Xui qua...". Viết thêm hàm printDivider() in dòng phân cách. Trong main, gọi srand(time(0)) một lần duy nhất, rồi cho người chơi tung 5 lượt (mỗi lượt gọi rollDice() và printDivider()).

Lưu ý: srand chỉ gọi một lần trong main. Nếu đặt srand(time(0)) bên trong rollDice(), các lượt tung trong cùng một giây sẽ ra kết quả giống hệt nhau.

lucky_dice.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

void rollDice();
void printDivider();

int main() {
    srand(time(0));
    std::cout << "=== TUNG XUC XAC MAY MAN ===\n";
    for (int turn = 1; turn <= 5; turn++) {
        std::cout << "Luot " << turn << ": ";
        rollDice();
        printDivider();
    }
    return 0;
}

void rollDice() {
    int die1 = rand() % 6 + 1;
    int die2 = rand() % 6 + 1;
    int total = die1 + die2;
    std::cout << "[" << die1 << "] [" << die2 << "] -> Tong: " << total << "\n";
    if (total == 12) {
        std::cout << "CRITICAL HIT!\n";
    } else if (total == 2) {
        std::cout << "Xui qua...\n";
    }
}

void printDivider() {
    std::cout << "- - - - - - - - - - -\n";
}

Bài 3 [Hard]: Arcade Mini — Menu nhiều trò chơi

Hard (20%)

Xây dựng một "máy arcade" console có menu lặp lại gồm: 1. Oan tu ti, 2. Doan chan le, 3. Huong dan, 0. Thoat. Mỗi trò chơi là một hàm riêng chơi trọn một ván bên trong nó:

  • playRockPaperScissors(): người chọn 1-Búa / 2-Kéo / 3-Bao (kiểm tra hợp lệ bằng do-while), máy chọn ngẫu nhiên, in kết quả thắng/thua/hòa.
  • playOddEven(): máy sinh số 1–100, người đoán c (chẵn) hoặc l (lẻ), in đúng/sai.
  • showHelp(), showMenu(), printBanner() (gọi ở đầu chương trình).

Yêu cầu: dùng prototype, main không quá 25 dòng, không có đoạn code nào bị lặp lại.

Gợi ý xét thắng Oẳn tù tì: Với quy ước 1-Búa, 2-Kéo, 3-Bao: người thắng khi (player == 1 && bot == 2) || (player == 2 && bot == 3) || (player == 3 && bot == 1).
arcade_mini.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

void printBanner();
void showMenu();
void showHelp();
void playRockPaperScissors();
void playOddEven();

int main() {
    srand(time(0));
    printBanner();
    int choice;
    do {
        showMenu();
        std::cin >> choice;
        switch (choice) {
            case 1: playRockPaperScissors(); break;
            case 2: playOddEven();           break;
            case 3: showHelp();              break;
            case 0: std::cout << "Hen gap lai!\n"; break;
            default: std::cout << "Khong co lua chon nay!\n";
        }
    } while (choice != 0);
    return 0;
}

void printBanner() {
    std::cout << "**************************\n";
    std::cout << "*     ARCADE  MINI       *\n";
    std::cout << "**************************\n";
}

void showMenu() {
    std::cout << "\n1. Oan tu ti\n";
    std::cout << "2. Doan chan le\n";
    std::cout << "3. Huong dan\n";
    std::cout << "0. Thoat\n";
    std::cout << "Chon: ";
}

void showHelp() {
    std::cout << "- Oan tu ti: Bua thang Keo, Keo thang Bao, Bao thang Bua.\n";
    std::cout << "- Chan le: doan so may nghi la chan (c) hay le (l).\n";
}

void playRockPaperScissors() {
    int player;
    do {
        std::cout << "Chon 1-Bua  2-Keo  3-Bao: ";
        std::cin >> player;
    } while (player < 1 || player > 3);

    int bot = rand() % 3 + 1;
    std::cout << "May chon: ";
    switch (bot) {
        case 1: std::cout << "Bua\n"; break;
        case 2: std::cout << "Keo\n"; break;
        default: std::cout << "Bao\n"; break;
    }

    if (player == bot) {
        std::cout << "=> Hoa!\n";
    } else if ((player == 1 && bot == 2) || (player == 2 && bot == 3) || (player == 3 && bot == 1)) {
        std::cout << "=> Ban thang!\n";
    } else {
        std::cout << "=> Ban thua!\n";
    }
}

void playOddEven() {
    int secret = rand() % 100 + 1;
    char guess;
    do {
        std::cout << "So bi mat la chan (c) hay le (l)? ";
        std::cin >> guess;
    } while (guess != 'c' && guess != 'l');

    bool isEven = (secret % 2 == 0);
    std::cout << "So bi mat la " << secret << ". ";
    if ((isEven && guess == 'c') || (!isEven && guess == 'l')) {
        std::cout << "Chinh xac!\n";
    } else {
        std::cout << "Sai roi!\n";
    }
}
💡 Mở rộng: Muốn đếm số ván thắng của cả phiên chơi, hàm trò chơi cần "báo kết quả" về cho main. Đó chính là giá trị trả về (return) — chủ đề của Buổi 24.
