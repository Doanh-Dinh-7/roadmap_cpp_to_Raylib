Toán Tử So Sánh, Logic & Thứ Tự Ưu Tiên Biểu Thức

Mục tiêu đầu ra: Xây dựng các biểu thức điều kiện logic phức hợp, hiểu thấu đáo cơ chế đoản mạch (Short-circuit) và thứ tự ưu tiên toán tử trong game.

1. Lý thuyết cốt lõi (20 Phút)

1.1 Các toán tử quan hệ (Relational Operators)

Luôn trả về kết quả kiểu boolean (true hoặc false):

  • ==: So sánh bằng; !=: So sánh khác nhau.
  • >, <, >=, <=: So sánh lớn hơn, bé hơn, lớn hơn hoặc bằng, bé hơn hoặc bằng.

1.2 Các toán tử logic & Bảng chân trị (Truth Table)

  • && (AND): Trả về true khi và chỉ khi cả 2 vế đều đúng.
  • || (OR): Trả về true chỉ cần ít nhất 1 vế đúng.
  • ! (NOT): Đảo ngược giá trị logic (!true thành false).
⚡ Cơ chế đoản mạch (Short-Circuit Evaluation):
- Với A && B: Nếu A là false, C++ sẽ KHÔNG tính toán B vì kết quả chắc chắn là sai.
- Với A || B: Nếu A là true, C++ sẽ KHÔNG tính toán B vì kết quả chắc chắn là đúng.
$\rightarrow$ Giúp tối ưu hóa tốc độ xử lý hàng trăm điều kiện trong Game Loop!

2. Thực hành tại lớp — Live Coding (45 Phút)

Thực hành: Kiểm tra điều kiện mở Rương Thần (Treasure Chest Unlock)

Medium

Rương báu chỉ mở được khi: Người chơi có chìa khóa vàng (hasGoldenKey == true) VÀ Cấp độ level >= 15 HOẶC người chơi là GM quản trị viên (isAdmin == true).

Ví dụ Input / Output 
Input:
Bạn có chìa khóa vàng không? (1: Có, 0: Không): 1
Nhập Level của bạn: 16
Bạn có phải là Admin GM không? (1: Đúng, 0: Sai): 0

Output:
Kết quả kiểm tra mở rương: 🔓 THÀNH CÔNG! Rương kho báu đã mở!
chest_condition.cpp 
#include <iostream>

int main() {
    bool hasGoldenKey;
    int playerLevel;
    bool isAdmin;

    std::cout << "Bạn có chìa khóa vàng không? (1: Có, 0: Không): ";
    std::cin >> hasGoldenKey;
    std::cout << "Nhập Level của bạn: ";
    std::cin >> playerLevel;
    std::cout << "Bạn có phải là Admin GM không? (1: Đúng, 0: Sai): ";
    std::cin >> isAdmin;

    // Biểu thức logic phức hợp
    bool canOpen = (hasGoldenKey && playerLevel >= 15) || isAdmin;

    std::cout << "\nKết quả kiểm tra mở rương: " 
              << (canOpen ? "🔓 THÀNH CÔNG! Rương kho báu đã mở!" : "🔒 THẤT BẠI! Bạn không đủ điều kiện mở rương.") 
              << "\n";

    return 0;
}

3. Bài tập về nhà (3 Cấp độ)

Bài 1 [Easy]: Kiểm tra nhân vật có nằm trong vùng an toàn (Safe Zone)

Easy (40%)

Vùng an toàn là đoạn tọa độ từ X = 100 đến X = 500. Nhập vào tọa độ playerX. In ra 1 (An toàn) nếu playerX >= 100 && playerX <= 500, ngược lại in ra 0 (Vùng nguy hiểm).

Ví dụ Input / Output 
Input:
Nhập tọa độ X của nhân vật: 250

Output:
Trạng thái an toàn: 1 (1: An toàn, 0: Vùng quái vật)
safe_zone.cpp 
#include <iostream>

int main() {
    int playerX;
    std::cout << "Nhập tọa độ X của nhân vật: ";
    std::cin >> playerX;

    bool isSafe = (playerX >= 100) && (playerX <= 500);
    std::cout << "Trạng thái an toàn: " << isSafe << " (1: An toàn, 0: Vùng quái vật)\n";
    return 0;
}

Bài 2 [Medium]: Điều kiện thi triển chiêu cuối (Ultimate Skill Check)

Medium (40%)

Nhân vật chỉ được dùng chiêu cuối (Ultimate) khi: Năng lượng Mana >= 100 VÀ Chiêu thức không đang hồi phục (isCooldown == false) VÀ Nhân vật không bị choáng (isStunned == false).

Ví dụ Input / Output 
Input:
Nhập Mana hiện tại: 120
Chiêu có đang hồi không? (1: Có, 0: Không): 0
Nhân vật có bị choáng không? (1: Có, 0: Không): 0

Output:
-> Có thể dùng chiêu cuối không: SẴN SÀNG KÍCH HOẠT! 🔥
ultimate_skill.cpp 
#include <iostream>

int main() {
    int mana;
    bool isCooldown, isStunned;

    std::cout << "Nhập Mana hiện tại: ";
    std::cin >> mana;
    std::cout << "Chiêu có đang hồi không? (1: Có, 0: Không): ";
    std::cin >> isCooldown;
    std::cout << "Nhân vật có bị choáng không? (1: Có, 0: Không): ";
    std::cin >> isStunned;

    bool canCast = (mana >= 100) && (!isCooldown) && (!isStunned);

    std::cout << "\n-> Có thể dùng chiêu cuối không: " 
              << (canCast ? "SẴN SÀNG KÍCH HOẠT! 🔥" : "CHƯA THỂ DÙNG CHIÊU! ❌") << "\n";
    return 0;
}

Bài 3 [Hard]: Kiểm tra va chạm hộp 2D (Axis-Aligned Bounding Box - AABB)

Hard (20%)

Cho hình chữ nhật A (tọa độ x1, y1, rộng w1, cao h1) và hình chữ nhật B (tọa độ x2, y2, rộng w2, cao h2). Viết một biểu thức logic kiểm tra xem 2 hình chữ nhật có va chạm lồng vào nhau hay không (Thuật toán va chạm AABB nền tảng của mọi Game 2D).

Ví dụ Input / Output 
Input:
Nhập tọa độ x2, y2 của hộp vật thể 2: 30 30

Output:
Kết quả va chạm: 💥 CÓ VA CHẠM (COLLISION)!

Nguyên lý: Hai hộp va chạm khi và chỉ khi chúng đồng thời giao nhau trên cả 2 trục X và Y.

aabb_collision.cpp 
#include <iostream>

int main() {
    float x1 = 10, y1 = 10, w1 = 50, h1 = 50;
    float x2, y2, w2 = 40, h2 = 40;

    std::cout << "Nhập tọa độ x2, y2 của hộp vật thể 2: ";
    std::cin >> x2 >> y2;

    // Thuật toán kiểm tra va chạm AABB
    bool isColliding = (x1 < x2 + w2) &&
                       (x1 + w1 > x2) &&
                       (y1 < y2 + h2) &&
                       (y1 + h1 > y2);

    std::cout << "Kết quả va chạm: " 
              << (isColliding ? "💥 CÓ VA CHẠM (COLLISION)!" : "An toàn, không va chạm.") 
              << "\n";
    return 0;
}
