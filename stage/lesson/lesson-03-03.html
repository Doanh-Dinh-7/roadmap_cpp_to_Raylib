Phạm Vi Biến (Scope) và Luyện Tập Thiết Kế Hàm

Mục tiêu đầu ra: Phân biệt biến cục bộ, biến toàn cục, hiện tượng che khuất tên và biến static cục bộ; áp dụng nguyên tắc "mỗi hàm một việc" để refactor game đoán số của Buổi 22 thành các hàm nhỏ, dễ đọc và tái sử dụng.

1. Lý thuyết cốt lõi (30 Phút)

1.1 Phạm vi (Scope) là gì?

Phạm vi của một biến là vùng code mà biến đó "được nhìn thấy" và sử dụng được. Quy tắc cơ bản trong C++: một biến chỉ tồn tại từ dòng khai báo đến dấu } đóng khối chứa nó. Ra khỏi khối, biến bị hủy và tên của nó không còn ý nghĩa.

block_scope.cpp 
#include <iostream>

int main() {
    int gold = 100;                  // Song trong ca main
    if (gold >= 50) {
        int potionPrice = 50;        // Chi song trong khoi if
        gold -= potionPrice;
    }
    // std::cout << potionPrice;     // LOI: potionPrice da bi huy

    for (int i = 0; i < 3; i++) {    // i chi song trong vong for
        std::cout << "Luot " << i << "\n";
    }
    // std::cout << i;               // LOI: i khong ton tai o day

    std::cout << "Vang con: " << gold << "\n";
    return 0;
}

1.2 Bảng phân loại biến theo phạm vi

Loại biến Khai báo ở đâu Nhìn thấy ở đâu Tồn tại bao lâu
Cục bộ (local) Trong hàm hoặc khối { } Từ chỗ khai báo đến cuối khối Bị hủy khi ra khỏi khối; mỗi lần gọi hàm tạo mới
Tham số Trong ( ) của hàm Toàn bộ thân hàm Như biến cục bộ của hàm
Toàn cục (global) Ngoài mọi hàm (đầu file) Mọi hàm phía dưới khai báo Suốt thời gian chương trình chạy
static cục bộ Trong hàm, có từ khóa static Chỉ trong hàm đó Suốt chương trình; chỉ khởi tạo một lần

Hai hàm khác nhau hoàn toàn có thể dùng chung tên biến cục bộ (ví dụ đều có int i hay int result) mà không ảnh hưởng nhau — mỗi hàm có "căn phòng riêng".

1.3 Biến toàn cục & hằng toàn cục

global_demo.cpp 
#include <iostream>

const int MAX_HP = 100;      // Hang toan cuc: AN TOAN, nen dung
int enemyCount = 0;          // Bien toan cuc: ham nao cung sua duoc -> han che

void spawnEnemy() {
    enemyCount++;
    std::cout << "Quai xuat hien! HP = " << MAX_HP << "\n";
}

int main() {
    spawnEnemy();
    spawnEnemy();
    std::cout << "So quai: " << enemyCount << "\n";   // 2
    return 0;
}

Hằng toàn cục (const) rất hữu ích cho các thông số cấu hình game: MAX_HP, SCREEN_WIDTH, WIN_SCORE. Ngược lại, biến toàn cục có thể thay đổi là con dao hai lưỡi: bất kỳ hàm nào cũng sửa được nó, khi có lỗi rất khó biết "ai đã sửa". Quy tắc của khóa học: dữ liệu đi vào hàm qua tham số, đi ra qua return; chỉ dùng toàn cục cho hằng số.

1.4 Che khuất tên (Name Shadowing)

Khi khối bên trong khai báo biến trùng tên với biến bên ngoài, biến bên trong sẽ "che" biến bên ngoài cho đến hết khối. Muốn truy cập biến toàn cục bị che, có thể dùng toán tử phạm vi ::ten_bien — nhưng cách tốt nhất là đừng đặt trùng tên.

shadowing_bug.cpp 
#include <iostream>

int main() {
    int score = 0;
    for (int level = 1; level <= 3; level++) {
        int score = level * 100;    // BUG: tao bien MOI, che bien ben ngoai
        std::cout << "Level " << level << ": " << score << "\n";
    }
    std::cout << "Tong diem: " << score << "\n";   // In ra 0 !!!
    return 0;
}

Sửa: bỏ chữ int và cộng dồn — score += level * 100; — để dùng đúng biến bên ngoài.

1.5 Biến static cục bộ

Biến cục bộ bình thường bị tạo mới mỗi lần gọi hàm. Thêm từ khóa static thì biến chỉ được khởi tạo một lần duy nhất và giữ nguyên giá trị giữa các lần gọi, nhưng vẫn chỉ nhìn thấy được bên trong hàm — an toàn hơn biến toàn cục.

static_local.cpp 
#include <iostream>

int nextMonsterId() {
    static int id = 0;      // Chi khoi tao 1 lan
    id++;
    return id;
}

int main() {
    std::cout << "Goblin #" << nextMonsterId() << "\n";   // 1
    std::cout << "Slime  #" << nextMonsterId() << "\n";   // 2
    std::cout << "Orc    #" << nextMonsterId() << "\n";   // 3
    return 0;
}

1.6 Nguyên tắc thiết kế hàm tốt

  • Mỗi hàm một việc: Nếu phải dùng chữ "và" khi mô tả hàm ("đọc số và kiểm tra và in gợi ý"), hãy tách nhỏ.
  • Tên là động từ rõ nghĩa: readGuess, giveHint, calcScore; hàm trả bool đặt tên dạng câu hỏi: isValid, askPlayAgain.
  • Ngắn gọn: Một hàm nên vừa một màn hình (khoảng dưới 30 dòng).
  • Vào bằng tham số, ra bằng return: Tránh để hàm âm thầm sửa biến toàn cục.
  • Không lặp code: Thấy một đoạn xuất hiện 2 lần trở lên → ứng viên để thành hàm.
🎮 Mẹo tư duy Game: Trong game thật, các hằng như SCREEN_WIDTH = 800, GRAVITY, PLAYER_SPEED thường đặt toàn cục để chỉnh "cảm giác game" ở một chỗ. Còn trạng thái thay đổi liên tục (vị trí, máu, điểm) được giữ trong main hoặc trong các cấu trúc dữ liệu (Giai đoạn 04) và truyền vào hàm. Biến static cục bộ hay dùng để đếm khung hình, sinh ID duy nhất cho quái vật/viên đạn.
⚠️ Lỗi thường gặp & bộ nhớ:
  • Khai báo lại thay vì gán: int score = ... trong khối con tạo biến mới, biến ngoài không đổi (xem ví dụ 1.4). Bật -Wshadow để trình biên dịch cảnh báo.
  • Dùng biến ngoài phạm vi: dùng i sau vòng for, hoặc dùng biến khai báo trong if ở bên ngoài → lỗi was not declared in this scope.
  • Biến cục bộ chưa khởi tạo chứa giá trị rác; biến toàn cục và static thì tự động bằng 0. Hãy luôn khởi tạo rõ ràng.
  • Lạm dụng biến toàn cục: chương trình chạy đúng lúc đầu nhưng càng thêm tính năng càng khó tìm lỗi.

2. Bài tập trên lớp (60 Phút)

Bài 1: Đoán kết quả — Ai là score?

Trên lớp

Đề bài: Không chạy máy, hãy dự đoán chương trình in ra những gì ở các dòng A đến F. Sau đó chạy thử để kiểm tra.

scope_quiz.cpp 
#include <iostream>

int score = 100;                       // Bien toan cuc

void addBonus() {
    int score = 5;                     // Che khuat bien toan cuc
    score += 10;
    std::cout << "A: " << score << "\n";
}

int main() {
    std::cout << "B: " << score << "\n";
    addBonus();
    {
        int score = 1;                 // Khoi rieng, bien rieng
        std::cout << "C: " << score << "\n";
    }
    score += 1;                        // Day la bien nao?
    std::cout << "D: " << score << "\n";
    for (int score = 0; score < 2; score++) {
        std::cout << "E: " << score << "\n";
    }
    std::cout << "F: " << ::score << "\n";
    return 0;
}

Thứ tự in: B: 100 → A: 15 → C: 1 → D: 101 → E: 0 → E: 1 → F: 101.

  • B: main chưa có biến score cục bộ nên dùng biến toàn cục (100).
  • A: addBonus có score cục bộ = 5, cộng 10 → 15. Biến toàn cục không bị đụng tới.
  • C: Biến trong khối { } riêng, hủy ngay sau dấu }.
  • D: Ra khỏi khối, score lại là biến toàn cục → 101.
  • E: Biến đếm của vòng for che biến toàn cục trong vòng lặp.
  • F: ::score luôn chỉ biến toàn cục → 101.

Bài 2: Refactor game đoán số (Buổi 22) thành các hàm

Trên lớp

Đề bài: Game đoán số ở Buổi 22 có toàn bộ logic trong main (hơn 70 dòng). Hãy tách thành các hàm theo bảng thiết kế dưới đây. Yêu cầu: không dùng biến toàn cục có thể thay đổi (chỉ được dùng hằng toàn cục), main chỉ còn vòng lặp ván chơi và phần tổng kết.

Hàm Nhiệm vụ (một việc)

int chooseLevel()Hiện menu độ khó, trả về 1–3
int getMaxNumber(int level), int getMaxTries(int level), int getMultiplier(int level)Tra cứu cấu hình theo độ khó

guess_game_v3.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

const int POINTS_PER_TRY = 10;      // Hang toan cuc: cau hinh game

int readNumberInRange(int minValue, int maxValue);
int chooseLevel();
int getMaxNumber(int level);
int getMaxTries(int level);
int getMultiplier(int level);
void giveHint(int guess, int secret);
int calcScore(int maxTries, int tries, int multiplier);
int playRound();
bool askPlayAgain();

int main() {
    srand(time(0));
    int totalScore = 0, rounds = 0, wins = 0;
    std::cout << "===== NUMBER GUESSING GAME v3 =====\n";

    do {
        int score = playRound();
        rounds++;
        if (score > 0) wins++;
        totalScore += score;
        std::cout << "Tong diem hien tai: " << totalScore << "\n";
    } while (askPlayAgain());

    std::cout << "\n===== TONG KET =====\n";
    std::cout << "So van: " << rounds << " | Thang: " << wins
              << " | Tong diem: " << totalScore << "\n";
    return 0;
}

int readNumberInRange(int minValue, int maxValue) {
    int value;
    while (true) {
        if (!(std::cin >> value)) {
            std::cin.clear();
            std::cin.ignore(1000, '\n');
            std::cout << "Vui long nhap so nguyen: ";
        } else if (value < minValue || value > maxValue) {
            std::cout << "Nhap so tu " << minValue << " den " << maxValue << ": ";
        } else {
            return value;               // Hop le -> tra ve ngay
        }
    }
}

int chooseLevel() {
    std::cout << "\nChon do kho: 1-De  2-Thuong  3-Kho : ";
    return readNumberInRange(1, 3);     // Tai su dung ham doc so
}

int getMaxNumber(int level) {
    switch (level) {
        case 1:  return 50;
        case 2:  return 100;
        default: return 500;
    }
}

int getMaxTries(int level) {
    switch (level) {
        case 1:  return 10;
        case 2:  return 7;
        default: return 9;
    }
}

int getMultiplier(int level) {
    return level;                       // De x1, Thuong x2, Kho x3
}

void giveHint(int guess, int secret) {
    if (guess < secret) std::cout << "  -> Lon hon!\n";
    else                std::cout << "  -> Nho hon!\n";
}

int calcScore(int maxTries, int tries, int multiplier) {
    return (maxTries - tries + 1) * POINTS_PER_TRY * multiplier;
}

int playRound() {
    int level = chooseLevel();
    int maxNumber = getMaxNumber(level);
    int maxTries = getMaxTries(level);
    int secret = rand() % maxNumber + 1;
    std::cout << "Toi da nghi mot so tu 1 den " << maxNumber
              << ". Ban co " << maxTries << " luot.\n";

    for (int tries = 1; tries <= maxTries; tries++) {
        std::cout << "[Luot " << tries << "/" << maxTries << "] Nhap so: ";
        int guess = readNumberInRange(1, maxNumber);
        if (guess == secret) {
            int score = calcScore(maxTries, tries, getMultiplier(level));
            std::cout << "CHINH XAC! +" << score << " diem.\n";
            return score;               // Thang -> ket thuc van
        }
        giveHint(guess, secret);
    }
    std::cout << "HET LUOT! So bi mat la " << secret << ".\n";
    return 0;
}

bool askPlayAgain() {
    char again;
    std::cout << "Choi tiep? (y/n): ";
    std::cin >> again;
    return again == 'y' || again == 'Y';
}
So sánh trước và sau: Biến cờ won và lệnh break đã biến mất — return bên trong vòng lặp vừa thoát vòng vừa thoát hàm. Hàm readNumberInRange được dùng ở hai nơi (chọn độ khó và nhập số đoán) thay vì viết lặp hai khối do-while. Biến tries, secret giờ là biến cục bộ của playRound, tự "reset" ở mỗi ván mới.

3. Bài tập về nhà (Tự luyện tập)

Bài 1 [Easy]: Bắt lỗi phạm vi trong game nhặt xu

Easy (40%)

Chương trình dưới đây muốn: người chơi đi qua 5 phòng, mỗi phòng nhặt 10 xu; nếu tổng xu từ 50 trở lên thì lên cấp 2. Chương trình có 2 lỗi về phạm vi (một lỗi biên dịch, một lỗi logic). Hãy tìm, giải thích và sửa.

coin_bug.cpp (code có lỗi) 
#include <iostream>

int main() {
    int coins = 0;
    for (int room = 1; room <= 5; room++) {
        int coins = 0;
        coins += 10;
        std::cout << "Phong " << room << ": nhat 10 xu\n";
    }

    if (coins >= 50) {
        int level = 2;
    }
    std::cout << "Tong xu: " << coins << " | Cap do: " << level << "\n";
    return 0;
}
  • Lỗi logic: int coins = 0; trong vòng for tạo biến mới che biến bên ngoài, mỗi vòng lại reset về 0 → tổng xu bên ngoài luôn là 0. Sửa: xóa dòng đó.
  • Lỗi biên dịch: level khai báo trong khối if nên bị hủy sau dấu }. Sửa: khai báo int level = 1; ở ngoài, trong if chỉ gán level = 2;.

#include <iostream>

int main() {

Bài 2 [Medium]: Hệ thống sinh quái theo đợt (static & hằng toàn cục)

Medium (40%)

Game có 3 đợt (wave); đợt thứ w sinh ra w + 1 con quái. Yêu cầu:

  • Hằng toàn cục BASE_HP = 50, HP_PER_WAVE = 20, TOTAL_WAVES = 3.
  • int nextMonsterId() dùng biến static để cấp ID tăng dần 1, 2, 3... cho mọi con quái.
  • int spawnMonster(int wave): lấy ID mới, tính máu = BASE_HP + wave * HP_PER_WAVE, in "Monster #ID - HP: ..." và trả về máu.
  • int spawnWave(int wave): sinh đủ quái của đợt, trả về tổng máu của đợt.

Trong main, in tổng máu từng đợt, tổng máu cả game và tổng số quái đã sinh. Không dùng biến toàn cục có thể thay đổi.

monster_waves.cpp 
#include <iostream>

const int BASE_HP = 50;
const int HP_PER_WAVE = 20;
const int TOTAL_WAVES = 3;

int nextMonsterId();
int spawnMonster(int wave);
int spawnWave(int wave);

int main() {
    int totalHp = 0;
    int totalMonsters = 0;
    for (int wave = 1; wave <= TOTAL_WAVES; wave++) {
        std::cout << "\n=== WAVE " << wave << " ===\n";
        int waveHp = spawnWave(wave);
        std::cout << "Tong mau wave " << wave << ": " << waveHp << "\n";
        totalHp += waveHp;
        totalMonsters += wave + 1;
    }
    std::cout << "\nTong so quai: " << totalMonsters << "\n";
    std::cout << "Tong mau ca game: " << totalHp << "\n";
    return 0;
}

int nextMonsterId() {
    static int id = 0;           // Giu gia tri giua cac lan goi
    id++;
    return id;
}

int spawnMonster(int wave) {
    int id = nextMonsterId();    // Bien cuc bo 'id' khac voi 'id' static ben kia
    int hp = BASE_HP + wave * HP_PER_WAVE;
    std::cout << "Monster #" << id << " - HP: " << hp << "\n";
    return hp;
}

int spawnWave(int wave) {
    int waveHp = 0;
    for (int i = 0; i < wave + 1; i++) {
        waveHp += spawnMonster(wave);
    }
    return waveHp;
}

Kết quả mong đợi: Wave 1 có Monster #1–#2 (HP 70), Wave 2 có #3–#5 (HP 90), Wave 3 có #6–#9 (HP 110). Tổng 9 quái, tổng máu 2·70 + 3·90 + 4·110 = 850.

Bài 3 [Hard]: Game xúc xắc "Pig" — Người đấu Máy

Hard (20%)

Luật chơi: Mỗi lượt, người chơi tung xúc xắc liên tục và cộng dồn điểm lượt. Nếu tung ra 1 → mất toàn bộ điểm lượt và hết lượt. Người chơi có thể dừng bất kỳ lúc nào để cộng điểm lượt vào tổng. Ai đạt 50 điểm trước sẽ thắng. Máy dùng chiến thuật: tung đến khi điểm lượt đạt 15 (hoặc đủ để thắng) thì dừng.

Yêu cầu thiết kế: hằng toàn cục WIN_SCORE, COMPUTER_HOLD; các hàm rollDie(), askRollAgain(), playerTurn(int playerScore), computerTurn(int computerScore) (trả về điểm kiếm được trong lượt), printScoreboard(int playerScore, int computerScore). Không có biến toàn cục có thể thay đổi; mỗi hàm không quá 25 dòng.

pig_dice.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

const int WIN_SCORE = 50;
const int COMPUTER_HOLD = 15;

int rollDie();
bool askRollAgain();
int playerTurn(int playerScore);
int computerTurn(int computerScore);
void printScoreboard(int playerScore, int computerScore);

int main() {
    srand(time(0));
    int playerScore = 0, computerScore = 0;
    std::cout << "===== PIG DICE - Ai dat " << WIN_SCORE << " diem truoc se thang =====\n";

    while (true) {
        playerScore += playerTurn(playerScore);
        printScoreboard(playerScore, computerScore);
        if (playerScore >= WIN_SCORE) {
            std::cout << "BAN THANG!\n";
            break;
        }
        computerScore += computerTurn(computerScore);
        printScoreboard(playerScore, computerScore);
        if (computerScore >= WIN_SCORE) {
            std::cout << "MAY THANG!\n";
            break;
        }
    }
    return 0;
}

int rollDie() {
    return rand() % 6 + 1;
}

bool askRollAgain() {
    char answer;
    do {
        std::cout << "Tung tiep (r) hay dung (h)? ";
        std::cin >> answer;
    } while (answer != 'r' && answer != 'h');
    return answer == 'r';
}

int playerTurn(int playerScore) {
    int turnTotal = 0;
    std::cout << "\n--- LUOT CUA BAN ---\n";
    while (true) {
        int face = rollDie();
        std::cout << "Ban tung duoc: " << face << "\n";
        if (face == 1) {
            std::cout << "Ra 1! Mat het diem luot.\n";
            return 0;
        }
        turnTotal += face;
        std::cout << "Diem luot: " << turnTotal << "\n";
        if (playerScore + turnTotal >= WIN_SCORE) return turnTotal;   // Du de thang
        if (!askRollAgain()) return turnTotal;
    }
}

int computerTurn(int computerScore) {
    int turnTotal = 0;
    std::cout << "\n--- LUOT CUA MAY ---\n";
    while (turnTotal < COMPUTER_HOLD && computerScore + turnTotal < WIN_SCORE) {
        int face = rollDie();
        std::cout << "May tung duoc: " << face << "\n";
        if (face == 1) {
            std::cout << "May ra 1! Mat het diem luot.\n";
            return 0;
        }
        turnTotal += face;
    }
    std::cout << "May dung lai voi " << turnTotal << " diem luot.\n";
    return turnTotal;
}

void printScoreboard(int playerScore, int computerScore) {
    std::cout << ">> Bang diem: Ban " << playerScore
              << " - May " << computerScore << "\n";
}
