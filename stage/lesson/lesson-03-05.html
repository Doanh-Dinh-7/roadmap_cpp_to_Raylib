Thao Tác Trên Mảng: Cập Nhật, Tính Tổng, Tìm Max/Min

Mục tiêu đầu ra: Cập nhật hàng loạt phần tử, tính tổng/trung bình, tìm giá trị lớn nhất/nhỏ nhất cùng vị trí của chúng; viết hàm nhận mảng làm tham số (int arr[], int n) để thống kê dữ liệu game.

1. Lý thuyết cốt lõi (35 Phút)

1.1 Bốn mẫu thuật toán kinh điển trên mảng

Hầu hết các thao tác thống kê trên mảng đều dựa trên một vòng for duyệt từ đầu đến cuối, kết hợp với một biến tích lũy hoặc biến ghi nhớ. Hãy thuộc lòng 4 mẫu sau:

Mẫu Khởi tạo Trong vòng lặp Ví dụ game
Cập nhật — arr[i] = arr[i] + x; Hồi máu cả đội, x2 điểm thưởng
Tính tổng int sum = 0; sum += arr[i]; Tổng sát thương của cả đội
Trung bình Sau khi có sum double avg = (double)sum / n; Điểm trung bình mỗi màn
Tìm Max int mx = arr[0]; if (arr[i] > mx) mx = arr[i]; Điểm cao nhất (High Score)
Tìm Min int mn = arr[0]; if (arr[i] < mn) mn = arr[i]; Quái yếu máu nhất để kết liễu
Vị trí Max int idx = 0; if (arr[i] > arr[idx]) idx = i; Người chơi MVP là ai

1.2 Ví dụ: Bảng điểm một trận đấu

match_stats.cpp 
#include <iostream>

int main() {
    const int N = 6;
    int scores[N] = {120, 85, 240, 60, 240, 150};

    // Cap nhat: moi nguoi duoc thuong 10 diem
    for (int i = 0; i < N; i++) {
        scores[i] += 10;
    }

    int sum = 0;
    int maxIdx = 0;                // Gia su phan tu dau la lon nhat
    int minIdx = 0;
    for (int i = 0; i < N; i++) {
        sum += scores[i];
        if (scores[i] > scores[maxIdx]) maxIdx = i;
        if (scores[i] < scores[minIdx]) minIdx = i;
    }
    double avg = (double)sum / N;  // Ep kieu de khong mat phan thap phan

    std::cout << "Tong diem : " << sum << "\n";
    std::cout << "Trung binh: " << avg << "\n";
    std::cout << "Cao nhat  : " << scores[maxIdx] << " (nguoi choi " << maxIdx + 1 << ")\n";
    std::cout << "Thap nhat : " << scores[minIdx] << " (nguoi choi " << minIdx + 1 << ")\n";
    return 0;
}

Lưu ý: hai người chơi số 3 và số 5 cùng có 250 điểm, nhưng vì điều kiện là > (không phải >=) nên maxIdx giữ vị trí xuất hiện đầu tiên (người chơi 3). Đổi thành >= sẽ lấy vị trí cuối cùng.

1.3 Truyền mảng vào hàm

Kết hợp kiến thức Hàm (Buổi 23–25) với mảng, ta tách mỗi phép thống kê thành một hàm riêng. Cú pháp tham số mảng: int arr[] (không ghi kích thước) và luôn kèm thêm tham số int n cho biết số phần tử, vì bên trong hàm không có cách nào biết mảng dài bao nhiêu.

Thành phần Cú pháp
Prototypeint sumArray(int arr[], int n);
Định nghĩaint sumArray(int arr[], int n) { ... }
Gọi hàmint total = sumArray(scores, N); — chỉ ghi tên mảng, không có []
Hàm chỉ đọc mảngint findMax(const int arr[], int n); — const chặn việc vô tình sửa mảng
array_functions.cpp 
#include <iostream>

int sumArray(const int arr[], int n);
void healAll(int hp[], int n, int amount, int maxHp);
void printArray(const int arr[], int n);

int main() {
    const int N = 4;
    int teamHp[N] = {40, 95, 10, 70};

    std::cout << "Truoc khi hoi mau: ";
    printArray(teamHp, N);

    healAll(teamHp, N, 30, 100);         // Ham sua TRUC TIEP mang teamHp

    std::cout << "Sau khi hoi mau : ";
    printArray(teamHp, N);
    std::cout << "Tong HP ca doi : " << sumArray(teamHp, N) << "\n";
    return 0;
}

int sumArray(const int arr[], int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) sum += arr[i];
    return sum;
}

void healAll(int hp[], int n, int amount, int maxHp) {
    for (int i = 0; i < n; i++) {
        hp[i] += amount;
        if (hp[i] > maxHp) hp[i] = maxHp;    // Khong vuot qua mau toi da
    }
}

void printArray(const int arr[], int n) {
    for (int i = 0; i < n; i++) std::cout << arr[i] << " ";
    std::cout << "\n";
}
📌 Mảng truyền vào hàm bị sửa trực tiếp: Ở Buổi 24 ta biết tham số kiểu int được truyền tham trị (hàm nhận bản sao, sửa không ảnh hưởng biến gốc). Mảng thì khác: hàm healAll làm việc trên chính mảng teamHp của main, nên sau khi gọi hàm, máu cả đội đã thay đổi thật. Cơ chế bên dưới (con trỏ) sẽ được giải thích ở Giai đoạn 04 — hiện tại chỉ cần nhớ quy tắc này và dùng const cho hàm chỉ đọc.
🎮 Mẹo tư duy Game: Màn hình kết thúc trận (end-game screen) của mọi game đối kháng đều là bài toán thống kê mảng: tổng sát thương, sát thương trung bình, ai là MVP (max), ai "gánh team" kém nhất (min). Viết sẵn các hàm sumArray, findMaxIndex, findMinIndex một lần là có thể tái sử dụng cho mọi loại dữ liệu số: điểm, vàng, số mạng hạ gục…
⚠️ Lỗi thường gặp:
  • Khởi tạo Max bằng 0: int mx = 0; sai khi mọi phần tử đều âm (ví dụ chỉ số nhiệt độ, điểm trừ). Luôn khởi tạo bằng arr[0].
  • Chia nguyên khi tính trung bình: sum / n với hai số int sẽ cắt mất phần thập phân (7 / 2 = 3). Hãy ép kiểu (double)sum / n.
  • Quên khởi tạo sum = 0: biến cục bộ chưa khởi tạo chứa giá trị rác.
  • Mảng rỗng (n == 0): khi đó arr[0] không tồn tại và chia cho n gây lỗi. Hàm thống kê nên kiểm tra n > 0 trước.
  • Gọi hàm sai: sumArray(scores[], N) hoặc sumArray(scores[N], N) đều sai — chỉ truyền tên mảng scores.

2. Bài tập trên lớp (55 Phút)

Bài 1: Thư viện hàm thống kê điểm

Trên lớp

Đề bài: Nhập n (1–50) điểm số của các lượt chơi. Viết các hàm: sumArray, average (trả về double), findMaxIndex, findMinIndex. Trong main chỉ nhập dữ liệu, gọi hàm và in kết quả: tổng, trung bình (2 chữ số thập phân không bắt buộc), điểm cao nhất/thấp nhất kèm lượt chơi đạt được.

score_library.cpp 
#include <iostream>

int sumArray(const int arr[], int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) sum += arr[i];
    return sum;
}

double average(const int arr[], int n) {
    if (n <= 0) return 0;                       // Tranh chia cho 0
    return (double)sumArray(arr, n) / n;       // Tai su dung ham da viet
}

int findMaxIndex(const int arr[], int n) {
    int idx = 0;
    for (int i = 1; i < n; i++) {               // Bat dau tu 1 vi arr[0] da la ung vien
        if (arr[i] > arr[idx]) idx = i;
    }
    return idx;
}

int findMinIndex(const int arr[], int n) {
    int idx = 0;
    for (int i = 1; i < n; i++) {
        if (arr[i] < arr[idx]) idx = i;
    }
    return idx;
}

int main() {
    const int MAX = 50;
    int scores[MAX];
    int n;

    do {
        std::cout << "So luot choi (1-50): ";
        std::cin >> n;
    } while (n < 1 || n > MAX);

    for (int i = 0; i < n; i++) {
        std::cout << "Diem luot " << i + 1 << ": ";
        std::cin >> scores[i];
    }

    int best = findMaxIndex(scores, n);
    int worst = findMinIndex(scores, n);

    std::cout << "\n===== THONG KE =====\n";
    std::cout << "Tong diem : " << sumArray(scores, n) << "\n";
    std::cout << "Trung binh: " << average(scores, n) << "\n";
    std::cout << "Cao nhat  : " << scores[best] << " (luot " << best + 1 << ")\n";
    std::cout << "Thap nhat : " << scores[worst] << " (luot " << worst + 1 << ")\n";
    return 0;
}
Vì sao trả về chỉ số thay vì giá trị? Có chỉ số idx thì lấy được cả giá trị (arr[idx]) lẫn vị trí. Ngược lại, chỉ có giá trị thì không biết nó nằm ở đâu. Hàm trả về chỉ số linh hoạt hơn.

Bài 2: Bùa x2 vàng và trừ phí sửa đồ

Trên lớp

Đề bài: Mảng int gold[5] = {120, 45, 300, 0, 80}; là số vàng của 5 thành viên trong đội. Viết hàm void multiplyAll(int arr[], int n, int factor) nhân tất cả với factor và hàm int chargeFee(int arr[], int n, int fee) trừ phí sửa đồ của từng người (ai không đủ tiền thì về 0) và trả về tổng số vàng thực sự thu được. In mảng trước và sau mỗi bước.

gold_update.cpp 
#include <iostream>

void printArray(const int arr[], int n) {
    for (int i = 0; i < n; i++) std::cout << arr[i] << "\t";
    std::cout << "\n";
}

void multiplyAll(int arr[], int n, int factor) {
    for (int i = 0; i < n; i++) arr[i] *= factor;
}

int chargeFee(int arr[], int n, int fee) {
    int collected = 0;
    for (int i = 0; i < n; i++) {
        if (arr[i] >= fee) {
            arr[i] -= fee;
            collected += fee;
        } else {
            collected += arr[i];           // Thu het so vang con lai
            arr[i] = 0;
        }
    }
    return collected;
}

int main() {
    const int N = 5;
    int gold[N] = {120, 45, 300, 0, 80};

    std::cout << "Ban dau   : ";
    printArray(gold, N);

    multiplyAll(gold, N, 2);
    std::cout << "Bua x2    : ";
    printArray(gold, N);

    int total = chargeFee(gold, N, 150);
    std::cout << "Sau phi   : ";
    printArray(gold, N);
    std::cout << "Lo ren thu duoc " << total << " vang.\n";
    return 0;
}
🎯 Câu hỏi thảo luận: Vì sao hàm printArray có const còn multiplyAll và chargeFee thì không? Thử thêm const vào multiplyAll rồi biên dịch để xem thông báo lỗi của trình biên dịch.

3. Bài tập về nhà (Tự luyện tập)

Ba bài dưới đây rèn kỹ năng thống kê mảng và thiết kế hàm nhận mảng:

Bài 1 [Easy]: Tổng, Max, Min của dãy sát thương

Easy (40%)

Nhập n (1–30) giá trị sát thương (có thể âm nếu bị phản đòn). In: tổng sát thương, sát thương trung bình, đòn mạnh nhất và đòn yếu nhất. Không cần viết hàm riêng — làm trực tiếp trong main bằng một vòng lặp duy nhất.

Gợi ý: Vì có thể có giá trị âm, phải khởi tạo mx và mn bằng dmg[0] chứ không phải 0.

damage_stats.cpp 
#include <iostream>

int main() {
    const int MAX = 30;
    int dmg[MAX];
    int n;

    do {
        std::cout << "So don danh (1-30): ";
        std::cin >> n;
    } while (n < 1 || n > MAX);

    for (int i = 0; i < n; i++) {
        std::cout << "Sat thuong don " << i + 1 << ": ";
        std::cin >> dmg[i];
    }

    int sum = 0;
    int mx = dmg[0];
    int mn = dmg[0];
    for (int i = 0; i < n; i++) {
        sum += dmg[i];
        if (dmg[i] > mx) mx = dmg[i];
        if (dmg[i] < mn) mn = dmg[i];
    }

    std::cout << "Tong sat thuong: " << sum << "\n";
    std::cout << "Trung binh     : " << (double)sum / n << "\n";
    std::cout << "Don manh nhat  : " << mx << "\n";
    std::cout << "Don yeu nhat   : " << mn << "\n";
    return 0;
}

Bài 2 [Medium]: Á quân và người trên trung bình

Medium (40%)

Cho mảng điểm int scores[8] = {70, 95, 60, 95, 88, 40, 88, 75};. Viết các hàm: (a) int countAboveAverage(const int arr[], int n) — đếm số người có điểm lớn hơn điểm trung bình; (b) int findSecondMax(const int arr[], int n) — trả về điểm cao thứ hai khác điểm cao nhất (với dữ liệu trên là 88), nếu mọi điểm bằng nhau thì trả về -1.

Phân tích: Tìm điểm cao thứ hai bằng 2 lượt duyệt: lượt 1 tìm mx; lượt 2 tìm giá trị lớn nhất trong các phần tử < mx. Dùng cờ found để biết đã gặp phần tử nào nhỏ hơn mx chưa.

runner_up.cpp 
#include <iostream>

int countAboveAverage(const int arr[], int n) {
    if (n <= 0) return 0;
    int sum = 0;
    for (int i = 0; i < n; i++) sum += arr[i];
    double avg = (double)sum / n;

    int count = 0;
    for (int i = 0; i < n; i++) {
        if (arr[i] > avg) count++;
    }
    return count;
}

int findSecondMax(const int arr[], int n) {
    if (n <= 0) return -1;
    // Luot 1: tim gia tri lon nhat
    int mx = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > mx) mx = arr[i];
    }
    // Luot 2: tim lon nhat trong cac phan tu nho hon mx
    bool found = false;
    int second = 0;
    for (int i = 0; i < n; i++) {
        if (arr[i] < mx) {
            if (!found || arr[i] > second) {
                second = arr[i];
                found = true;
            }
        }
    }
    if (!found) return -1;        // Moi phan tu deu bang nhau
    return second;
}

int main() {
    const int N = 8;
    int scores[N] = {70, 95, 60, 95, 88, 40, 88, 75};

    std::cout << "So nguoi tren trung binh: " << countAboveAverage(scores, N) << "\n";

    int second = findSecondMax(scores, N);
    if (second == -1) {
        std::cout << "Khong co a quan (moi diem bang nhau).\n";
    } else {
        std::cout << "Diem a quan: " << second << "\n";
    }
    return 0;
}

Kết quả với dữ liệu mẫu: trung bình = 76.375 → có 4 người trên trung bình (95, 95, 88, 88); điểm á quân là 88.

Bài 3 [Hard]: Bảng tổng kết trận đấu đội 6 người

Hard (20%)

Dùng hai mảng song song kills[6] và deaths[6]: phần tử thứ i của hai mảng cùng thuộc về người chơi số i + 1. Người dùng nhập số mạng hạ gục và số lần chết của 6 người. Chương trình:

  • Tính chỉ số K/D của từng người = kills / deaths (nếu deaths == 0 thì K/D = kills).
  • In bảng tổng kết: số thứ tự, kills, deaths, K/D và biểu đồ ngang gồm kills dấu *.
  • Tìm MVP (K/D cao nhất) và tổng kills/deaths của cả đội.
  • Viết ít nhất 3 hàm nhận mảng làm tham số (ví dụ sumArray, kdRatio, findMvp).

Thiết kế: Hàm kdRatio(kills, deaths, i) nhận cả 2 mảng và chỉ số người chơi, trả về double. Hàm findMvp duyệt và so sánh K/D bằng cách gọi lại kdRatio — mỗi hàm một việc như đã học ở Buổi 25.

team_scoreboard.cpp 
#include <iostream>

int sumArray(const int arr[], int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) sum += arr[i];
    return sum;
}

double kdRatio(const int kills[], const int deaths[], int i) {
    if (deaths[i] == 0) return kills[i];          // Khong chet lan nao
    return (double)kills[i] / deaths[i];
}

int findMvp(const int kills[], const int deaths[], int n) {
    int best = 0;
    for (int i = 1; i < n; i++) {
        if (kdRatio(kills, deaths, i) > kdRatio(kills, deaths, best)) {
            best = i;
        }
    }
    return best;
}

void printStars(int count) {
    for (int s = 0; s < count; s++) std::cout << '*';
}

void readNonNegative(int arr[], int i, const char label[]) {
    do {
        std::cout << "  " << label << ": ";
        std::cin >> arr[i];
    } while (arr[i] < 0);
}

int main() {
    const int N = 6;
    int kills[N];
    int deaths[N];

    for (int i = 0; i < N; i++) {
        std::cout << "Nguoi choi " << i + 1 << ":\n";
        readNonNegative(kills, i, "Kills");
        readNonNegative(deaths, i, "Deaths");
    }

    std::cout << "\n#\tKills\tDeaths\tK/D\tBieu do\n";
    for (int i = 0; i < N; i++) {
        std::cout << i + 1 << "\t" << kills[i] << "\t" << deaths[i] << "\t"
                  << kdRatio(kills, deaths, i) << "\t";
        printStars(kills[i]);
        std::cout << "\n";
    }

    int mvp = findMvp(kills, deaths, N);
    std::cout << "\nTong kills ca doi : " << sumArray(kills, N) << "\n";
    std::cout << "Tong deaths ca doi: " << sumArray(deaths, N) << "\n";
    std::cout << "MVP: Nguoi choi " << mvp + 1
              << " voi K/D = " << kdRatio(kills, deaths, mvp) << "\n";
    return 0;
}
Về mảng song song: Đây là cách lưu "nhiều thuộc tính của cùng một đối tượng" khi chưa học struct. Nhược điểm: phải luôn giữ đúng chỉ số giữa các mảng — ở Giai đoạn 04, struct Player { int kills; int deaths; } sẽ gom chúng lại gọn gàng hơn. Tham số const char label[] chỉ là một mảng ký tự chứa chữ để in ra; cách làm việc với chuỗi đầy đủ sẽ học ở Buổi 31.
