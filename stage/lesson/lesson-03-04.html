Mảng Một Chiều (Arrays): Khai Báo và Duyệt Phần Tử

Mục tiêu đầu ra: Khai báo và khởi tạo mảng tĩnh, hiểu chỉ số bắt đầu từ 0, duyệt mảng bằng for để lưu trữ và thao tác danh sách số/ký tự; nhận diện và phòng tránh lỗi truy cập ngoài phạm vi mảng (out-of-bounds).

1. Lý thuyết cốt lõi (35 Phút)

1.1 Vì sao cần mảng?

Giả sử game có 5 con quái, mỗi con có lượng máu (HP) riêng. Nếu chỉ dùng biến đơn, ta phải viết hp1, hp2, hp3, hp4, hp5 — và khi muốn trừ máu cả 5 con thì phải viết 5 dòng lệnh. Với 100 con quái thì sao? Không thể!

Mảng (array) là một dãy các ô nhớ liên tiếp, cùng kiểu dữ liệu, dùng chung một tên. Mỗi ô được truy cập bằng chỉ số (index) đặt trong cặp ngoặc vuông. Nhờ chỉ số là một con số, ta có thể dùng vòng lặp for để xử lý toàn bộ mảng chỉ với vài dòng code.

📦 Hình dung mảng int hp[5] = {100, 80, 0, 45, 60};
Chỉ số01234
Phần tửhp[0]hp[1]hp[2]hp[3]hp[4]

Mảng có 5 phần tử thì chỉ số hợp lệ là 0 đến 4 (tức 0 đến N - 1). Không có hp[5]!

1.3 Duyệt mảng bằng vòng lặp for

Mẫu duyệt mảng chuẩn: biến đếm i chạy từ 0 đến N - 1, mỗi vòng xử lý phần tử arr[i]. Ví dụ dưới đây in máu của 5 con quái và trừ máu tất cả do một phép thuật diện rộng:

monster_hp.cpp 
#include <iostream>

int main() {
    const int N = 5;
    int hp[N] = {100, 80, 0, 45, 60};

    // 1. In mau tung con quai
    for (int i = 0; i < N; i++) {
        std::cout << "Quai " << i << ": HP = " << hp[i] << "\n";
    }

    // 2. Phep thuat dien rong: tru 30 HP moi con (khong de am)
    for (int i = 0; i < N; i++) {
        hp[i] -= 30;
        if (hp[i] < 0) hp[i] = 0;
    }

    // 3. In lai tren mot dong
    std::cout << "Sau phep thuat: ";
    for (int i = 0; i < N; i++) {
        std::cout << hp[i] << " ";
    }
    std::cout << "\n";
    return 0;
}

1.4 Nhập dữ liệu vào mảng

Khi số phần tử do người dùng quyết định, ta khai báo mảng với kích thước tối đa (ví dụ MAX = 100), rồi dùng biến n để lưu số phần tử thực sự sử dụng. Luôn kiểm tra n nằm trong khoảng 1..MAX:

input_array.cpp 
#include <iostream>

int main() {
    const int MAX = 100;
    int scores[MAX];
    int n;

    do {
        std::cout << "So man choi (1-" << MAX << "): ";
        std::cin >> n;
    } while (n < 1 || n > MAX);       // Chan truoc loi vuot mang

    for (int i = 0; i < n; i++) {
        std::cout << "Diem man " << i + 1 << ": ";   // Hien thi tu 1 cho de doc
        std::cin >> scores[i];
    }
    return 0;
}
🎮 Mẹo tư duy Game: Mảng có mặt ở khắp nơi trong game: túi đồ (inventory) là mảng các ô chứa mã vật phẩm, thanh kỹ năng là mảng thời gian hồi chiêu, bảng xếp hạng là mảng điểm số. Ở Giai đoạn 06 với Raylib, bạn sẽ dùng mảng để lưu vị trí của hàng chục viên đạn và kẻ địch — mỗi khung hình (frame) chỉ cần một vòng for để cập nhật và vẽ tất cả.
⚠️ Lỗi truy cập ngoài phạm vi mảng (Out-of-bounds):
  • C++ không kiểm tra chỉ số giúp bạn. Viết hp[5] hay hp[-1] với mảng 5 phần tử vẫn biên dịch được, nhưng chương trình sẽ đọc/ghi vào vùng nhớ của biến khác → giá trị kỳ lạ, game bị sai ngẫu nhiên hoặc crash. Đây là hành vi không xác định (undefined behavior).
  • Lỗi kinh điển: for (int i = 0; i <= N; i++) — dấu <= làm vòng lặp chạy thêm 1 lần với i = N.
  • Mảng khai báo không khởi tạo (int a[5];) chứa giá trị rác. Nếu cần cộng dồn, hãy khởi tạo = {0}.
  • Kích thước mảng tĩnh phải là hằng số biết lúc biên dịch (const int N = 5;). Không viết int n; std::cin >> n; int a[n]; — đây không phải C++ chuẩn.
  • Không thể gán cả mảng bằng a = b; — phải chép từng phần tử bằng vòng lặp.

2. Bài tập trên lớp (55 Phút)

Bài 1: Lịch sử điểm các màn chơi

Trên lớp

Đề bài: Nhập số màn chơi n (1–20) và điểm của từng màn. In ra: (a) danh sách điểm theo thứ tự nhập; (b) danh sách điểm theo thứ tự ngược lại (màn gần nhất trước); (c) các màn đạt từ 50 điểm trở lên kèm số thứ tự màn.

level_history.cpp 
#include <iostream>

int main() {
    const int MAX = 20;
    int scores[MAX];
    int n;

    do {
        std::cout << "So man choi (1-20): ";
        std::cin >> n;
    } while (n < 1 || n > MAX);

    for (int i = 0; i < n; i++) {
        std::cout << "Diem man " << i + 1 << ": ";
        std::cin >> scores[i];
    }

    // (a) Thu tu nhap
    std::cout << "\nThu tu choi : ";
    for (int i = 0; i < n; i++) {
        std::cout << scores[i] << " ";
    }

    // (b) Thu tu nguoc: i chay tu n - 1 ve 0
    std::cout << "\nGan nhat truoc: ";
    for (int i = n - 1; i >= 0; i--) {
        std::cout << scores[i] << " ";
    }

    // (c) Cac man dat >= 50 diem
    std::cout << "\nCac man dat yeu cau (>= 50):\n";
    for (int i = 0; i < n; i++) {
        if (scores[i] >= 50) {
            std::cout << "  Man " << i + 1 << ": " << scores[i] << "\n";
        }
    }
    return 0;
}
Chú ý chỉ số: Bên trong chương trình, màn đầu tiên là scores[0]; nhưng khi hiển thị cho người chơi, ta in i + 1 để đánh số từ 1 cho tự nhiên. Đừng nhầm lẫn hai cách đánh số này!

Bài 2: Chuỗi phím combo (mảng ký tự)

Trên lớp

Đề bài: Một combo chiêu thức gồm 8 phím, lưu trong mảng char combo[8]. Người chơi nhập lần lượt 8 phím (chỉ chấp nhận W A S D J K, chữ thường thì tự chuyển sang chữ hoa). Sau đó in combo dạng W->A->J... và đếm số lần nhấn phím tấn công J.

combo_keys.cpp 
#include <iostream>

int main() {
    const int LEN = 8;
    char combo[LEN];

    for (int i = 0; i < LEN; i++) {
        char key;
        bool valid = false;
        do {
            std::cout << "Phim thu " << i + 1 << " (W/A/S/D/J/K): ";
            std::cin >> key;
            if (key >= 'a' && key <= 'z') {
                key = key - 'a' + 'A';          // Chuyen chu thuong -> chu hoa
            }
            switch (key) {
                case 'W': case 'A': case 'S':
                case 'D': case 'J': case 'K':
                    valid = true;
                    break;
                default:
                    std::cout << "Phim khong hop le!\n";
            }
        } while (!valid);
        combo[i] = key;
    }

    int attackCount = 0;
    std::cout << "Combo: ";
    for (int i = 0; i < LEN; i++) {
        std::cout << combo[i];
        if (i < LEN - 1) std::cout << "->";   // Khong in mui ten sau phim cuoi
        if (combo[i] == 'J') attackCount++;
    }
    std::cout << "\nSo don tan cong (J): " << attackCount << "\n";
    return 0;
}
🎯 Thử nghiệm trên lớp: Đổi điều kiện vòng in thành i <= LEN rồi chạy lại. Bạn sẽ thấy một ký tự "lạ" xuất hiện ở cuối — đó chính là lỗi out-of-bounds đang đọc vùng nhớ ngoài mảng. Sửa lại ngay sau khi quan sát!

3. Bài tập về nhà (Tự luyện tập)

Hoàn thành cả 3 bài để thành thạo khai báo và duyệt mảng trước buổi sau:

Bài 1 [Easy]: Lọc vật phẩm trong túi đồ

Easy (40%)

Túi đồ có 10 ô, mỗi ô chứa mã vật phẩm (số nguyên, 0 nghĩa là ô trống). Khởi tạo sẵn int bag[10] = {12, 0, 7, 0, 0, 25, 3, 0, 18, 0};. Hãy: (a) in nội dung các ô ở vị trí chẵn (0, 2, 4…); (b) đếm số ô trống; (c) in danh sách ô có đồ theo dạng Slot 0: 12.

Gợi ý: Để duyệt các vị trí chẵn, cho i tăng mỗi lần 2 đơn vị (i += 2) thay vì kiểm tra i % 2 == 0.

bag_filter.cpp 
#include <iostream>

int main() {
    const int SIZE = 10;
    int bag[SIZE] = {12, 0, 7, 0, 0, 25, 3, 0, 18, 0};

    // (a) Cac o o vi tri chan
    std::cout << "O vi tri chan: ";
    for (int i = 0; i < SIZE; i += 2) {
        std::cout << bag[i] << " ";
    }
    std::cout << "\n";

    // (b) Dem o trong
    int emptyCount = 0;
    for (int i = 0; i < SIZE; i++) {
        if (bag[i] == 0) emptyCount++;
    }
    std::cout << "So o trong: " << emptyCount << "/" << SIZE << "\n";

    // (c) Danh sach o co do
    std::cout << "Vat pham dang co:\n";
    for (int i = 0; i < SIZE; i++) {
        if (bag[i] != 0) {
            std::cout << "  Slot " << i << ": " << bag[i] << "\n";
        }
    }
    return 0;
}

Bài 2 [Medium]: Bản đồ đối xứng & Đảo ngược

Medium (40%)

Một màn chơi 1 chiều được mô tả bằng mảng ký tự char map[7] (ví dụ # = tường, . = đường đi, $ = vàng). Người chơi nhập 7 ký tự. Hãy: (a) tạo mảng reversed[7] chứa bản đồ đảo ngược và in ra; (b) kiểm tra bản đồ có đối xứng hay không (đọc xuôi giống đọc ngược, ví dụ # . $ $ $ . #).

Phân tích: Phần tử đối xứng với map[i] là map[N - 1 - i]. Khi kiểm tra đối xứng chỉ cần so sánh nửa đầu với nửa sau, gặp một cặp khác nhau là kết luận ngay (break).

mirror_map.cpp 
#include <iostream>

int main() {
    const int N = 7;
    char map[N];
    char reversed[N];

    std::cout << "Nhap 7 o ban do (# . $), cach nhau boi dau cach: ";
    for (int i = 0; i < N; i++) {
        std::cin >> map[i];
    }

    // (a) Tao mang dao nguoc
    for (int i = 0; i < N; i++) {
        reversed[i] = map[N - 1 - i];
    }
    std::cout << "Ban do goc    : ";
    for (int i = 0; i < N; i++) std::cout << map[i];
    std::cout << "\nBan do dao nguoc: ";
    for (int i = 0; i < N; i++) std::cout << reversed[i];
    std::cout << "\n";

    // (b) Kiem tra doi xung: chi can duyet nua dau
    bool symmetric = true;
    for (int i = 0; i < N / 2; i++) {
        if (map[i] != map[N - 1 - i]) {
            symmetric = false;
            break;
        }
    }

    if (symmetric) {
        std::cout << "Ban do DOI XUNG!\n";
    } else {
        std::cout << "Ban do khong doi xung.\n";
    }
    return 0;
}

Bài 3 [Hard]: Trận chiến thanh máu ASCII

Hard (20%)

Có 5 con quái, máu ban đầu lưu trong mảng int hp[5] = {100, 70, 50, 90, 30};. Mỗi lượt, người chơi chọn con quái để đánh (nhập 1–5). Sát thương ngẫu nhiên từ 10 đến 35. Sau mỗi lượt, in thanh máu ASCII của cả đàn quái: mỗi ký tự # tương ứng 10 HP (làm tròn lên), quái chết in [DEAD]. Không cho chọn quái đã chết hoặc số ngoài 1–5. Trò chơi kết thúc khi tất cả quái chết; in tổng số lượt đã dùng.

Gợi ý: Số ký tự # làm tròn lên của hp là (hp + 9) / 10. Để biết còn quái sống không, duyệt mảng đếm số phần tử có hp[i] > 0.
hp_bar_battle.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    srand(time(0));
    const int N = 5;
    int hp[N] = {100, 70, 50, 90, 30};
    int turns = 0;
    int alive = N;

    while (alive > 0) {
        // --- 1. Ve thanh mau ---
        std::cout << "\n===== LUOT " << turns + 1 << " =====\n";
        for (int i = 0; i < N; i++) {
            std::cout << "Quai " << i + 1 << ": ";
            if (hp[i] <= 0) {
                std::cout << "[DEAD]\n";
                continue;
            }
            int blocks = (hp[i] + 9) / 10;       // Lam tron len
            for (int b = 0; b < blocks; b++) std::cout << '#';
            std::cout << " (" << hp[i] << ")\n";
        }

        // --- 2. Chon muc tieu hop le ---
        int target;
        while (true) {
            std::cout << "Danh quai so (1-5): ";
            std::cin >> target;
            if (target < 1 || target > N) {
                std::cout << "Khong co quai nay!\n";
            } else if (hp[target - 1] <= 0) {      // Doi tu so thu tu sang chi so
                std::cout << "Quai nay da chet roi!\n";
            } else {
                break;
            }
        }

        // --- 3. Gay sat thuong ---
        int damage = rand() % 26 + 10;               // 10..35
        hp[target - 1] -= damage;
        std::cout << "Ban gay " << damage << " sat thuong len quai " << target << "!\n";
        if (hp[target - 1] <= 0) {
            hp[target - 1] = 0;
            std::cout << "Quai " << target << " da bi tieu diet!\n";
        }
        turns++;

        // --- 4. Dem lai so quai con song ---
        alive = 0;
        for (int i = 0; i < N; i++) {
            if (hp[i] > 0) alive++;
        }
    }

    std::cout << "\nCHIEN THANG! Ban da tieu diet ca dan quai sau " << turns << " luot.\n";
    return 0;
}
💡 Mở rộng: Thêm mảng thứ hai int maxHp[5] để vẽ thanh máu dạng [###.....] (phần đã mất in dấu chấm). Đây chính là cách game vẽ thanh máu: tỉ lệ hp / maxHp quyết định độ dài phần màu đỏ.
