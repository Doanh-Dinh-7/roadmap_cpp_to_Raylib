Chuỗi Ký Tự (string): Khai Báo, Nhập Xuất và Duyệt Chuỗi

Mục tiêu đầu ra: Khai báo và sử dụng std::string, phân biệt khi nào dùng std::cin >> và khi nào dùng std::getline (kèm std::cin.ignore), lấy độ dài chuỗi bằng length()/size(), truy cập và duyệt từng ký tự để phân tích tên nhân vật, tin nhắn chat.

1. Lý thuyết cốt lõi (35 Phút)

1.1 Chuỗi ký tự là gì?

Từ trước đến nay ta dùng char để lưu một ký tự ('y', 'n'). Nhưng tên nhân vật, tin nhắn chat, câu thoại NPC đều là dãy nhiều ký tự. C++ cung cấp kiểu std::string (thư viện <string>) để lưu dãy ký tự đó.

Có thể hình dung std::string giống một mảng char thông minh (Buổi 26): mỗi ký tự có chỉ số bắt đầu từ 0, truy cập bằng s[i] — nhưng chuỗi tự biết độ dài của mình và có thể co giãn, không cần khai báo kích thước cố định.

Chỉ số 0123456
name = "Hiep Si" Hiep(dấu cách)Si

name.length() bằng 7 (dấu cách cũng là một ký tự), ký tự cuối là name[6], tức name[name.length() - 1].

1.2 Bảng tóm tắt cú pháp

Thao tác Mã C++ Ghi chú
Thư viện #include <string> Bắt buộc khi dùng std::string
Khai báo & gán std::string name = "Mario"; Chuỗi dùng nháy kép "...", ký tự dùng nháy đơn '...'
Chuỗi rỗng std::string s; hoặc s = ""; Kiểm tra bằng s.empty()
Nhập một từ std::cin >> s; Dừng ở dấu cách / xuống dòng đầu tiên
Nhập cả dòng std::getline(std::cin, s); Đọc cả dấu cách, dừng ở Enter
Độ dài s.length() hoặc s.size() Hai hàm giống hệt nhau
Truy cập ký tự s[i] Chỉ số hợp lệ: 0 → s.length() - 1
Sửa ký tự s[0] = 'M'; Gán một char vào vị trí
So sánh s == "admin", s != t So sánh từng ký tự, phân biệt hoa/thường

1.3 Code mẫu: Khai báo, truy cập, sửa và so sánh

string_basics.cpp 
#include <iostream>
#include <string>

int main() {
    std::string playerName = "Hiep Si";
    std::string guildName;                        // Chuoi rong ""

    std::cout << "Ten: " << playerName << "\n";
    std::cout << "Do dai: " << playerName.length() << "\n";     // 7
    std::cout << "Ky tu dau: " << playerName[0] << "\n";        // H
    std::cout << "Ky tu cuoi: "
              << playerName[playerName.length() - 1] << "\n";     // i

    playerName[0] = 'K';                           // Sua mot ky tu
    std::cout << "Sau khi sua: " << playerName << "\n";   // Kiep Si

    if (guildName.empty()) {
        std::cout << "Ban chua gia nhap bang hoi nao.\n";
    }

    if (playerName == "Kiep Si") {
        std::cout << "Ten khop!\n";
    }
    return 0;
}

1.4 std::cin và std::getline — cái bẫy kinh điển

std::cin >> s chỉ đọc đến dấu cách đầu tiên: người chơi gõ Hiep Si thì s chỉ nhận "Hiep". Muốn đọc cả dòng có dấu cách, dùng std::getline(std::cin, s).

Nhưng khi dùng std::cin >> age trước rồi mới getline, ký tự xuống dòng '\n' (do bấm Enter) vẫn còn nằm trong bộ đệm → getline đọc ngay dòng trống đó và "bị bỏ qua". Cách chữa: gọi std::cin.ignore(1000, '\n') để dọn bộ đệm trước khi getline.

cin_getline.cpp 
#include <iostream>
#include <string>

int main() {
    int level;
    std::string fullName;

    std::cout << "Nhap cap do: ";
    std::cin >> level;                              // Go "5" + Enter -> con lai '\n'

    std::cin.ignore(1000, '\n');                    // Bo '\n' con sot trong bo dem

    std::cout << "Nhap ho ten nhan vat: ";
    std::getline(std::cin, fullName);                  // Doc ca dong, ke ca dau cach

    std::cout << "Chao " << fullName << " (Lv." << level << ")\n";
    return 0;
}

1.5 Duyệt từng ký tự trong chuỗi

Giống duyệt mảng: dùng vòng for với chỉ số từ 0 đến length() - 1. Nên lưu độ dài vào biến int len trước vòng lặp cho gọn và tránh cảnh báo so sánh số có dấu/không dấu.

loop_chars.cpp (đoạn trích) 
std::string word = "RAYLIB";
int len = word.length();

for (int i = 0; i < len; i++) {
    std::cout << "[" << i << "] = " << word[i] << "\n";
}

// Dem so chu 'A' trong chuoi
int countA = 0;
for (int i = 0; i < len; i++) {
    if (word[i] == 'A') countA++;
}

Để phân loại ký tự, ta so sánh theo khoảng trong bảng mã ASCII: chữ hoa c >= 'A' && c <= 'Z', chữ thường c >= 'a' && c <= 'z', chữ số c >= '0' && c <= '9'. (Buổi 32 sẽ giới thiệu các hàm có sẵn trong <cctype> để làm việc này.)

🎮 Mẹo tư duy Game: Chuỗi có mặt ở mọi game: tên nhân vật trên đầu, ô chat, câu thoại NPC, mã cheat code... Trước khi chấp nhận tên người chơi, game thường duyệt từng ký tự để kiểm tra: độ dài 3–12 ký tự, chỉ gồm chữ và số, không có từ cấm. Ở Raylib, hàm DrawText cũng nhận một chuỗi để vẽ chữ lên màn hình.
⚠️ Lỗi thường gặp:
  • Truy cập ngoài chuỗi: s[s.length()] hoặc s[0] khi chuỗi rỗng → hành vi không xác định, giống out-of-bounds của mảng. Luôn kiểm tra !s.empty() trước khi lấy ký tự đầu/cuối.
  • Quên std::cin.ignore khi dùng getline sau cin >> → getline nhận chuỗi rỗng.
  • Nhầm nháy đơn và nháy kép: 'A' là một char, "A" là một chuỗi. Viết s[0] == "A" sẽ báo lỗi biên dịch.
  • So sánh i < s.length() với int i → trình biên dịch cảnh báo "signed/unsigned". Lưu int len = s.length(); trước để tránh.

2. Bài tập trên lớp (40 Phút)

Bài 1: Thẻ nhân vật có khung tự co giãn

Trên lớp

Đề bài: Nhập cấp độ (số nguyên) bằng std::cin, sau đó nhập tên nhân vật (có thể có dấu cách) bằng std::getline. In tên trong một khung = có chiều dài vừa khít với tên, kèm số ký tự và chữ cái đầu. Nếu tên rỗng, in "Ten khong hop le!".

character_card.cpp 
#include <iostream>
#include <string>

// In mot duong vien gom 'count' dau '='
void printBorder(int count) {
    for (int i = 0; i < count; i++) {
        std::cout << "=";
    }
    std::cout << "\n";
}

int main() {
    int level;
    std::string name;

    std::cout << "Nhap cap do: ";
    std::cin >> level;
    std::cin.ignore(1000, '\n');

    std::cout << "Nhap ten nhan vat: ";
    std::getline(std::cin, name);

    if (name.empty()) {
        std::cout << "Ten khong hop le!\n";
        return 0;
    }

    int len = name.length();
    printBorder(len + 4);                         // "| " + ten + " |"
    std::cout << "| " << name << " |\n";
    printBorder(len + 4);

    std::cout << "Cap do: " << level << "\n";
    std::cout << "So ky tu: " << len << "\n";
    std::cout << "Chu cai dau: " << name[0] << "\n";
    return 0;
}
Thử nghiệm: Xóa dòng std::cin.ignore(...) rồi chạy lại — bạn sẽ thấy chương trình không chờ nhập tên và báo "Ten khong hop le!". Đó chính là cái bẫy ở mục 1.4.

Bài 2: Phân tích tin nhắn chat

Trên lớp

Đề bài: Nhập một tin nhắn chat (cả dòng). Đếm và in số: chữ hoa, chữ thường, chữ số, dấu cách, ký tự khác, và nguyên âm (a e i o u, cả hoa lẫn thường). Viết hàm bool isVowel(char c) dùng một chuỗi "aeiouAEIOU" và duyệt chuỗi đó để kiểm tra.

chat_analyzer.cpp 
#include <iostream>
#include <string>

bool isVowel(char c) {
    std::string vowels = "aeiouAEIOU";
    int len = vowels.length();
    for (int k = 0; k < len; k++) {
        if (c == vowels[k]) return true;
    }
    return false;
}

int main() {
    std::string msg;
    std::cout << "Nhap tin nhan: ";
    std::getline(std::cin, msg);

    int upper = 0, lower = 0, digits = 0;
    int spaces = 0, others = 0, vowelCount = 0;
    int len = msg.length();

    for (int i = 0; i < len; i++) {
        char c = msg[i];
        if (c >= 'A' && c <= 'Z') {
            upper++;
        } else if (c >= 'a' && c <= 'z') {
            lower++;
        } else if (c >= '0' && c <= '9') {
            digits++;
        } else if (c == ' ') {
            spaces++;
        } else {
            others++;
        }

        if (isVowel(c)) vowelCount++;
    }

    std::cout << "Tong ky tu: " << len << "\n";
    std::cout << "Chu hoa: " << upper << " | Chu thuong: " << lower << "\n";
    std::cout << "Chu so: " << digits << " | Dau cach: " << spaces
              << " | Khac: " << others << "\n";
    std::cout << "Nguyen am: " << vowelCount << "\n";

    if (len > 0 && upper * 2 > upper + lower && upper + lower > 5) {
        std::cout << "[Canh bao] Dung viet hoa qua nhieu nhe!\n";
    }
    return 0;
}
🎯 Chạy thử: Nhập GG EZ 123 !!! → 4 chữ hoa, 0 chữ thường, 3 chữ số, 3 dấu cách, 3 ký tự khác, 1 nguyên âm (E). Phần cảnh báo cuối là bộ lọc "spam viết hoa" mà nhiều game online dùng trong khung chat.

3. Bài tập về nhà (Tự luyện tập)

Cả 3 bài đều nhập chuỗi bằng std::getline. Nhớ thử với chuỗi rỗng và chuỗi có dấu cách.

Bài 1 [Easy]: Tên nhân vật soi gương

Easy (40%)

Nhập tên nhân vật. In tên theo thứ tự ngược lại (ví dụ Hiep Si → iS peiH), sau đó in số ký tự không tính dấu cách.

Gợi ý: Duyệt chỉ số từ len - 1 lùi về 0. Nếu chuỗi rỗng thì len - 1 = -1, vòng lặp không chạy lần nào — an toàn.

mirror_name.cpp 
#include <iostream>
#include <string>

int main() {
    std::string name;
    std::cout << "Nhap ten nhan vat: ";
    std::getline(std::cin, name);

    int len = name.length();

    std::cout << "Ten soi guong: ";
    for (int i = len - 1; i >= 0; i--) {      // Duyet nguoc
        std::cout << name[i];
    }
    std::cout << "\n";

    int letters = 0;
    for (int i = 0; i < len; i++) {
        if (name[i] != ' ') letters++;
    }
    std::cout << "So ky tu (khong tinh dau cach): " << letters << "\n";
    return 0;
}

Bài 2 [Medium]: Kiểm tra mật khẩu tài khoản game

Medium (40%)

Viết hàm bool isStrongPassword(std::string pw) kiểm tra mật khẩu mạnh: (1) ít nhất 8 ký tự; (2) có ít nhất 1 chữ hoa; (3) có ít nhất 1 chữ thường; (4) có ít nhất 1 chữ số; (5) không chứa dấu cách. Hàm in ra từng lý do chưa đạt. Chương trình chính yêu cầu nhập lại (bằng getline) cho tới khi mật khẩu hợp lệ.

Phân tích: Duyệt chuỗi một lần, bật các cờ hasUpper, hasLower, hasDigit, hasSpace. Sau vòng lặp mới kết luận — giống kỹ thuật "cờ hiệu" của Linear Search (Buổi 28).

password_check.cpp 
#include <iostream>
#include <string>

bool isStrongPassword(std::string pw) {
    int len = pw.length();
    bool hasUpper = false, hasLower = false;
    bool hasDigit = false, hasSpace = false;

    for (int i = 0; i < len; i++) {
        char c = pw[i];
        if (c >= 'A' && c <= 'Z') hasUpper = true;
        else if (c >= 'a' && c <= 'z') hasLower = true;
        else if (c >= '0' && c <= '9') hasDigit = true;
        else if (c == ' ') hasSpace = true;
    }

    bool ok = true;
    if (len < 8)  { std::cout << " - Can it nhat 8 ky tu\n";   ok = false; }
    if (!hasUpper) { std::cout << " - Thieu chu hoa\n";          ok = false; }
    if (!hasLower) { std::cout << " - Thieu chu thuong\n";       ok = false; }
    if (!hasDigit) { std::cout << " - Thieu chu so\n";           ok = false; }
    if (hasSpace)  { std::cout << " - Khong duoc chua dau cach\n"; ok = false; }
    return ok;
}

int main() {
    std::string password;
    bool valid = false;

    do {
        std::cout << "Tao mat khau: ";
        std::getline(std::cin, password);
        valid = isStrongPassword(password);
        if (!valid) {
            std::cout << "Mat khau yeu, vui long nhap lai.\n\n";
        }
    } while (!valid);

    std::cout << "Tao tai khoan thanh cong!\n";
    return 0;
}

Bài 3 [Hard]: Mật thư Caesar giữa hai đồng đội

Hard (20%)

Mã hóa Caesar dịch mỗi chữ cái đi k vị trí trong bảng chữ cái, quay vòng về đầu khi vượt z (ví dụ k = 3: a → d, x → a, Z → C). Chữ hoa giữ hoa, chữ thường giữ thường, các ký tự khác giữ nguyên. Viết chương trình có menu:

  • 1 — Mã hóa: nhập thông điệp (cả dòng) và khóa k (1–25).
  • 2 — Giải mã: nhập thông điệp đã mã hóa và khóa k.
  • 3 — Phá mã: không biết khóa, in thử cả 25 khả năng để người chơi tự đọc ra câu có nghĩa.
Gợi ý: Viết hàm std::string caesar(std::string text, int shift) trả về chuỗi đã dịch. Công thức cho chữ thường: 'a' + (c - 'a' + shift) % 26. Giải mã với khóa k chính là mã hóa với khóa 26 - k. Đừng quên std::cin.ignore sau khi nhập lựa chọn menu!
caesar_cipher.cpp 
#include <iostream>
#include <string>

// Dich moi chu cai di 'shift' vi tri (0-25), giu nguyen ky tu khac
std::string caesar(std::string text, int shift) {
    int len = text.length();
    for (int i = 0; i < len; i++) {
        char c = text[i];
        if (c >= 'a' && c <= 'z') {
            text[i] = 'a' + (c - 'a' + shift) % 26;
        } else if (c >= 'A' && c <= 'Z') {
            text[i] = 'A' + (c - 'A' + shift) % 26;
        }
    }
    return text;                              // Tra ve ban sao da dich
}

int readKey() {
    int key;
    do {
        std::cout << "Nhap khoa (1-25): ";
        std::cin >> key;
    } while (key < 1 || key > 25);
    return key;
}

int main() {
    int choice;
    do {
        std::cout << "1 - Ma hoa | 2 - Giai ma | 3 - Pha ma: ";
        std::cin >> choice;
    } while (choice < 1 || choice > 3);
    std::cin.ignore(1000, '\n');               // Don '\n' truoc getline

    std::string text;
    std::cout << "Nhap thong diep: ";
    std::getline(std::cin, text);

    if (choice == 1) {
        int key = readKey();
        std::cout << "Mat thu: " << caesar(text, key) << "\n";
    } else if (choice == 2) {
        int key = readKey();
        std::cout << "Ban goc: " << caesar(text, 26 - key) << "\n";
    } else {
        for (int k = 1; k <= 25; k++) {          // Thu moi khoa co the
            std::cout << "Khoa " << k << ": " << caesar(text, 26 - k) << "\n";
        }
    }
    return 0;
}
💡 Kiểm tra nhanh: Mã hóa Tan cong luc 9h! với khóa 3 → Wdq frqj oxf 9k!. Giải mã chuỗi đó với khóa 3 phải ra lại câu gốc. Chế độ 3 cho thấy Caesar rất dễ phá vì chỉ có 25 khóa — một vòng for là đủ "hack".
