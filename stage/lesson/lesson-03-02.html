Tham Số (Parameters) và Giá Trị Trả Về (Return)

Mục tiêu đầu ra: Truyền dữ liệu vào hàm bằng tham số, nhận kết quả bằng return; hiểu rằng truyền tham trị chỉ gửi bản sao; dùng tham số mặc định; thiết kế hàm tính toán (sát thương, điểm số, kiểm tra trạng thái) cho game.

1. Lý thuyết cốt lõi (35 Phút)

1.1 Tham số: "cửa vào" của hàm

Hàm printLine() ở Buổi 23 luôn in đúng một kiểu dòng kẻ. Nếu muốn dòng kẻ dài 10 ký tự lúc này, 30 ký tự lúc khác, ta cần gửi thông tin vào hàm. Biến nhận thông tin đó gọi là tham số (parameter); giá trị cụ thể truyền vào khi gọi gọi là đối số (argument).

parameter_demo.cpp 
#include <iostream>

// length va symbol la THAM SO (parameter)
void printLine(int length, char symbol) {
    for (int i = 0; i < length; i++) {
        std::cout << symbol;
    }
    std::cout << "\n";
}

int main() {
    printLine(10, '-');    // 10 va '-' la DOI SO (argument)
    printLine(20, '=');
    int width = 5;
    printLine(width * 2, '*');   // Doi so co the la bieu thuc
    return 0;
}

Đối số được gán cho tham số theo đúng thứ tự: đối số thứ nhất → tham số thứ nhất, v.v. Số lượng và kiểu phải khớp với khai báo.

1.2 Giá trị trả về: "cửa ra" của hàm

Thay void bằng một kiểu dữ liệu (int, double, bool, char...) để hàm gửi lại một kết quả cho nơi gọi bằng lệnh return. Lời gọi hàm khi đó có thể đặt ở bất kỳ đâu cần một giá trị: phép gán, biểu thức, điều kiện if, hoặc std::cout.

return_demo.cpp 
#include <iostream>

int calculateDamage(int attack, int defense) {
    int damage = attack - defense;
    if (damage < 1) {
        return 1;           // Luon gay it nhat 1 sat thuong
    }
    return damage;
}

bool isAlive(int hp) {
    return hp > 0;          // Tra ve ket qua cua phep so sanh
}

int main() {
    int monsterHp = 30;
    int dmg = calculateDamage(18, 5);          // Dung trong phep gan
    monsterHp = monsterHp - dmg;
    std::cout << "Gay " << dmg << " sat thuong. HP quai: " << monsterHp << "\n";

    std::cout << "Don yeu: " << calculateDamage(3, 10) << "\n";   // Dung trong cout

    if (isAlive(monsterHp)) {                     // Dung trong dieu kien
        std::cout << "Quai van con song!\n";
    }
    return 0;
}

1.3 Bảng tóm tắt cú pháp

Mẫu hàm Ví dụ Ý nghĩa
Có tham số, không trả về void printHp(int hp) Nhận dữ liệu để làm việc (in, vẽ)
Có tham số, có trả về int add(int a, int b) Nhận dữ liệu → tính toán → gửi kết quả về
Không tham số, có trả về int rollDie() Tự tạo giá trị (ví dụ số ngẫu nhiên) rồi trả về
Hàm kiểm tra (trả về bool) bool isAlive(int hp) Đặt tên dạng câu hỏi: is..., has..., can...
Tham số mặc định void printLine(int len = 20, char c = '-') Gọi printLine() hoặc printLine(5) đều hợp lệ
Prototype có tham số int add(int a, int b); Có thể bỏ tên tham số: int add(int, int);

1.4 Truyền tham trị (Pass by Value) — hàm chỉ nhận bản sao

Khi gọi hàm, C++ sao chép giá trị của đối số vào tham số. Hàm thay đổi tham số chỉ làm thay đổi bản sao, biến gốc ở nơi gọi không hề bị ảnh hưởng. Muốn cập nhật biến gốc, hãy return giá trị mới rồi gán lại.

pass_by_value.cpp 
#include <iostream>

void healWrong(int hp) {
    hp = hp + 50;            // Chi sua BAN SAO
    std::cout << "Trong ham: hp = " << hp << "\n";
}

int heal(int hp, int amount) {
    hp = hp + amount;
    if (hp > 100) hp = 100;  // Khong vuot qua mau toi da
    return hp;               // Gui gia tri moi ve
}

int main() {
    int playerHp = 40;

    healWrong(playerHp);
    std::cout << "Sau healWrong: " << playerHp << "\n";   // Van la 40!

    playerHp = heal(playerHp, 50);                         // Gan lai ket qua
    std::cout << "Sau heal: " << playerHp << "\n";         // 90
    return 0;
}
Kết quả chạy: Trong ham: hp = 90 → Sau healWrong: 40 → Sau heal: 90. Cách để hàm sửa trực tiếp biến gốc (tham chiếu &) sẽ được học ở Giai đoạn 04; hiện tại hãy luôn dùng mẫu x = f(x);.

1.5 Tham số mặc định (Default Arguments)

Tham số mặc định cho phép bỏ qua đối số khi gọi; hàm sẽ dùng giá trị đã định sẵn.

default_args.cpp 
#include <iostream>

void printLine(int length = 20, char symbol = '-');   // Gia tri mac dinh dat o PROTOTYPE

int main() {
    printLine();            // length = 20, symbol = '-'
    printLine(8);           // length = 8,  symbol = '-'
    printLine(8, '#');      // length = 8,  symbol = '#'
    return 0;
}

void printLine(int length, char symbol) {             // Dinh nghia KHONG lap lai mac dinh
    for (int i = 0; i < length; i++) {
        std::cout << symbol;
    }
    std::cout << "\n";
}
  • Tham số mặc định phải nằm bên phải: void f(int a, int b = 0) hợp lệ, void f(int a = 0, int b) là lỗi.
  • Chỉ ghi giá trị mặc định ở một nơi — thường là prototype. Ghi ở cả hai nơi sẽ bị lỗi biên dịch.
  • Không thể bỏ qua đối số ở giữa: muốn đổi symbol thì phải truyền cả length.
🎮 Mẹo tư duy Game: Trong Raylib, gần như mọi thao tác đều là hàm có tham số: DrawCircle(x, y, radius, RED), DrawText("Score", 10, 10, 20, WHITE). Còn các hàm trả về giá trị thì dùng để hỏi trạng thái game: IsKeyPressed(KEY_SPACE) trả về bool, GetRandomValue(1, 6) trả về int. Tư duy "hàm làm việc" vs "hàm trả lời câu hỏi" sẽ theo bạn suốt quá trình làm game.
⚠️ Lỗi thường gặp:
  • Quên return trong hàm không phải void (ví dụ chỉ return trong nhánh if) → hàm trả về giá trị rác, chương trình chạy sai khó đoán. Hãy bật cảnh báo -Wall để trình biên dịch nhắc.
  • Gọi hàm có trả về nhưng bỏ quên kết quả: heal(playerHp, 50); → máu không đổi vì không gán lại.
  • Truyền sai thứ tự đối số: calculateDamage(defense, attack) vẫn biên dịch được nhưng tính sai.
  • Chia nguyên: int average(int total, int n) { return total / n; } làm mất phần thập phân; dùng kiểu trả về double và (double)total / n. Nhớ kiểm tra n != 0.
  • Lệnh sau return trong cùng khối không bao giờ chạy.

2. Bài tập trên lớp (55 Phút)

Bài 1: Bộ hàm tiện ích cho chỉ số nhân vật

Trên lớp

Đề bài: Viết 3 hàm và thử nghiệm trong main:

  • int clamp(int value, int minValue, int maxValue): ép value nằm trong khoảng [minValue, maxValue].
  • int takeDamage(int hp, int damage): trả về máu mới sau khi trúng đòn, không âm (dùng lại clamp).
  • double hpPercent(int hp, int maxHp): trả về phần trăm máu còn lại.
stat_utils.cpp 
#include <iostream>

int clamp(int value, int minValue, int maxValue);
int takeDamage(int hp, int damage);
double hpPercent(int hp, int maxHp);

int main() {
    const int MAX_HP = 120;
    int hp = MAX_HP;

    hp = takeDamage(hp, 45);
    std::cout << "HP: " << hp << " (" << hpPercent(hp, MAX_HP) << "%)\n";

    hp = takeDamage(hp, 200);    // Don chi mang
    std::cout << "HP: " << hp << " (" << hpPercent(hp, MAX_HP) << "%)\n";

    std::cout << "clamp(150, 0, 100) = " << clamp(150, 0, 100) << "\n";
    return 0;
}

int clamp(int value, int minValue, int maxValue) {
    if (value < minValue) return minValue;
    if (value > maxValue) return maxValue;
    return value;
}

int takeDamage(int hp, int damage) {
    return clamp(hp - damage, 0, hp);    // Ham goi ham
}

double hpPercent(int hp, int maxHp) {
    if (maxHp <= 0) return 0.0;          // Tranh chia cho 0
    return (double)hp * 100 / maxHp;
}

Bài 2: Vẽ thanh máu (Health Bar) có tham số mặc định

Trên lớp

Đề bài: Viết hàm void drawHealthBar(int hp, int maxHp, int width = 20) vẽ thanh máu dạng [##########----------] 60/120, với số ký tự # tỉ lệ với lượng máu. Viết thêm int rollDie(int sides = 6) trả về số ngẫu nhiên từ 1 đến sides. Mô phỏng 5 lượt quái vật tấn công, mỗi lượt gây sát thương rollDie(20) và vẽ lại thanh máu.

health_bar.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

void drawHealthBar(int hp, int maxHp, int width = 20);
int rollDie(int sides = 6);

int main() {
    srand(time(0));
    const int MAX_HP = 120;
    int hp = MAX_HP;

    drawHealthBar(hp, MAX_HP);
    for (int turn = 1; turn <= 5 && hp > 0; turn++) {
        int damage = rollDie(20);
        hp = hp - damage;
        if (hp < 0) hp = 0;
        std::cout << "Luot " << turn << ": quai gay " << damage << " sat thuong\n";
        drawHealthBar(hp, MAX_HP);
    }
    drawHealthBar(hp, MAX_HP, 40);   // Ban to hon o man hinh tong ket
    return 0;
}

void drawHealthBar(int hp, int maxHp, int width) {
    int filled = hp * width / maxHp;      // So o duoc to day
    std::cout << "[";
    for (int i = 0; i < width; i++) {
        if (i < filled) std::cout << "#";
        else            std::cout << "-";
    }
    std::cout << "] " << hp << "/" << maxHp << "\n";
}

int rollDie(int sides) {
    return rand() % sides + 1;
}
🎯 Nhận xét: Thứ tự phép tính hp * width / maxHp quan trọng: nếu viết hp / maxHp * width thì hp / maxHp chia nguyên ra 0 (khi hp < maxHp) và thanh máu luôn rỗng.

3. Bài tập về nhà (Tự luyện tập)

Bài 1 [Easy]: Max của 3 số & kiểm tra chẵn

Easy (40%)

Viết hàm int maxOf3(int a, int b, int c) trả về số lớn nhất trong 3 số và hàm bool isEven(int n). Nhập điểm của 3 người chơi, in ra điểm cao nhất và cho biết điểm đó chẵn hay lẻ.

max_of_3.cpp 
#include <iostream>

int maxOf3(int a, int b, int c);
bool isEven(int n);

int main() {
    int p1, p2, p3;
    std::cout << "Nhap diem 3 nguoi choi: ";
    std::cin >> p1 >> p2 >> p3;

    int best = maxOf3(p1, p2, p3);
    std::cout << "Diem cao nhat: " << best << "\n";
    if (isEven(best)) {
        std::cout << "Day la so chan.\n";
    } else {
        std::cout << "Day la so le.\n";
    }
    return 0;
}

int maxOf3(int a, int b, int c) {
    int result = a;
    if (b > result) result = b;
    if (c > result) result = c;
    return result;
}

bool isEven(int n) {
    return n % 2 == 0;
}

Bài 2 [Medium]: Bảng tính điểm trận đấu & xếp hạng

Medium (40%)

Sau mỗi trận, game tính điểm theo công thức score = kills * 100 + assists * 50 - deaths * 30 + bonus (điểm không được âm). Viết:

  • int calcScore(int kills, int deaths, int assists, int bonus = 0)
  • char getRank(int score): >= 1000 → 'S', >= 700 → 'A', >= 400 → 'B', còn lại 'C'.
  • void printResult(int score, char rank)

Nhập số trận n, mỗi trận nhập K/D/A và hỏi trận đó có phải trận thắng không (thắng được bonus = 200). Cuối cùng in tổng điểm và hạng trung bình (dựa trên điểm trung bình).

match_score.cpp 
#include <iostream>

int calcScore(int kills, int deaths, int assists, int bonus = 0);
char getRank(int score);
void printResult(int score, char rank);

int main() {
    int n;
    do {
        std::cout << "So tran: ";
        std::cin >> n;
    } while (n <= 0);

    int total = 0;
    for (int i = 1; i <= n; i++) {
        int k, d, a;
        char win;
        std::cout << "\nTran " << i << " - nhap Kill Death Assist: ";
        std::cin >> k >> d >> a;
        std::cout << "Thang tran? (y/n): ";
        std::cin >> win;

        int score;
        if (win == 'y' || win == 'Y') {
            score = calcScore(k, d, a, 200);
        } else {
            score = calcScore(k, d, a);          // Dung bonus mac dinh = 0
        }
        printResult(score, getRank(score));
        total += score;
    }

    int average = total / n;
    std::cout << "\nTong diem: " << total << "\n";
    std::cout << "Diem trung binh: " << average << " - Hang: " << getRank(average) << "\n";
    return 0;
}

int calcScore(int kills, int deaths, int assists, int bonus) {
    int score = kills * 100 + assists * 50 - deaths * 30 + bonus;
    if (score < 0) score = 0;
    return score;
}

char getRank(int score) {
    if (score >= 1000) return 'S';
    if (score >= 700)  return 'A';
    if (score >= 400)  return 'B';
    return 'C';
}

void printResult(int score, char rank) {
    std::cout << "=> Diem: " << score << " | Hang: " << rank << "\n";
}

Nhận xét: Nhờ return sớm, getRank không cần chuỗi else if: mỗi khi một điều kiện đúng, hàm kết thúc ngay.

Bài 3 [Hard]: Đấu trường theo lượt (Turn-based Battle)

Hard (20%)

Hero (HP 100, ATK 20, DEF 5) đấu với Orc (HP 120, ATK 16, DEF 3). Mỗi lượt người chơi chọn: 1. Tan cong hoặc 2. Uong thuoc (hồi 30 HP, tối đa 3 bình). Sau lượt người chơi, Orc tấn công lại. Trận kết thúc khi một bên hết máu. Yêu cầu dùng các hàm:

  • int rollDie(int sides)
  • bool isCritical(int chancePercent): trả về true với xác suất chancePercent%.
  • int calcDamage(int attack, int defense, bool critical): sát thương = attack - defense + rollDie(6), nhân đôi nếu chí mạng, tối thiểu 1.
  • int applyDamage(int hp, int damage), int heal(int hp, int amount, int maxHp), bool isAlive(int hp).
  • void drawHealthBar(int hp, int maxHp, int width = 20) (dùng lại từ bài trên lớp).
Phân tích: Mọi phép tính đều nằm trong hàm nhỏ và trả về giá trị mới; main chỉ giữ trạng thái (máu, số bình thuốc) và gán lại kết quả theo mẫu hp = f(hp, ...).
turn_battle.cpp 
#include <iostream>
#include <cstdlib>
#include <ctime>

int rollDie(int sides);
bool isCritical(int chancePercent);
int calcDamage(int attack, int defense, bool critical);
int applyDamage(int hp, int damage);
int heal(int hp, int amount, int maxHp);
bool isAlive(int hp);
void drawHealthBar(int hp, int maxHp, int width = 20);

int main() {
    srand(time(0));
    const int HERO_MAX = 100, HERO_ATK = 20, HERO_DEF = 5;
    const int ORC_MAX = 120, ORC_ATK = 16, ORC_DEF = 3;
    int heroHp = HERO_MAX, orcHp = ORC_MAX;
    int potions = 3, turn = 1;

    while (isAlive(heroHp) && isAlive(orcHp)) {
        std::cout << "\n===== LUOT " << turn << " =====\n";
        std::cout << "Hero "; drawHealthBar(heroHp, HERO_MAX);
        std::cout << "Orc  "; drawHealthBar(orcHp, ORC_MAX);

        int choice;
        do {
            std::cout << "1. Tan cong  2. Uong thuoc (con " << potions << "): ";
            std::cin >> choice;
        } while (choice != 1 && choice != 2);

        if (choice == 2 && potions > 0) {
            heroHp = heal(heroHp, 30, HERO_MAX);
            potions--;
            std::cout << "Hero hoi mau! HP = " << heroHp << "\n";
        } else {
            if (choice == 2) std::cout << "Het thuoc! Hero tan cong thay.\n";
            bool crit = isCritical(20);
            int dmg = calcDamage(HERO_ATK, ORC_DEF, crit);
            orcHp = applyDamage(orcHp, dmg);
            std::cout << "Hero chem " << dmg << " sat thuong";
            if (crit) std::cout << " (CHI MANG!)";
            std::cout << "\n";
        }

        if (!isAlive(orcHp)) break;               // Orc guc, khong phan cong

        bool orcCrit = isCritical(10);
        int orcDmg = calcDamage(ORC_ATK, HERO_DEF, orcCrit);
        heroHp = applyDamage(heroHp, orcDmg);
        std::cout << "Orc dap " << orcDmg << " sat thuong";
        if (orcCrit) std::cout << " (CHI MANG!)";
        std::cout << "\n";
        turn++;
    }

    std::cout << "\n===== KET QUA =====\n";
    if (isAlive(heroHp)) std::cout << "CHIEN THANG sau " << turn << " luot!\n";
    else                 std::cout << "GAME OVER...\n";
    return 0;
}

int rollDie(int sides) {
    return rand() % sides + 1;
}

bool isCritical(int chancePercent) {
    return rollDie(100) <= chancePercent;
}

int calcDamage(int attack, int defense, bool critical) {
    int damage = attack - defense + rollDie(6);
    if (critical) damage = damage * 2;
    if (damage < 1) damage = 1;
    return damage;
}

int applyDamage(int hp, int damage) {
    hp = hp - damage;
    if (hp < 0) hp = 0;
    return hp;
}

int heal(int hp, int amount, int maxHp) {
    hp = hp + amount;
    if (hp > maxHp) hp = maxHp;
    return hp;
}

bool isAlive(int hp) {
    return hp > 0;
}

void drawHealthBar(int hp, int maxHp, int width) {
    int filled = hp * width / maxHp;
    std::cout << "[";
    for (int i = 0; i < width; i++) {
        if (i < filled) std::cout << "#";
        else            std::cout << "-";
    }
    std::cout << "] " << hp << "/" << maxHp << "\n";
}
💡 Mở rộng: Thêm lựa chọn 3. Phong thu (lượt đó DEF của Hero nhân đôi). Bạn chỉ cần truyền HERO_DEF * 2 vào calcDamage — không phải sửa bất kỳ hàm nào. Đó là lợi ích của hàm có tham số.
