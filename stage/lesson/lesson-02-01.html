Vòng Lặp While & Điều Kiện Dừng

Mục tiêu đầu ra: Hiểu cơ chế vòng lặp while, kiểm soát điều kiện dừng, áp dụng biến đếm và xây dựng game loop cơ bản trên console.

1. Lý thuyết cốt lõi (20 Phút)

Vòng lặp while là cấu trúc điều khiển cho phép lặp lại một khối lệnh chừng nào điều kiện còn đúng (true). Đây là nền tảng của mọi game loop — vòng lặp trung tâm chạy liên tục trong suốt thời gian game hoạt động.

1.1 Cú pháp vòng lặp while

Cú pháp 
while (condition) {
    /* thân lặp — thực thi khi condition == true */
}

1.2 Sơ đồ luồng thực thi

Luồng hoạt động:
Kiểm tra điều kiện → Nếu đúng → Thực thi thân lặp → Quay lại kiểm tra
Kiểm tra điều kiện → Nếu sai → Thoát khỏi vòng lặp

1.3 Biến đếm và điều kiện dừng

Mỗi vòng lặp phải có cơ chế làm cho điều kiện trở thành false ở một thời điểm nào đó, nếu không sẽ gây ra vòng lặp vô hạn — lỗi phổ biến làm treo chương trình.

while_co_ban.cpp 
int count = 0;
while (count < 5) {
    std::cout << "Lan lap thu: " << count << std::endl;
    count++; // cap nhat bien dieu kien — bat buoc!
}

1.4 Ứng dụng thực tế: Game Loop console

🎮 Kết nối Game Dev: Mọi game đều có "game loop" chạy mãi — while(running) { update(); draw(); }. Vòng lặp while chính là xương sống của mọi trò chơi!
game_loop_console.cpp 
bool running = true;
int score = 0;
while (running) {
    char input;
    std::cout << "Nhan 'q' de thoat, phim khac de tang diem: ";
    std::cin >> input;
    if (input == 'q') {
        running = false;
    } else {
        score++;
        std::cout << "Diem: " << score << std::endl;
    }
}
std::cout << "Ket thuc! Diem cuoi: " << score << std::endl;

2. Bài tập trên lớp — Live Coding (40 Phút)

Giảng viên hướng dẫn học viên cùng viết và chạy thử trực tiếp:

Thực hành: Đếm ngược kiểu bom nổ trong game

Trên lớp

Viết chương trình đếm ngược từ 10 về 0 (kiểu đếm ngược bom nổ trong game), rồi in "No! Game Over!" sau vòng lặp. Mỗi số cách nhau bởi dấu ...

Gợi ý: Khởi tạo timer = 10, điều kiện dừng là timer >= 0, mỗi vòng giảm timer--.

Code mẫu:

dem_nguoc.cpp 
#include <iostream>

int main() {
    int timer = 10;
    while (timer >= 0) {
        std::cout << timer << "... ";
        timer--;
    }
    std::cout << "\nNo! Game Over!" << std::endl;
    return 0;
}

3. Bài tập về nhà (Tự luyện tập)

Học viên hoàn thành các bài tập sau để nắm vững vòng lặp while và điều kiện dừng:

Bài 1 [Easy]: Tính tổng 1 đến n

Easy (40%)

Viết chương trình nhập số nguyên dương n từ bàn phím, sau đó dùng vòng lặp while để tính tổng các số từ 1 đến n và in kết quả.

Ý tưởng: Dùng biến sum = 0 và i = 1, lặp trong khi i <= n, cộng dồn rồi tăng i.

tong_1_den_n.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap n: ";
    std::cin >> n;
    int sum = 0, i = 1;
    while (i <= n) {
        sum += i;
        i++;
    }
    std::cout << "Tong 1 den " << n << " = " << sum << std::endl;
    return 0;
}

Bài 2 [Medium]: Nhập số đến khi gặp 0

Medium (40%)

Viết chương trình liên tục nhận số nguyên dương từ người dùng và tính tổng. Chương trình dừng khi người dùng nhập 0. In ra tổng cuối cùng.

Ý tưởng: Đọc số đầu tiên trước vòng lặp, điều kiện dừng là num != 0, đọc số tiếp theo ở cuối thân lặp.

tong_den_0.cpp 
#include <iostream>

int main() {
    int num, sum = 0;
    std::cout << "Nhap so (0 de dung): ";
    std::cin >> num;
    while (num != 0) {
        sum += num;
        std::cout << "Nhap so (0 de dung): ";
        std::cin >> num;
    }
    std::cout << "Tong: " << sum << std::endl;
    return 0;
}

Bài 3 [Hard]: Game Đoán Số phiên bản while

Hard (20%)

Viết Game Đoán Số: máy tính chọn số bí mật từ 1–100, người chơi đoán mãi đến khi đúng. Mỗi lần đoán sai in "Lon hon!" hoặc "Nho hon!". Đếm và hiển thị số lần đoán khi thắng.

Ý tưởng: Dùng do-while để đảm bảo đoán ít nhất 1 lần. Dùng rand() % 100 + 1 để tạo số ngẫu nhiên.

doan_so.cpp 
#include <iostream>
#include <cstdlib>

int main() {
    srand(42);
    int secret = rand() % 100 + 1;
    int guess, attempts = 0;
    do {
        std::cout << "Doan so (1-100): ";
        std::cin >> guess;
        attempts++;
        if (guess < secret) std::cout << "Lon hon!\n";
        else if (guess > secret) std::cout << "Nho hon!\n";
    } while (guess != secret);
    std::cout << "Dung roi! " << attempts << " luot doan.\n";
    return 0;
}
