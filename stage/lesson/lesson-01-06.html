Toán Tử Số Học và Toán Tử Gán Trong C++

Mục tiêu đầu ra: Sử dụng thành thạo các toán tử tính toán, gán phức hợp và phân biệt chính xác cơ chế tiền tố ++x vs hậu tố x++.

1. Lý thuyết cốt lõi (20 Phút)

1.1 Toán tử số học & Gán phức hợp

Trong cơ chế game, việc cập nhật giá trị biến diễn ra liên tục:

  • hp -= damage; tương đương hp = hp - damage; (Trừ máu khi dính đòn).
  • score += comboBonus; tương đương score = score + comboBonus; (Cộng dồn điểm).
  • ammo %= clipSize; (Tính số đạn lẻ còn lại).

1.2 Cạm bẫy Tiền tố (Prefix) vs Hậu tố (Postfix)

Cả ++x và x++ đều tăng giá trị của x lên 1 đơn vị, nhưng thời điểm trả về giá trị trong biểu thức là hoàn toàn khác nhau:

  • Tiền tố (++x): Tăng giá trị của x TRƯỚC, rồi mới trả về giá trị mới cho biểu thức sử dụng.
  • Hậu tố (x++): Trả về giá trị hiện tại của x cho biểu thức sử dụng TRƯỚC, rồi sau đó mới tăng x lên 1.
prefix_vs_postfix.cpp 
int a = 5;
int b = ++a; // a thành 6, b nhận giá trị 6

int x = 5;
int y = x++; // y nhận giá trị 5, sau đó x mới thành 6

2. Thực hành tại lớp — Live Coding (45 Phút)

Thực hành: Mô phỏng hiệp đấu nhận sát thương và Combo thưởng điểm

Easy

Khởi tạo nhân vật có hp = 100, score = 0, ammo = 30. Mô phỏng 3 hành động:
1. Bắn 1 viên đạn (giảm ammo dùng hậu tố ammo--).
2. Bắn trúng quái vật, nhận 150 điểm kèm combo nhân 2.
3. Bị quái vật cắn phản đòn mất 25 HP dùng toán tử -=.

Ví dụ Output 
Output:
=== TRẠNG THÁI KHỞI ĐẦU ===
HP: 100 | Score: 0 | Ammo: 30

-> Bắn 1 viên đạn! Đạn còn: 29
-> Bắn trúng đầu quái! Điểm hiện tại: 300
-> Bị phản đòn! HP còn lại: 75
combat_math.cpp 
#include <iostream>

int main() {
    int hp = 100;
    int score = 0;
    int ammo = 30;

    std::cout << "=== TRẠNG THÁI KHỞI ĐẦU ===\n";
    std::cout << "HP: " << hp << " | Score: " << score << " | Ammo: " << ammo << "\n";

    // 1. Bắn 1 viên đạn
    ammo--;
    std::cout << "\n-> Bắn 1 viên đạn! Đạn còn: " << ammo << "\n";

    // 2. Đạt Combo điểm
    score += (150 * 2);
    std::cout << "-> Bắn trúng đầu quái! Điểm hiện tại: " << score << "\n";

    // 3. Bị phản đòn
    hp -= 25;
    std::cout << "-> Bị quái vật cắn! HP còn lại: " << hp << "\n";

    return 0;
}

3. Bài tập về nhà (3 Cấp độ)

Bài 1 [Easy]: Tính chu vi và diện tích vòng tròn bảo vệ (Shield Radius)

Easy (40%)

Nhập vào bán kính của khiên chắn bảo vệ nhân vật radius (số thực). Tính chu vi khiên 2 * PI * radius và diện tích vùng bảo vệ PI * radius * radius với hằng số PI = 3.14159f.

Ví dụ Input / Output 
Input:
Nhập bán kính khiên bảo vệ (R): 10

Output:
Chu vi khiên: 62.8318
Diện tích bao phủ: 314.159
shield_circle.cpp 
#include <iostream>

int main() {
    const float PI = 3.14159f;
    float radius;
    std::cout << "Nhập bán kính khiên bảo vệ (R): ";
    std::cin >> radius;

    float perimeter = 2.0f * PI * radius;
    float area = PI * radius * radius;

    std::cout << "Chu vi khiên: " << perimeter << "\n";
    std::cout << "Diện tích bao phủ: " << area << "\n";
    return 0;
}

Bài 2 [Medium]: Đổi tiền tệ đổi tiền mặt sang mệnh giá tiền lẻ (ATM Dispenser)

Medium (40%)

Nhập vào một số tiền vàng nguyên gold. Hãy phân rã số tiền đó ra số tờ tiền mệnh giá 500k, 200k, 100k, 50k bằng cách sử dụng kết hợp toán tử chia nguyên / và chia lấy dư %.

Ví dụ Input / Output 
Input:
Nhập số tiền cần rút: 1850000

Output:
Số tờ 500k: 3
Số tờ 200k: 1
Số tờ 100k: 1
Số tờ 50k : 1
Số tiền lẻ dư: 0 đ
currency_exchange.cpp 
#include <iostream>

int main() {
    int amount;
    std::cout << "Nhập số tiền cần rút: ";
    std::cin >> amount;

    int to500 = amount / 500000;
    amount %= 500000;

    int to200 = amount / 200000;
    amount %= 200000;

    int to100 = amount / 100000;
    amount %= 100000;

    int to50 = amount / 50000;
    amount %= 50000;

    std::cout << "Số tờ 500k: " << to500 << "\n";
    std::cout << "Số tờ 200k: " << to200 << "\n";
    std::cout << "Số tờ 100k: " << to100 << "\n";
    std::cout << "Số tờ 50k : " << to50 << "\n";
    std::cout << "Số tiền lẻ dư: " << amount << " đ\n";
    return 0;
}

Bài 3 [Hard]: Mô phỏng con lắc đơn và gia tốc trọng trường

Hard (20%)

Chu kỳ dao động của một bẫy chông con lắc trong hầm ngục tính theo công thức: T = 2 * PI * sqrt(L / g). Nhập chiều dài dây treo L (mét) và sử dụng g = 9.8f để tính chu kỳ con lắc vung qua lại (dùng hàm sqrt() trong <cmath>).

Ví dụ Input / Output 
Input:
Nhập chiều dài dây bẫy con lắc (m): 2.5

Output:
Chu kỳ vung của bẫy con lắc: 3.173 giây/lượt dao động.
pendulum_trap.cpp 
#include <iostream>
#include <cmath>

int main() {
    const float PI = 3.14159265f;
    const float G = 9.8f;
    float length;

    std::cout << "Nhập chiều dài dây bẫy con lắc (m): ";
    std::cin >> length;

    float period = 2.0f * PI * sqrt(length / G);

    std::cout << "Chu kỳ vung của bẫy con lắc: " << period << " giây/lượt dao động.\n";
    return 0;
}
