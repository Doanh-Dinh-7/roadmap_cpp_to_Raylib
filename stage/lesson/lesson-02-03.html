Sửa Bài Vòng Lặp Cơ Bản & Nhận Diện Lỗi Lặp Vô Hạn

Mục tiêu đầu ra: Nhận diện và sửa được 5 lỗi vòng lặp phổ biến, áp dụng kỹ thuật debug bằng cout, tính tổng và tìm Max/Min trong vòng lặp.

1. Lý thuyết cốt lõi (20 Phút)

Buổi hôm nay tập trung vào việc nhận diện và sửa lỗi — kỹ năng thực chiến quan trọng không kém gì viết code mới. Một lập trình viên giỏi phải đọc được code lỗi và biết ngay chỗ sai.

1.1 Năm lỗi vòng lặp phổ biến

⚠️ Lỗi 1: Quên cập nhật biến điều kiện → vòng lặp vô hạn
loi_1_vo_han.cpp 
// LOI: Quen tang i -> lap vo han
int i = 0;
while (i < 10) {
    std::cout << i; // thieu i++ o day!
}

// SUA:
int i = 0;
while (i < 10) {
    std::cout << i;
    i++; // them dong nay de thoat khoi vong lap
}
⚠️ Lỗi 2: Dùng = thay vì == trong điều kiện
loi_2_dieu_kien_sai.cpp 
// LOI: = la gan gia tri (luon true), == moi la so sanh
int x = 5;
while (x = 10) { // gan x = 10, luon true!
    std::cout << x;
    x--;
}

// SUA:
while (x == 10) { // dung == de so sanh
    std::cout << x;
    x--;
}
⚠️ Lỗi 3: Off-by-one error — lặp nhiều hơn hoặc ít hơn 1 lần
loi_3_off_by_one.cpp 
// LOI: Muon in 1..10 nhung dung < thay vi <=
for (int i = 1; i < 10; i++) { // chi in 1..9 (thieu 10)
    std::cout << i << " ";
}

// SUA:
for (int i = 1; i <= 10; i++) { // dung <= de in du 1..10
    std::cout << i << " ";
}
Lỗi 4 & 5:
Lỗi 4 — Vòng lặp lồng nhau dùng chung biến đếm (i cả trong lẫn ngoài): biến trong ghi đè biến ngoài làm vòng ngoài bị sai.
Lỗi 5 — Điều kiện ngược (> thay vì <): vòng lặp không bao giờ chạy vì điều kiện sai ngay từ đầu.

1.2 Kỹ thuật debug vòng lặp

💡 Thêm cout debug: Thêm dòng in giá trị biến điều kiện ngay đầu thân lặp để theo dõi từng vòng. Khi tìm ra lỗi thì xóa dòng debug đi.
debug_vong_lap.cpp 
int i = 0;
while (i < 5) {
    // DEBUG: in gia tri i de theo doi
    std::cout << "[DEBUG] i = " << i << "\n";
    // logic chinh
    std::cout << "Xu ly phan tu " << i << "\n";
    i++;
}

1.3 Tìm giá trị lớn nhất (Max) trong dãy

tim_max.cpp 
int n, maxVal;
std::cin >> n;
std::cin >> maxVal; // lay so dau tien lam max tam thoi
for (int i = 1; i < n; i++) {
    int x;
    std::cin >> x;
    if (x > maxVal) maxVal = x; // cap nhat neu tim duoc so lon hon
}
std::cout << "Max: " << maxVal << std::endl;

2. Bài tập trên lớp — Live Coding (40 Phút)

Thực hành: Tìm và sửa lỗi trong 3 đoạn code

Trên lớp

Giảng viên trình chiếu 3 đoạn code có lỗi khác nhau. Học viên quan sát, phân tích và trao đổi để tìm lỗi trước khi xem đáp án. Mỗi đoạn có 1 lỗi duy nhất cần sửa.

Phương pháp:
1. Đọc code, xác định mục tiêu (code này muốn làm gì?)
2. Chạy tay từng bước (trace code) với giá trị cụ thể
3. Tìm điểm mà kết quả lệch so với mục tiêu
4. Sửa và kiểm tra lại

Bài lỗi 1: Quên cập nhật biến → thêm i++ cuối thân lặp.

Bài lỗi 2: Dùng < thay vì <= → off-by-one, thiếu phần tử cuối.

Bài lỗi 3: Vòng lặp lồng nhau dùng cùng tên biến i → đổi biến trong thành j.

3. Bài tập về nhà (Tự luyện tập)

Học viên hoàn thành các bài tập sau để rèn kỹ năng xử lý dữ liệu trong vòng lặp:

Bài 1 [Easy]: Đếm số chẵn trong dãy

Easy (40%)

Nhập số nguyên n, sau đó nhập n số nguyên. Đếm và in ra số lượng số chẵn trong dãy.

Ý tưởng: Dùng if (x % 2 == 0) count++; trong vòng lặp để đếm số chẵn.

dem_so_chan.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap n: ";
    std::cin >> n;
    int count = 0;
    for (int i = 0; i < n; i++) {
        int x;
        std::cin >> x;
        if (x % 2 == 0) count++;
    }
    std::cout << "So luong so chan: " << count << std::endl;
    return 0;
}

Bài 2 [Medium]: Trung bình cộng loại bỏ số âm

Medium (40%)

Nhập n số nguyên từ bàn phím. Tính trung bình cộng của các số không âm (≥ 0) trong dãy. Số âm không được tính vào trung bình. In kết quả.

Ý tưởng: Dùng 2 biến: sum cộng dồn số không âm, posCount đếm số lượng. Chia ở cuối nếu posCount > 0.

trung_binh_loai_am.cpp 
#include <iostream>

int main() {
    int n;
    std::cout << "Nhap n: ";
    std::cin >> n;
    int sum = 0, posCount = 0;
    for (int i = 0; i < n; i++) {
        int x;
        std::cin >> x;
        if (x >= 0) { sum += x; posCount++; }
    }
    if (posCount > 0)
        std::cout << "Trung binh: " << (double)sum / posCount << std::endl;
    else
        std::cout << "Khong co so khong am nao!\n";
    return 0;
}

Bài 3 [Hard]: Tìm số lớn nhất và vị trí của nó

Hard (20%)

Nhập dãy số nguyên từ bàn phím, dừng khi nhập 0. Tìm số lớn nhất trong dãy và vị trí của nó (đếm từ 1). In cả số lẫn vị trí ra màn hình.

Ý tưởng: Dùng thêm biến pos lưu vị trí, cập nhật pos cùng lúc với maxVal. Biến idx đếm vị trí hiện tại.

max_va_vi_tri.cpp 
#include <iostream>
#include <climits>

int main() {
    int num, maxVal = INT_MIN, pos = 0, idx = 0;
    std::cout << "Nhap so (0 de dung): ";
    std::cin >> num;
    while (num != 0) {
        idx++;
        if (num > maxVal) { maxVal = num; pos = idx; }
        std::cout << "Nhap so (0 de dung): ";
        std::cin >> num;
    }
    if (idx > 0)
        std::cout << "So lon nhat: " << maxVal << " tai vi tri " << pos << std::endl;
    else
        std::cout << "Day rong!\n";
    return 0;
}
