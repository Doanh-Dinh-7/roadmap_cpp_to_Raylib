GIAI ĐOẠN 05 — LẬP TRÌNH HƯỚNG ĐỐI TƯỢNG (OOP)

4 trụ cột OOP trong C++: Đóng gói (Class/Object), Kế thừa (Inheritance), Đa hình (Polymorphism với virtual function) và Trừu tượng hóa. Tổ chức mã nguồn chuẩn tách rời file header .h và triển khai .cpp.

Trọng tâm: Mini Project Turn-based Battle Game (Warrior, Mage, Archer đấu Quái vật với HP/Atk/Def/Skill).

GIAI ĐOẠN 06 — LÀM QUEN VỚI RAYLIB

Cài đặt môi trường đồ họa Raylib trong C++, kiến trúc Game Loop chuẩn (Init $\rightarrow$ Update $\rightarrow$ Draw $\rightarrow$ Unload), vẽ hình khối hình học, xử lý bàn phím/chuột, chuyển động vector và va chạm hình học (AABB).

Trọng tâm: Game bóng né vật thể rơi (Dodge Game) có tính điểm, màn hình Game Over và chơi lại.

Công Cụ & Môi Trường Lập Trình

Bộ công cụ tiêu chuẩn chuyên nghiệp, nhẹ và tương thích tốt trên Windows/Linux/macOS.

C++ (C++14+)

Ngôn ngữ cốt lõi rèn luyện tư duy logic, quản lý bộ nhớ và hiệu năng cao.

Raylib Library

Thư viện đồ họa 2D thuần khiết, đơn giản, không phụ thuộc cồng kềnh.

VS Code

Trình soạn thảo mã nguồn nhẹ, kết hợp các extension C/C++ tiện lợi.

GCC & MinGW-w64

Bộ trình biên dịch chuẩn quốc tế cho C/C++ trên môi trường Windows.

Git & GitHub

Quản lý phiên bản mã nguồn, theo dõi tiến độ nộp bài và lưu trữ đồ án.

Tiêu Chuẩn Đánh Giá Final Project (100%)

Đồ án tốt nghiệp được chấm điểm minh bạch theo 5 tiêu chí năng lực cốt lõi.

Tiêu chí Trọng số Nội dung đánh giá chi tiết
Logic & Gameplay 30% Luật chơi rõ ràng, core loop hoàn chỉnh, mục tiêu phân định thắng/thua cụ thể.
Kỹ năng C++ / OOP 25% Code sạch, tách file .h/.cpp, vận dụng đúng đắn tính kế thừa, đa hình OOP.
Trải nghiệm chơi (Game UX) 20% Điều khiển nhạy, không delay phím, game mượt 60 FPS, không crash hay lỗi vặt.
UI, Đồ họa, Âm thanh 15% Giao diện hiển thị điểm/máu rõ ràng; hình ảnh sprite và âm thanh phù hợp chủ đề.
Trình bày & Demo 10% Tự tin giải thích kiến trúc source code, trả lời phản biện và demo trực tiếp.
